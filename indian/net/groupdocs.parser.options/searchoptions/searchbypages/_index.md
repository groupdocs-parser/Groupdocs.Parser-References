## SearchOptions.SearchByPages property

यह दर्शाने वाला मान प्राप्त करता है कि क्या खोज पृष्ठों द्वारा की जाती है।

```csharp
public bool SearchByPages { get; set; }
```

### Property Value

`true` यदि खोज पृष्ठों द्वारा की जाती है; अन्यथा, `false` और खोज पूरे दस्तावेज़ पर की जाती है बिना [`PageIndex`](../../../groupdocs.parser.data/searchresult/pageindex) प्रॉपर्टी मान को [`SearchResult`](../../../groupdocs.parser.data/searchresult) क्लास में शामिल किए।
