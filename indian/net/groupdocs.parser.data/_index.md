नेमस्पेस पार्सिंग परिणामों को दर्शाने वाली क्लास प्रदान करता है।

## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [AnnotationItem](./annotationitem) | एक एनोटेशन आइटम को दर्शाता है जो एनोटेशन निष्कर्षण कार्यक्षमता में उपयोग किया जाता है। |
| [ContainerItem](./containeritem) | ज़िप आर्काइव एंटिटी, ईमेल अटैचमेंट, PDF पोर्टफ़ोलियो आइटम आदि जैसे कंटेनर आइटम को दर्शाता है। |
| [DocumentData](./documentdata) | दस्तावेज़ का डेटा दर्शाता है। यह [`FieldData`](../groupdocs.parser.data/fielddata) वस्तुओं से बना है जो दस्तावेज़ से फ़ील्ड डेटा रखती हैं। |
| [DocumentPageData](./documentpagedata) | दस्तावेज़ पृष्ठ का डेटा दर्शाता है। यह [`FieldData`](../groupdocs.parser.data/fielddata) वस्तुओं से बना है जो दस्तावेज़ पृष्ठ से फ़ील्ड डेटा रखती हैं। |
| [FieldData](./fielddata) | फ़ील्ड डेटा दर्शाता है जैसे नाम, पृष्ठ सूचकांक, फ़ील्ड मान आदि। फ़ील्ड के आधार पर मान टेक्स्ट, इमेज, टेबल आदि हो सकता है। |
| [HighlightItem](./highlightitem) | हाइलाइट दर्शाता है, टेक्स्ट का वह भाग जो आमतौर पर खोज कार्यक्षमता में पाए गए टेक्स्ट के संदर्भ को समझाने के लिए उपयोग किया जाता है। |
| [MetadataItem](./metadataitem) | मेटाडेटा आइटम दर्शाता है जो कंटेनर आइटम और मेटाडेटा निष्कर्षण कार्यक्षमता में उपयोग होता है। |
| [Page](./page) | दस्तावेज़ पृष्ठ की जानकारी दर्शाता है जैसे पृष्ठ सूचकांक और पृष्ठ आकार। यह उस पृष्ठ को दर्शाने के लिए उपयोग होता है जिसमें [`PageArea`](../groupdocs.parser.data/pagearea) क्लास के उत्तराधिकारी होते हैं, टेम्प्लेट द्वारा पार्सिंग कार्यक्षमता में। |
| [PageArea](./pagearea) | पृष्ठ क्षेत्रों के लिए एक सारभूत बेस क्लास दर्शाता है जो टेम्प्लेट द्वारा पार्सिंग कार्यक्षमता में दस्तावेज़ पृष्ठ पर ब्लॉकों को दर्शाने के लिए उपयोग होती है। |
| [PageBarcodeArea](./pagebarcodearea) | पृष्ठ बारकोड क्षेत्र दर्शाता है जो टेम्प्लेट द्वारा पार्सिंग कार्यक्षमता में बारकोड मान को दर्शाने के लिए उपयोग होता है। |
| [PageGroupArea](./pagegrouparea) | पृष्ठ क्षेत्रों का समूह दर्शाता है जो टेम्प्लेट द्वारा पार्सिंग कार्यक्षमता में दस्तावेज़ पृष्ठ के विभिन्न प्रकार के ब्लॉकों को समूहित करने के लिए उपयोग होता है। |
| [PageHyperlinkArea](./pagehyperlinkarea) | पृष्ठ क्षेत्र दर्शाता है जो पृष्ठ पर हाइपरलिंक को दर्शाने के लिए उपयोग होता है। |
| [PageImageArea](./pageimagearea) | पृष्ठ इमेज क्षेत्र दर्शाता है जो टेम्प्लेट द्वारा पार्सिंग कार्यक्षमता में पृष्ठ पर इमेज को दर्शाने के लिए या ईमेल या ज़िप आर्काइव से निकाली गई इमेज अटैचमेंट को दर्शाने के लिए उपयोग होता है। |
| [PageTableArea](./pagetablearea) | टेबल पृष्ठ क्षेत्र दर्शाता है जो टेम्प्लेट द्वारा पार्सिंग कार्यक्षमता में टेबल को दर्शाने के लिए उपयोग होता है। |
| [PageTableAreaCell](./pagetableareacell) | टेबल सेल दर्शाता है जो [`PageTableArea`](../groupdocs.parser.data/pagetablearea) क्लास में उपयोग होती है। |
| [PageTextArea](./pagetextarea) | पृष्ठ टेक्स्ट क्षेत्र दर्शाता है जो टेम्प्लेट द्वारा पार्सिंग या फ़ॉर्म पार्सिंग कार्यक्षमता में टेक्स्ट मान को दर्शाने के लिए उपयोग होता है। |
| [Point](./point) | एक बिंदु दर्शाता है। |
| [Rectangle](./rectangle) | एक आयताकार क्षेत्र दर्शाता है। |
| [SearchResult](./searchresult) | खोज कार्यक्षमता में खोज परिणाम दर्शाता है। |
| [Size](./size) | एक आकार दर्शाता है। |
| [TextStyle](./textstyle) | टेक्स्ट की शैली दर्शाता है जैसे फ़ॉन्ट नाम, फ़ॉन्ट आकार आदि। |
| [TocItem](./tocitem) | सामग्री-सूची निष्कर्षण कार्यक्षमता में उपयोग होने वाला आइटम दर्शाता है। |
| [WorksheetCell](./worksheetcell) | वर्कशीट सेल दर्शाता है। |
| [WorksheetInfo](./worksheetinfo) | शीट जानकारी दर्शाता है। |
| [WorksheetRange](./worksheetrange) | वर्कशीट निष्कर्षण के लिए उपयोग होने वाली रेंज प्रदान करता है। |
