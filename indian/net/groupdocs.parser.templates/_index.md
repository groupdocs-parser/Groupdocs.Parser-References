नेमस्पेस दस्तावेज़ डेटा पार्स करने के लिए टेम्प्लेट बनाने की क्लास प्रदान करता है।

## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [Template](./template) | दस्तावेज़ पृष्ठ टेम्प्लेट प्रदान करता है। यह [`TemplateItem`](../groupdocs.parser.templates/templateitem) वस्तुओं से बना है जो टेम्प्लेट के आइटम जैसे पाठ फ़ील्ड और तालिका परिभाषाएँ दर्शाते हैं। |
| [TemplateBarcode](./templatebarcode) | टेम्प्लेट बारकोड फ़ील्ड प्रदान करता है। |
| [TemplateCollection](./templatecollection) | दस्तावेज़ पार्सिंग टेम्प्लेट्स का संग्रह दर्शाता है। |
| [TemplateField](./templatefield) | टेम्प्लेट टेक्स्ट फ़ील्ड प्रदान करता है। |
| [TemplateFixedPosition](./templatefixedposition) | आयताकार क्षेत्र द्वारा परिभाषित टेम्प्लेट फ़ील्ड स्थिति प्रदान करता है। |
| [TemplateItem](./templateitem) | टेम्प्लेट आइटम्स के लिए एक बेस एब्स्ट्रैक्ट क्लास प्रदान करता है। |
| [TemplateLinkedPosition](./templatelinkedposition) | लिंक्ड फ़ील्ड का उपयोग करने वाली टेम्प्लेट फ़ील्ड स्थिति प्रदान करता है। |
| [TemplateLinkedPositionEdges](./templatelinkedpositionedges) | टेक्स्ट फ़ील्ड खोजे जाने वाले लिंक्ड फ़ील्ड के किनारों को प्रदान करता है। [`TemplateLinkedPositionEdges`](../groupdocs.parser.templates/templatelinkedpositionedges) का उपयोग [`TemplateLinkedPosition`](../groupdocs.parser.templates/templatelinkedposition) क्लास में किया जाता है। |
| [TemplateOptions](./templateoptions) | टेम्प्लेट कार्यक्षमता द्वारा पार्सिंग के लिए उपयोग किए जाने वाले विकल्प प्रदान करता है। |
| [TemplatePosition](./templateposition) | टेम्प्लेट स्थितियों के लिए एक बेस एब्स्ट्रैक्ट क्लास प्रदान करता है। |
| [TemplateRegexPosition](./templateregexposition) | रेगुलर एक्सप्रेशन का उपयोग करने वाली टेम्प्लेट फ़ील्ड स्थिति प्रदान करता है। |
| [TemplateTable](./templatetable) | टेम्प्लेट तालिका प्रदान करता है। |
| [TemplateTableLayout](./templatetablelayout) | टेम्प्लेट तालिका लेआउट प्रदान करता है जिसका उपयोग [`TemplateTable`](../groupdocs.parser.templates/templatetable) क्लास द्वारा तालिका स्थिति निर्धारित करने के लिए किया जाता है। |
| [TemplateTableParameters](./templatetableparameters) | तालिका डिटेक्शन एल्गोरिदम के लिए पैरामीटर प्रदान करता है। |
