यह पैकेज दस्तावेज़ डेटा पार्स करने के लिए टेम्प्लेट बनाने के क्लास प्रदान करता है।

| क्लास | विवरण |
| --- | --- |
| [Template](../com.groupdocs.parser.templates/template) | दस्तावेज़ पृष्ठ टेम्पलेट प्रदान करता है। |

| [TemplateItem](../com.groupdocs.parser.templates/templateitem) | टेम्पलेट आइटम्स के लिए बेस एब्स्ट्रैक्ट क्लास प्रदान करता है। |
| [TemplateLinkedPosition](../com.groupdocs.parser.templates/templatelinkedposition) | टेम्पलेट फ़ील्ड स्थिति प्रदान करता है जो लिंक्ड फ़ील्ड का उपयोग करता है। |
| [TemplateLinkedPositionEdges](../com.groupdocs.parser.templates/templatelinkedpositionedges) | टेक्स्ट फ़ील्ड खोजे जाने वाले लिंक्ड फ़ील्ड के किनारे प्रदान करता है। |
| [TemplateOptions](../com.groupdocs.parser.templates/templateoptions) | टेम्पलेट कार्यक्षमता द्वारा पार्सिंग के लिए उपयोग किए जाने वाले विकल्प प्रदान करता है। |
| [TemplatePosition](../com.groupdocs.parser.templates/templateposition) | टेम्पलेट पोजीशन्स के लिए बेस एब्स्ट्रैक्ट क्लास प्रदान करता है। |
| [TemplateRegexPosition](../com.groupdocs.parser.templates/templateregexposition) | टेम्पलेट फ़ील्ड स्थिति प्रदान करता है जो नियमित अभिव्यक्ति का उपयोग करता है। |
| [TemplateTable](../com.groupdocs.parser.templates/templatetable) | टेम्प्लेट तालिका प्रदान करता है। |
| [TemplateTableLayout](../com.groupdocs.parser.templates/templatetablelayout) | टेम्प्लेट तालिका लेआउट प्रदान करता है जिसका उपयोग [TemplateTable](../com.groupdocs.parser.templates/templatetable) क्लास द्वारा तालिका की स्थिति निर्धारित करने के लिए किया जाता है। |
| [TemplateTableParameters](../com.groupdocs.parser.templates/templatetableparameters) | तालिका पहचान एल्गोरिदम के लिए पैरामीटर प्रदान करता है। |
