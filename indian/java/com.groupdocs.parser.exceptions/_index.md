यह पैकेज विभिन्न अपवाद क्लास प्रदान करता है।



## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [CorruptedDocumentException](../com.groupdocs.parser.exceptions/corrupteddocumentexception) | दस्तावेज़ लोड करते समय फेंका जाता है, जब दस्तावेज़ भ्रष्ट हो। |
| [GroupDocsParserException](../com.groupdocs.parser.exceptions/groupdocsparserexception) | ऐप्लिकेशन निष्पादन के दौरान उत्पन्न होने वाली त्रुटियों का प्रतिनिधित्व करता है। |
| [InvalidPasswordException](../com.groupdocs.parser.exceptions/invalidpasswordexception) | यदि दस्तावेज़ पासवर्ड से एन्क्रिप्ट किया गया है और दस्तावेज़ खोलते समय निर्दिष्ट पासवर्ड गलत या अनुपलब्ध है तो फेंका जाता है। |
| [UnsupportedDocumentFormatException](../com.groupdocs.parser.exceptions/unsupporteddocumentformatexception) | दस्तावेज़ लोड करते समय फेंका जाता है, जब दस्तावेज़ फ़ॉर्मेट पहचाना नहीं जाता या समर्थित नहीं है। |
