このパッケージは、さまざまな例外クラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [CorruptedDocumentException](../com.groupdocs.parser.exceptions/corrupteddocumentexception) | ドキュメントの読み込み中に、ドキュメントが破損している場合にスローされます。 |
| [GroupDocsParserException](../com.groupdocs.parser.exceptions/groupdocsparserexception) | アプリケーション実行中に発生するエラーを表します。 |
| [InvalidPasswordException](../com.groupdocs.parser.exceptions/invalidpasswordexception) | ドキュメントがパスワードで暗号化されており、開く際に指定されたパスワードが間違っているか欠落している場合にスローされます。 |
| [UnsupportedDocumentFormatException](../com.groupdocs.parser.exceptions/unsupporteddocumentformatexception) | ドキュメントの読み込み中に、ドキュメント形式が認識されない、またはサポートされていない場合にスローされます。 |
