このパッケージは、解析結果を表すクラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [ContainerItem](../com.groupdocs.parser.data/containeritem) | Zip アーカイブエンティティ、メール添付ファイル、PDF ポートフォリオ項目などのコンテナ項目を表します。 |
| [DocumentData](../com.groupdocs.parser.data/documentdata) | ドキュメントのデータを表します。 |
| [DocumentPageData](../com.groupdocs.parser.data/documentpagedata) | ドキュメントページのデータを表します。 |
| [FieldData](../com.groupdocs.parser.data/fielddata) | 名前、ページインデックス、フィールド値などのフィールドデータを表します。 |
| [HighlightItem](../com.groupdocs.parser.data/highlightitem) | 検索機能で見つかったテキストのコンテキストを説明するために通常使用される、テキストの一部であるハイライトを表します。 |
| [MetadataItem](../com.groupdocs.parser.data/metadataitem) | コンテナ項目およびメタデータ抽出機能で使用されるメタデータ項目を表します。 |
| [Page](../com.groupdocs.parser.data/page) | ページインデックスやページサイズなどのドキュメントページ情報を表します。 |
| [PageArea](../com.groupdocs.parser.data/pagearea) | テンプレート解析機能でドキュメントページ上のブロックを表すために使用されるページ領域の抽象基底クラスを表します。 |
| [PageBarcodeArea](../com.groupdocs.parser.data/pagebarcodearea) | テンプレート解析機能でバーコード値を表すために使用されるページバーコード領域を表します。 |
| [PageGroupArea](../com.groupdocs.parser.data/pagegrouparea) | テンプレート解析機能でドキュメントページのさまざまなタイプのブロックをグループ化するために使用されるページ領域のグループを表します。 |
| [PageHyperlinkArea](../com.groupdocs.parser.data/pagehyperlinkarea) | ページ上のハイパーリンクを表すために使用されるページ領域を表します。 |
| [PageImageArea](../com.groupdocs.parser.data/pageimagearea) | テンプレート解析機能でページ上の画像を表すために使用されるページ画像領域、またはメールや Zip アーカイブから抽出された画像が画像添付ファイルの場合に使用されます。 |
| [PageTableArea](../com.groupdocs.parser.data/pagetablearea) | テンプレート解析機能でテーブルを表すために使用されるテーブルページ領域を表します。 |
| [PageTableAreaCell](../com.groupdocs.parser.data/pagetableareacell) | テーブルセルを表します。このセルは [PageTableArea](../com.groupdocs.parser.data/pagetablearea) クラスで使用されます。 |
| [PageTextArea](../com.groupdocs.parser.data/pagetextarea) | テンプレート解析またはフォーム解析機能でテキスト値を表すために使用されるページテキスト領域を表します。 |
| [Point](../com.groupdocs.parser.data/point) | 点を表します。 |
| [Rectangle](../com.groupdocs.parser.data/rectangle) | 矩形領域を表します。 |
| [SearchResult](../com.groupdocs.parser.data/searchresult) | 検索機能における検索結果を表します。 |
| [Size](../com.groupdocs.parser.data/size) | サイズを表します。 |
| [TextReader](../com.groupdocs.parser.data/textreader) | 文字のシーケンシャルな系列を読み取ることができるリーダーを表します。 |
| [TextStyle](../com.groupdocs.parser.data/textstyle) | フォント名やフォントサイズなど、テキストのスタイルを表します。 |
| [TocItem](../com.groupdocs.parser.data/tocitem) | 目次抽出機能で使用される項目を表します。 |
