このパッケージは、ドキュメントデータの解析用テンプレートを作成するクラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [Template](../com.groupdocs.parser.templates/template) | ドキュメントページテンプレートを提供します。 |
| [TemplateBarcode](../com.groupdocs.parser.templates/templatebarcode) | テンプレートのバーコードフィールドを提供します。 |
| [TemplateField](../com.groupdocs.parser.templates/templatefield) | テンプレートのテキストフィールドを提供します。 |
| [TemplateFixedPosition](../com.groupdocs.parser.templates/templatefixedposition) | 矩形領域で定義されるテンプレートフィールド位置を提供します。 |
| [TemplateItem](../com.groupdocs.parser.templates/templateitem) | テンプレート項目の基底抽象クラスを提供します。 |
| [TemplateLinkedPosition](../com.groupdocs.parser.templates/templatelinkedposition) | リンクされたフィールドを使用するテンプレートフィールド位置を提供します。 |
| [TemplateLinkedPositionEdges](../com.groupdocs.parser.templates/templatelinkedpositionedges) | テキストフィールドが検索されるリンクされたフィールドのエッジを提供します。 |
| [TemplateOptions](../com.groupdocs.parser.templates/templateoptions) | テンプレート機能による解析に使用されるオプションを提供します。 |
| [TemplatePosition](../com.groupdocs.parser.templates/templateposition) | テンプレート位置の基底抽象クラスを提供します。 |
| [TemplateRegexPosition](../com.groupdocs.parser.templates/templateregexposition) | 正規表現を使用するテンプレートフィールド位置を提供します。 |
| [TemplateTable](../com.groupdocs.parser.templates/templatetable) | テンプレートテーブルを提供します。 |
| [TemplateTableLayout](../com.groupdocs.parser.templates/templatetablelayout) | テンプレートテーブルのレイアウトを提供します。このレイアウトは [TemplateTable](../com.groupdocs.parser.templates/templatetable) クラスでテーブルの位置を定義するために使用されます。 |
| [TemplateTableParameters](../com.groupdocs.parser.templates/templatetableparameters) | テーブル検出アルゴリズムのパラメータを提供します。 |
