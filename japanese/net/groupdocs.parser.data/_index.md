この名前空間は、解析結果を表すクラスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [AnnotationItem](./annotationitem) | アノテーション抽出機能で使用されるアノテーション項目を表します。 |
| [ContainerItem](./containeritem) | Zip アーカイブエンティティ、メール添付、PDF ポートフォリオ項目などのコンテナ項目を表します。 |
| [DocumentData](./documentdata) | ドキュメントのデータを表します。ドキュメントからのフィールドデータを含む [`FieldData`](../groupdocs.parser.data/fielddata) オブジェクトで構成されています。 |
| [DocumentPageData](./documentpagedata) | ドキュメントページのデータを表します。ドキュメントページからのフィールドデータを含む [`FieldData`](../groupdocs.parser.data/fielddata) オブジェクトで構成されています。 |
| [FieldData](./fielddata) | 名前、ページインデックス、フィールド値などのフィールドデータを表します。フィールドによって、値はテキスト、画像、テーブルなどになる場合があります。 |
| [HighlightItem](./highlightitem) | ハイライト（検索機能で見つかったテキストの文脈を説明するために通常使用されるテキストの一部）を表します。 |
| [MetadataItem](./metadataitem) | コンテナ項目およびメタデータ抽出機能で使用されるメタデータ項目を表します。 |
| [Page](./page) | ページインデックスやページサイズなどのドキュメントページ情報を表します。テンプレートによる解析機能で [`PageArea`](../groupdocs.parser.data/pagearea) クラスの派生クラスを含むページを表すために使用されます。 |
| [PageArea](./pagearea) | テンプレートによる解析機能でドキュメントページ上のブロックを表すために使用されるページ領域の抽象基底クラスを表します。 |
| [PageBarcodeArea](./pagebarcodearea) | テンプレートによる解析機能でバーコード値を表すために使用されるページバーコード領域を表します。 |
| [PageGroupArea](./pagegrouparea) | テンプレートによる解析機能でドキュメントページのさまざまなタイプのブロックをグループ化するために使用されるページ領域のグループを表します。 |
| [PageHyperlinkArea](./pagehyperlinkarea) | ページ上のハイパーリンクを表すために使用されるページ領域を表します。 |
| [PageImageArea](./pageimagearea) | テンプレートによる解析機能でページ上の画像を表すために使用されるページ画像領域、またはメールや Zip アーカイブから抽出された画像が添付ファイルとしてある場合に使用されます。 |
| [PageTableArea](./pagetablearea) | テンプレートによる解析機能でテーブルを表すために使用されるテーブルページ領域を表します。 |
| [PageTableAreaCell](./pagetableareacell) | [`PageTableArea`](../groupdocs.parser.data/pagetablearea) クラスで使用されるテーブルセルを表します。 |
| [PageTextArea](./pagetextarea) | テンプレート解析またはフォーム解析機能でテキスト値を表すために使用されるページテキスト領域を表します。 |
| [Point](./point) | 点を表します。 |
| [Rectangle](./rectangle) | 矩形領域を表します。 |
| [SearchResult](./searchresult) | 検索機能における検索結果を表します。 |
| [Size](./size) | サイズを表します。 |
| [TextStyle](./textstyle) | フォント名やフォントサイズなど、テキストのスタイルを表します。 |
| [TocItem](./tocitem) | 目次抽出機能で使用される項目を表します。 |
| [WorksheetCell](./worksheetcell) | ワークシートのセルを表します。 |
| [WorksheetInfo](./worksheetinfo) | シート情報を表します。 |
| [WorksheetRange](./worksheetrange) | ワークシート抽出に使用される範囲を提供します。 |
