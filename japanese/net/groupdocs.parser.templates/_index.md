この名前空間は、ドキュメントデータの解析用テンプレートを作成するクラスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [Template](./template) | ドキュメントページテンプレートを提供します。テンプレートの項目（テキストフィールドやテーブル定義など）を表す[`TemplateItem`](../groupdocs.parser.templates/templateitem) オブジェクトで構成されています。 |
| [TemplateBarcode](./templatebarcode) | テンプレートのバーコードフィールドを提供します。 |
| [TemplateCollection](./templatecollection) | ドキュメント解析テンプレートのコレクションを表します。 |
| [TemplateField](./templatefield) | テンプレートのテキストフィールドを提供します。 |
| [TemplateFixedPosition](./templatefixedposition) | 矩形領域で定義されたテンプレートフィールドの位置を提供します。 |
| [TemplateItem](./templateitem) | テンプレート項目の基底抽象クラスを提供します。 |
| [TemplateLinkedPosition](./templatelinkedposition) | リンクされたフィールドを使用するテンプレートフィールドの位置を提供します。 |
| [TemplateLinkedPositionEdges](./templatelinkedpositionedges) | テキストフィールドが検索されるリンクフィールドのエッジを提供します。[`TemplateLinkedPositionEdges`](../groupdocs.parser.templates/templatelinkedpositionedges) は [`TemplateLinkedPosition`](../groupdocs.parser.templates/templatelinkedposition) クラスで使用されます。 |
| [TemplateOptions](./templateoptions) | テンプレート機能による解析に使用されるオプションを提供します。 |
| [TemplatePosition](./templateposition) | テンプレート位置の基底抽象クラスを提供します。 |
| [TemplateRegexPosition](./templateregexposition) | 正規表現を使用するテンプレートフィールドの位置を提供します。 |
| [TemplateTable](./templatetable) | テンプレートテーブルを提供します。 |
| [TemplateTableLayout](./templatetablelayout) | テーブル位置を定義するために [`TemplateTable`](../groupdocs.parser.templates/templatetable) クラスで使用されるテンプレートテーブルレイアウトを提供します。 |
| [TemplateTableParameters](./templatetableparameters) | テーブル検出アルゴリズム用のパラメータを提供します。 |
