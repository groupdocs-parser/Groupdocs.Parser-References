## SearchOptions.SearchByPages property

検索がページ単位で実行されるかどうかを示す値を取得します。

```csharp
public bool SearchByPages { get; set; }
```

### Property Value

`true` は検索がページ単位で実行される場合、そうでなければ `false` で、検索は [`PageIndex`](../../../groupdocs.parser.data/searchresult/pageindex) プロパティの値を [`SearchResult`](../../../groupdocs.parser.data/searchresult) クラスに含めずに全文書で実行されます。
