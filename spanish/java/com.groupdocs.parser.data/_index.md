El paquete proporciona clases que representan los resultados del análisis.



## Clases

| Clase | Descripción |
| --- | --- |
| [ContainerItem](../com.groupdocs.parser.data/containeritem) | Representa un elemento contenedor como una entidad de archivo Zip, un adjunto de correo electrónico, un elemento de PDF Portfolio, etc. |
| [DocumentData](../com.groupdocs.parser.data/documentdata) | Representa los datos del documento. |
| [DocumentPageData](../com.groupdocs.parser.data/documentpagedata) | Representa los datos de la página del documento. |
| [FieldData](../com.groupdocs.parser.data/fielddata) | Representa datos de campo como un nombre, un índice de página, un valor de campo, etc. |
| [HighlightItem](../com.groupdocs.parser.data/highlightitem) | Representa un resaltado, una parte del texto que normalmente se usa para explicar el contexto del texto encontrado en la funcionalidad de búsqueda. |
| [MetadataItem](../com.groupdocs.parser.data/metadataitem) | Representa un elemento de metadatos que se utiliza en elementos contenedores y en la funcionalidad de extracción de metadatos. |
| [Page](../com.groupdocs.parser.data/page) | Representa la información de la página del documento, como el índice de página y el tamaño de página. |
| [PageArea](../com.groupdocs.parser.data/pagearea) | Representa una clase base abstracta para áreas de página que se utilizan para representar bloques en la página del documento en la funcionalidad de análisis mediante plantillas. |
| [PageBarcodeArea](../com.groupdocs.parser.data/pagebarcodearea) | Representa un área de código de barras de página que se utiliza para representar un valor de código de barras en la funcionalidad de análisis mediante plantillas. |
| [PageGroupArea](../com.groupdocs.parser.data/pagegrouparea) | Representa un grupo de áreas de página que se utiliza para agrupar diferentes tipos de bloques de la página del documento en la funcionalidad de análisis mediante plantillas. |
| [PageHyperlinkArea](../com.groupdocs.parser.data/pagehyperlinkarea) | Representa un área de página que se utiliza para representar un hipervínculo en la página. |
| [PageImageArea](../com.groupdocs.parser.data/pageimagearea) | Representa un área de imagen de página que se utiliza para representar una imagen en la página en la funcionalidad de análisis mediante plantillas o un adjunto de imagen si las imágenes se extraen de correos electrónicos o archivos Zip. |
| [PageTableArea](../com.groupdocs.parser.data/pagetablearea) | Representa un área de tabla de página que se utiliza para representar una tabla en la funcionalidad de análisis mediante plantillas. |
| [PageTableAreaCell](../com.groupdocs.parser.data/pagetableareacell) | Representa una celda de tabla que se utiliza en la clase [PageTableArea](../com.groupdocs.parser.data/pagetablearea). |
| [PageTextArea](../com.groupdocs.parser.data/pagetextarea) | Representa un área de texto de página que se utiliza para representar un valor de texto en la funcionalidad de análisis mediante plantillas o análisis de formularios. |
| [Point](../com.groupdocs.parser.data/point) | Representa un punto. |
| [Rectangle](../com.groupdocs.parser.data/rectangle) | Representa un área rectangular. |
| [SearchResult](../com.groupdocs.parser.data/searchresult) | Representa el resultado de búsqueda en la funcionalidad de búsqueda. |
| [Size](../com.groupdocs.parser.data/size) | Representa un tamaño. |
| [TextReader](../com.groupdocs.parser.data/textreader) | Representa un lector que puede leer una serie secuencial de caracteres. |
| [TextStyle](../com.groupdocs.parser.data/textstyle) | Representa el estilo del texto, como el nombre de la fuente, el tamaño de la fuente, etc. |
| [TocItem](../com.groupdocs.parser.data/tocitem) | Representa el elemento que se utiliza en la funcionalidad de extracción del índice. |
