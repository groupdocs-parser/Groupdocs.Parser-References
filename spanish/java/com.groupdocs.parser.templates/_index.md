El paquete proporciona clases para crear plantillas para el análisis de datos de documentos.



## Clases

| Clase | Descripción |
| --- | --- |
| [Template](../com.groupdocs.parser.templates/template) | Proporciona la plantilla de página del documento. |
| [TemplateBarcode](../com.groupdocs.parser.templates/templatebarcode) | Proporciona el campo de código de barras de la plantilla. |
| [TemplateField](../com.groupdocs.parser.templates/templatefield) | Proporciona el campo de texto de la plantilla. |
| [TemplateFixedPosition](../com.groupdocs.parser.templates/templatefixedposition) | Proporciona una posición de campo de plantilla que se define por el área rectangular. |
| [TemplateItem](../com.groupdocs.parser.templates/templateitem) | Proporciona una clase abstracta base para los elementos de plantilla. |
| [TemplateLinkedPosition](../com.groupdocs.parser.templates/templatelinkedposition) | Proporciona una posición de campo de plantilla que utiliza el campo vinculado. |
| [TemplateLinkedPositionEdges](../com.groupdocs.parser.templates/templatelinkedpositionedges) | Proporciona los bordes del campo vinculado donde se busca el campo de texto. |
| [TemplateOptions](../com.groupdocs.parser.templates/templateoptions) | Proporciona las opciones que se utilizan para el análisis mediante la funcionalidad de plantilla. |
| [TemplatePosition](../com.groupdocs.parser.templates/templateposition) | Proporciona una clase abstracta base para las posiciones de plantilla. |
| [TemplateRegexPosition](../com.groupdocs.parser.templates/templateregexposition) | Proporciona una posición de campo de plantilla que utiliza la expresión regular. |
| [TemplateTable](../com.groupdocs.parser.templates/templatetable) | Proporciona la tabla de plantilla. |
| [TemplateTableLayout](../com.groupdocs.parser.templates/templatetablelayout) | Proporciona el diseño de la tabla de plantilla que es utilizado por la clase [TemplateTable](../com.groupdocs.parser.templates/templatetable) para definir la posición de la tabla. |
| [TemplateTableParameters](../com.groupdocs.parser.templates/templatetableparameters) | Proporciona parámetros para los algoritmos de detección de tablas. |
