Il pacchetto fornisce classi per creare modelli per l'analisi dei dati dei documenti.



## Classi

| Classe | Descrizione |
| --- | --- |
| [Template](../com.groupdocs.parser.templates/template) | Fornisce il modello di pagina del documento. |
| [TemplateBarcode](../com.groupdocs.parser.templates/templatebarcode) | Fornisce il campo barcode del modello. |
| [TemplateField](../com.groupdocs.parser.templates/templatefield) | Fornisce il campo di testo del modello. |
| [TemplateFixedPosition](../com.groupdocs.parser.templates/templatefixedposition) | Fornisce una posizione del campo del modello definita dall'area rettangolare. |
| [TemplateItem](../com.groupdocs.parser.templates/templateitem) | Fornisce una classe astratta base per gli elementi del modello. |
| [TemplateLinkedPosition](../com.groupdocs.parser.templates/templatelinkedposition) | Fornisce una posizione del campo del modello che utilizza il campo collegato. |
| [TemplateLinkedPositionEdges](../com.groupdocs.parser.templates/templatelinkedpositionedges) | Fornisce i bordi del campo collegato dove viene cercato il campo di testo. |
| [TemplateOptions](../com.groupdocs.parser.templates/templateoptions) | Fornisce le opzioni utilizzate per l'analisi tramite la funzionalità del modello. |
| [TemplatePosition](../com.groupdocs.parser.templates/templateposition) | Fornisce una classe astratta base per le posizioni del modello. |
| [TemplateRegexPosition](../com.groupdocs.parser.templates/templateregexposition) | Fornisce una posizione del campo del modello che utilizza l'espressione regolare. |
| [TemplateTable](../com.groupdocs.parser.templates/templatetable) | Fornisce la tabella modello. |
| [TemplateTableLayout](../com.groupdocs.parser.templates/templatetablelayout) | Fornisce il layout della tabella modello che è usato dalla classe [TemplateTable](../com.groupdocs.parser.templates/templatetable) per definire la posizione della tabella. |
| [TemplateTableParameters](../com.groupdocs.parser.templates/templatetableparameters) | Fornisce i parametri per gli algoritmi di rilevamento della tabella. |
