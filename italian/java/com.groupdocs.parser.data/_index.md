Il pacchetto fornisce classi che rappresentano i risultati dell'analisi.



## Classi

| Classe | Descrizione |
| --- | --- |
| [ContainerItem](../com.groupdocs.parser.data/containeritem) | Rappresenta un elemento contenitore come entità di archivio Zip, allegato email, elemento PDF Portfolio e così via. |
| [DocumentData](../com.groupdocs.parser.data/documentdata) | Rappresenta i dati del documento. |
| [DocumentPageData](../com.groupdocs.parser.data/documentpagedata) | Rappresenta i dati della pagina del documento. |
| [FieldData](../com.groupdocs.parser.data/fielddata) | Rappresenta i dati del campo come un nome, un indice di pagina, un valore del campo e così via. |
| [HighlightItem](../com.groupdocs.parser.data/highlightitem) | Rappresenta un evidenziatore, una parte del testo solitamente usata per spiegare il contesto del testo trovato nella funzionalità di ricerca. |
| [MetadataItem](../com.groupdocs.parser.data/metadataitem) | Rappresenta un elemento di metadati che è usato negli elementi contenitore e nella funzionalità di estrazione dei metadati. |
| [Page](../com.groupdocs.parser.data/page) | Rappresenta le informazioni della pagina del documento come l'indice della pagina e le dimensioni della pagina. |
| [PageArea](../com.groupdocs.parser.data/pagearea) | Rappresenta una classe base astratta per le aree della pagina che sono usate per rappresentare blocchi sulla pagina del documento nella funzionalità di parsing tramite modello. |
| [PageBarcodeArea](../com.groupdocs.parser.data/pagebarcodearea) | Rappresenta un'area barcode della pagina che è usata per rappresentare un valore barcode nella funzionalità di parsing tramite modello. |
| [PageGroupArea](../com.groupdocs.parser.data/pagegrouparea) | Rappresenta un gruppo di aree della pagina che è usato per raggruppare diversi tipi di blocchi della pagina del documento nella funzionalità di parsing tramite modello. |
| [PageHyperlinkArea](../com.groupdocs.parser.data/pagehyperlinkarea) | Rappresenta un'area della pagina che è usata per rappresentare un collegamento ipertestuale nella pagina. |
| [PageImageArea](../com.groupdocs.parser.data/pageimagearea) | Rappresenta un'area immagine della pagina che è usata per rappresentare un'immagine nella pagina nella funzionalità di parsing tramite modello o un allegato immagine se le immagini sono estratte da email o archivi Zip. |
| [PageTableArea](../com.groupdocs.parser.data/pagetablearea) | Rappresenta un'area tabella della pagina che è usata per rappresentare una tabella nella funzionalità di parsing tramite modello. |
| [PageTableAreaCell](../com.groupdocs.parser.data/pagetableareacell) | Rappresenta una cella di tabella che è usata nella classe [PageTableArea](../com.groupdocs.parser.data/pagetablearea). |
| [PageTextArea](../com.groupdocs.parser.data/pagetextarea) | Rappresenta un'area di testo della pagina che è usata per rappresentare un valore di testo nella funzionalità di parsing tramite modello o di parsing di modulo. |
| [Point](../com.groupdocs.parser.data/point) | Rappresenta un punto. |
| [Rectangle](../com.groupdocs.parser.data/rectangle) | Rappresenta un'area rettangolare. |
| [SearchResult](../com.groupdocs.parser.data/searchresult) | Rappresenta il risultato della ricerca nella funzionalità di ricerca. |
| [Size](../com.groupdocs.parser.data/size) | Rappresenta una dimensione. |
| [TextReader](../com.groupdocs.parser.data/textreader) | Rappresenta un lettore che può leggere una serie sequenziale di caratteri. |
| [TextStyle](../com.groupdocs.parser.data/textstyle) | Rappresenta lo stile del testo come un nome di carattere, una dimensione del carattere e così via. |
| [TocItem](../com.groupdocs.parser.data/tocitem) | Rappresenta l'elemento utilizzato nella funzionalità di estrazione dell'indice. |
