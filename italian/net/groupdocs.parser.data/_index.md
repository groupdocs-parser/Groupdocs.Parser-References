Il namespace fornisce classi che rappresentano i risultati del parsing.

## Classi

| Classe | Descrizione |
| --- | --- |
| [AnnotationItem](./annotationitem) | Rappresenta un elemento di annotazione utilizzato nella funzionalità di estrazione delle annotazioni. |
| [ContainerItem](./containeritem) | Rappresenta un elemento contenitore come entità di archivio Zip, allegato email, elemento di PDF Portfolio e così via. |
| [DocumentData](./documentdata) | Rappresenta i dati del documento. È composto da oggetti [`FieldData`](../groupdocs.parser.data/fielddata) che contengono i dati dei campi dal documento. |
| [DocumentPageData](./documentpagedata) | Rappresenta i dati della pagina del documento. È composto da oggetti [`FieldData`](../groupdocs.parser.data/fielddata) che contengono i dati dei campi della pagina del documento. |
| [FieldData](./fielddata) | Rappresenta i dati del campo, come un nome, un indice di pagina, un valore del campo e così via. A seconda del campo, il valore può essere un testo, un'immagine, una tabella e così via. |
| [HighlightItem](./highlightitem) | Rappresenta un evidenziatore, una parte del testo solitamente usata per spiegare il contesto del testo trovato nella funzionalità di ricerca. |
| [MetadataItem](./metadataitem) | Rappresenta un elemento di metadati utilizzato negli elementi container e nella funzionalità di estrazione dei metadati. |
| [Page](./page) | Rappresenta le informazioni della pagina del documento, come l'indice della pagina e le dimensioni della pagina. Viene usato per rappresentare la pagina che contiene gli eredi della classe [`PageArea`](../groupdocs.parser.data/pagearea) nella funzionalità di parsing tramite modello. |
| [PageArea](./pagearea) | Rappresenta una classe base astratta per le aree di pagina, utilizzata per rappresentare i blocchi sulla pagina del documento nella funzionalità di parsing tramite modello. |
| [PageBarcodeArea](./pagebarcodearea) | Rappresenta un'area di codice a barre della pagina, utilizzata per rappresentare il valore del codice a barre nella funzionalità di parsing tramite modello. |
| [PageGroupArea](./pagegrouparea) | Rappresenta un gruppo di aree di pagina, utilizzato per raggruppare diversi tipi di blocchi della pagina del documento nella funzionalità di parsing tramite modello. |
| [PageHyperlinkArea](./pagehyperlinkarea) | Rappresenta un'area di pagina utilizzata per rappresentare un collegamento ipertestuale sulla pagina. |
| [PageImageArea](./pageimagearea) | Rappresenta un'area immagine della pagina, utilizzata per rappresentare un'immagine sulla pagina nella funzionalità di parsing tramite modello o un allegato immagine se le immagini vengono estratte da email o archivi Zip. |
| [PageTableArea](./pagetablearea) | Rappresenta un'area tabella della pagina, utilizzata per rappresentare una tabella nella funzionalità di parsing tramite modello. |
| [PageTableAreaCell](./pagetableareacell) | Rappresenta una cella di tabella utilizzata nella classe [`PageTableArea`](../groupdocs.parser.data/pagetablearea). |
| [PageTextArea](./pagetextarea) | Rappresenta un'area di testo della pagina, utilizzata per rappresentare un valore di testo nella funzionalità di parsing tramite modello o di parsing di moduli. |
| [Point](./point) | Rappresenta un punto. |
| [Rectangle](./rectangle) | Rappresenta un'area rettangolare. |
| [SearchResult](./searchresult) | Rappresenta il risultato della ricerca nella funzionalità di ricerca. |
| [Size](./size) | Rappresenta una dimensione. |
| [TextStyle](./textstyle) | Rappresenta lo stile del testo, come il nome del font, la dimensione del font e così via. |
| [TocItem](./tocitem) | Rappresenta l'elemento utilizzato nella funzionalità di estrazione del sommario. |
| [WorksheetCell](./worksheetcell) | Rappresenta una cella del foglio di lavoro. |
| [WorksheetInfo](./worksheetinfo) | Rappresenta le informazioni del foglio. |
| [WorksheetRange](./worksheetrange) | Fornisce l'intervallo utilizzato per l'estrazione del foglio di lavoro. |
