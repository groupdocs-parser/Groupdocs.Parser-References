public IEnumerable<MetadataItem> Metadata { get; }

### Property Value

Una raccolta di oggetti [`MetadataItem`](../../metadataitem); vuota se i metadati non sono impostati.

### Osservazioni

Questi metadati si riferiscono all'elemento contenitore stesso, non a un documento. A seconda del tipo di contenitore i metadati possono contenere i seguenti elementi:

**Email Attachments**

**Name**

**Description**

**content-type**

Il tipo MIME del contenuto dell'allegato.

**ZIP Archives**

**Name**

**Description**

**date**

L'ora e la data in cui il file indicato dalla voce Zip è stato modificato l'ultima volta.

**disposition**

Per rilevare se l'allegato immagine è inline viene utilizzato il metadato 'disposition'. Se è presente, può assumere i valori 'inline' o 'attachment'.

**Outlook Storage**

**Name**

**Description**

**date**

L'ora e la data in cui l'elemento Outlook Storage è stato modificato l'ultima volta.

**email-sender**

Il valore del campo "sender".

**email-to**

Il valore del campo "to".

**subject**

Il valore del campo "subject".
