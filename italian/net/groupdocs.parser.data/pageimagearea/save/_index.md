### Esempi

Il seguente esempio mostra come salvare le immagini su file:

```csharp
// Crea un'istanza della classe Parser
using (Parser parser = new Parser(filePath))
{
    // Estrai immagini dal documento
    IEnumerable<PageImageArea> images = parser.GetImages();
    
    // Verifica se l'estrazione delle immagini è supportata
    if (images == null)
    {
        Console.WriteLine("Page images extraction isn't supported");
        return;
    }

    // Itera sulle immagini

    {
        // Salva l'immagine nel file

    }
}

public void Save(string filePath, ImageOptions options)
```

| Parameter | Type | Descrizione |
| --- | --- | --- |
| filePath | Stringa | Il percorso del file. |
| options | ImageOptions | Le opzioni utilizzate per salvare l'immagine. |

### Esempi

Il seguente esempio mostra come salvare le immagini in file in un formato diverso:

```csharp
// Crea un'istanza della classe Parser
using (Parser parser = new Parser(filePath))
{
    // Estrai immagini dal documento
    IEnumerable<PageImageArea> images = parser.GetImages();
    
    // Verifica se l'estrazione delle immagini è supportata
    if (images == null)
    {
        Console.WriteLine("Page images extraction isn't supported");
        return;
    }

    // Crea le opzioni per salvare le immagini in formato PNG
    ImageOptions options = new ImageOptions(ImageFormat.Png);
    
    // Itera sulle immagini
    foreach (PageImageArea image in images)
    {
        // Salva l'immagine nel file png
        image.Save(Guid.NewGuid().ToString() + ".png", options);
    }
}
```
