## GetImageStream() {#getimagestream}

Restituisce lo stream dell'immagine.

```csharp
public Stream GetImageStream()
```

### Valore di ritorno

Uno stream con l'immagine.

### Esempi

Il seguente esempio mostra come salvare le immagini su file:

```csharp
// Crea un'istanza della classe Parser
using (Parser parser = new Parser(filePath))
{
    // Estrai immagini dal documento
    IEnumerable<PageImageArea> images = parser.GetImages();
    
    // Verifica se l'estrazione delle immagini è supportata
    if (images == null)
    {
        Console.WriteLine("Page images extraction isn't supported");
        return;
    }

    // Itera sulle immagini
    foreach (PageImageArea image in images)
    {
        // Apri lo stream dell'immagine
        using (Stream imageStream = image.GetImageStream())
        {
            // Crea il file per salvare l'immagine
            using (Stream destStream = File.Create(Guid.NewGuid().ToString() + image.FileType.Extension))
            {
                byte[] buffer = new byte[4096];
                int readed = 0;

                do
                {
                    // Leggi i dati dallo stream dell'immagine
                    readed = imageStream.Read(buffer, 0, buffer.Length);

                    if (readed > 0)
                    {
                        // Scrivi i dati sullo stream del file
                        destStream.Write(buffer, 0, readed);
                    }
                }
                while (readed > 0);
            }
        }
    }
}
```

### Esempi

Il seguente esempio mostra come salvare le immagini in file in un formato diverso:

```csharp
// Crea un'istanza della classe Parser
using (Parser parser = new Parser(filePath))
{
    // Estrai immagini dal documento
    IEnumerable<PageImageArea> images = parser.GetImages();
    
    // Verifica se l'estrazione delle immagini è supportata
    if (images == null)
    {
        Console.WriteLine("Page images extraction isn't supported");
        return;
    }

    // Crea le opzioni per salvare le immagini in formato PNG
    ImageOptions options = new ImageOptions(ImageFormat.Png);
    
    // Itera sulle immagini

    {
        // Apri lo stream dell'immagine
        using (Stream imageStream = image.GetImageStream(options))
        {
            // Crea il file per salvare l'immagine
            using (Stream destStream = File.Create(Guid.NewGuid().ToString() + ".png"))
            {
                byte[] buffer = new byte[4096];
                int readed = 0;

                do
                {
                    // Leggi i dati dallo stream dell'immagine
                    readed = imageStream.Read(buffer, 0, buffer.Length);

                    if (readed > 0)
                    {
                        // Scrivi i dati sullo stream del file
                        destStream.Write(buffer, 0, readed);
                    }
                }
                while (readed > 0);
            }
        }
    }
}
```
