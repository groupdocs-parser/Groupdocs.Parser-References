## Parser.GetHighlight method

Estrae un'evidenziazione dal documento.

```csharp
public HighlightItem GetHighlight(int position, bool isDirect, HighlightOptions options)
```

| Parameter | Type | Descrizione |
| --- | --- | --- |
| posizione | Int32 | La posizione iniziale dell'evidenziazione. |
| isDirect | Boolean | Il valore che indica se l'estrazione dell'evidenziazione è diretta. `true` se l'evidenziazione è estratta a destra della *position*; altrimenti, `false`. |
| options | HighlightOptions | Le opzioni di estrazione dell'evidenziazione. |

### Valore di ritorno

Un'istanza della classe [`HighlightItem`](../../../groupdocs.parser.data/highlightitem) che rappresenta l'evidenziazione estratta; `null` se l'estrazione dell'evidenziazione non è supportata.

### Esempi

L'esempio seguente mostra come estrarre un'evidenziazione che contiene 3 parole:

```csharp
// Crea un'istanza della classe Parser
using (Parser parser = new Parser(filePath))
{
    // Estrai un'evidenziazione:
    HighlightItem hl = parser.GetHighlight(2, true, new HighlightOptions(3));
    
    // Verifica se l'estrazione dell'evidenziazione è supportata
    if (hl == null)
    {
        Console.WriteLine("Highlight extraction isn't supported");
        return;
    }
    
    // Stampa un'evidenziazione estratta
    Console.WriteLine(string.Format("At {0}: {1}", hl.Position, hl.Text));
}
```
