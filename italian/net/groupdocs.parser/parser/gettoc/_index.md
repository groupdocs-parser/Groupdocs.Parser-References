## Parser.GetToc method

Estrae un indice dal documento.

```csharp
public IEnumerable<TocItem> GetToc()
```

### Valore di ritorno

Una collezione di elementi dell'indice; `null` se l'estrazione dell'indice non è supportata.

### Esempi

Il seguente esempio mostra come estrarre l'indice da un file CHM:

```csharp
// Crea un'istanza della classe Parser
using (Parser parser = new Parser(filePath))
{
    // Verifica se l'estrazione del testo è supportata
    if (!parser.Features.Text)
    {
        Console.WriteLine("Text extraction isn't supported.");
        return;
    }

    // Verifica se l'estrazione del toc è supportata
    if (!parser.Features.Toc)
    {
        Console.WriteLine("Toc extraction isn't supported.");
        return;
    }
 
    // Ottieni il sommario
    IEnumerable<TocItem> toc = parser.GetToc();
    
    // Itera sugli elementi
    foreach (TocItem i in toc)
    {
        // Stampa il testo dell'indice
        Console.WriteLine(i.Text);
        // Verifica se l'indice della pagina ha un valore
        if (i.PageIndex == null)
        {
            continue;
        }
        // Estrai il testo di una pagina
        using (TextReader reader = parser.GetText(i.PageIndex.Value))
        {
            Console.WriteLine(reader.ReadToEnd());
        }
    }
}
```
