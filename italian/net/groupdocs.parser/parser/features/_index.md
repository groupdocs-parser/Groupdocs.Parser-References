### Esempi

Se la funzionalità non è supportata, il metodo restituisce `null` invece del valore. Alcune operazioni possono richiedere tempo significativo. Quindi non è ottimale chiamare il metodo solo per verificare il supporto della funzionalità. Per questo scopo viene utilizzata la proprietà Features:

```csharp
using(Parser parser = new Parser("doc.zip"))
{
    if(!parser.Features.Text)
    {
        Console.WriteLine("Text extraction isn't supported");
        return;
    }
 
    using(TextReader reader = parser.GetText())
    {
        Console.WriteLine(reader.ReadToEnd());
    }
}
```
