## Parser.ParseForm method

Analizza il modulo del documento.

```csharp
public DocumentData ParseForm()
```

### Valore di ritorno

Un'istanza della classe [`DocumentData`](../../../groupdocs.parser.data/documentdata) che contiene i dati estratti; `null` se l'analisi tramite modello non è supportata.

### Esempi

Il seguente esempio mostra come analizzare una forma del documento:

```csharp
// Crea un'istanza della classe Parser
using (Parser parser = new Parser(filePath))
{
    // Estrai dati da documento PDF
    DocumentData data = parser.ParseForm();
    // Itera sui dati estratti
    for (int i = 0; i<data.Count; i++)
    {
        Console.Write(data[i].Name + ": ");
        PageTextArea area = data[i].PageArea as PageTextArea;
        Console.WriteLine(area == null ? "Not a template field" : area.Text);
    }
}
```
