### Esempi

Il seguente esempio mostra la situazione in cui il documento contiene "Invoice Number INV-12345"; in tal caso il campo del modello può essere definito nel modo seguente:

```csharp
// Crea un campo modello regex con nome "InvoiceNumber"
TemplateField templateField = new TemplateField(
    new TemplateRegexPosition("Invoice Number\\s+[A-Z0-9\\-]+"),
    "InvoiceNumber");
```

In questo caso, come valore, viene estratta l'intera stringa. Per estrarre solo una parte della stringa viene utilizzato il gruppo di espressione regolare "value":

```csharp
// Crea un campo modello regex con nome "InvoiceNumber" con il gruppo "value"
TemplateField templateField = new TemplateField(
    new TemplateRegexPosition("Invoice Number\\s+(?<value>[A-Z0-9\\-]+)"),
    "InvoiceNumber");
```

In questo caso, come valore, viene estratta la stringa "INV-3337".
