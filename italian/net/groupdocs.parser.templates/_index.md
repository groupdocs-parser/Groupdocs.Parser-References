Il namespace fornisce classi per creare modelli per il parsing dei dati dei documenti.

## Classi

| Classe | Descrizione |
| --- | --- |
| [Template](./template) | Fornisce il modello di pagina del documento. È composto da oggetti [`TemplateItem`](../groupdocs.parser.templates/templateitem) che rappresentano gli elementi del modello, come i campi di testo e le definizioni di tabella. |
| [TemplateBarcode](./templatebarcode) | Fornisce il campo barcode del modello. |
| [TemplateCollection](./templatecollection) | Rappresenta una raccolta di modelli di analisi del documento. |
| [TemplateField](./templatefield) | Fornisce il campo di testo del modello. |
| [TemplateFixedPosition](./templatefixedposition) | Fornisce una posizione del campo del modello definita dall'area rettangolare. |
| [TemplateItem](./templateitem) | Fornisce una classe astratta di base per gli elementi del modello. |
| [TemplateLinkedPosition](./templatelinkedposition) | Fornisce una posizione del campo del modello che utilizza il campo collegato. |
| [TemplateLinkedPositionEdges](./templatelinkedpositionedges) | Fornisce i bordi del campo collegato dove viene cercato il campo di testo. [`TemplateLinkedPositionEdges`](../groupdocs.parser.templates/templatelinkedpositionedges) è usato nella classe [`TemplateLinkedPosition`](../groupdocs.parser.templates/templatelinkedposition). |
| [TemplateOptions](./templateoptions) | Fornisce le opzioni utilizzate per l'analisi tramite la funzionalità di modello. |
| [TemplatePosition](./templateposition) | Fornisce una classe astratta di base per le posizioni del modello. |
| [TemplateRegexPosition](./templateregexposition) | Fornisce una posizione del campo del modello che utilizza l'espressione regolare. |
| [TemplateTable](./templatetable) | Fornisce la tabella del modello. |
| [TemplateTableLayout](./templatetablelayout) | Fornisce il layout della tabella del modello che è usato dalla classe [`TemplateTable`](../groupdocs.parser.templates/templatetable) per definire la posizione della tabella. |
| [TemplateTableParameters](./templatetableparameters) | Fornisce parametri per gli algoritmi di rilevamento delle tabelle. |
