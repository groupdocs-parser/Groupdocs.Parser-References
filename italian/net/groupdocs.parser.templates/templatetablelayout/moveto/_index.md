## TemplateTableLayout.MoveTo method

Crea un nuovo layout con le stesse dimensioni, separatori e posizione nel *punto*.

```csharp
public TemplateTableLayout MoveTo(Point point)
```

| Parameter | Type | Descrizione |
| --- | --- | --- |
| point | Point | La posizione del nuovo layout. |

### Valore di ritorno

Un nuovo layout con le stesse dimensioni, separatori e posizione nel *punto*.

### Esempi

Questa funzionalità consente di spostare il layout della tabella.

Ad esempio, un documento ha tabelle in ogni pagina (o un insieme di documenti con una tabella nella pagina). Queste tabelle differiscono per posizione e contenuto, ma hanno le stesse colonne e righe. In questo caso un utente può definire l'oggetto [`TemplateTableLayout`](../../templatetablelayout) a `(0, 0)` una volta e poi spostarlo nella posizione della tabella specifica.

Se la posizione della tabella dipende da un altro oggetto della pagina, un utente può definire l'oggetto [`TemplateTableLayout`](../../templatetablelayout) basato sul documento modello e poi spostarlo secondo un oggetto di ancoraggio. Ad esempio, se questa è una tabella di riepilogo ed è seguita da una tabella di dettagli (che può contenere un numero diverso di righe). In questo caso un utente può definire l'oggetto [`TemplateTableLayout`](../../templatetablelayout) sul documento modello (con il rettangolo della tabella di dettagli noto) e poi spostare l'oggetto [`TemplateTableLayout`](../../templatetablelayout) secondo la differenza del rettangolo della tabella di dettagli tra modello e documento reale.

Il metodo `MoveTo` restituisce una copia dell'oggetto corrente. Un utente può passare qualsiasi coordinata (anche negative - in tal caso il layout verrà spostato a sinistra/alto).

```csharp
// Crea un layout di tabella
TemplateTableLayout layout = new TemplateTableLayout(
    new double[] { 0, 25, 150, 180, 230 },
    new double[] { 0, 15, 30, 45, 60, 75 });

// Stampa un rettangolo
Rectangle rect = layout.Rectangle;

// Stampa: pos: (0, 0) size: (230, 75)
Console.WriteLine(string.Format("pos: ({0}, {1}) size: ({2}, {3})", rect.Left, rect.Top, rect.Size.Width, rect.Size.Height));

// Sposta il layout nella posizione della tabella specifica
TemplateTableLayout movedLayout = layout.MoveTo(new Point(315, 250));

// Assicurati che i primi separatori siano spostati:
Console.WriteLine(movedLayout.VerticalSeparators[0]); // prints: 315
Console.WriteLine(movedLayout.HorizontalSeparators[0]); // prints: 250

Rectangle movedRect = movedLayout.Rectangle;

// Stampa: pos: (315, 250) size: (230, 75)
Console.WriteLine(string.Format("pos: ({0}, {1}) size: ({2}, {3})", movedRect.Left, movedRect.Top, movedRect.Size.Width, movedRect.Size.Height));

// L'oggetto movedLayout è una copia dell'oggetto layout, quindi possiamo regolare i separatori senza influire sul layout originale:
movedLayout.HorizontalSeparators.Add(90);

Console.WriteLine(movedLayout.HorizontalSeparators.Count); // prints: 7
Console.WriteLine(layout.HorizontalSeparators.Count); // prints: 6
```
