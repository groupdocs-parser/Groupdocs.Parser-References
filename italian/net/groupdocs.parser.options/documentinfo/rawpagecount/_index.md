## DocumentInfo.RawPageCount property

Restituisce il numero totale di pagine grezze del documento.

```csharp
public int RawPageCount { get; }
```

### Property Value

Un valore intero che rappresenta il numero totale di pagine grezze.

### Osservazioni

Utilizza la proprietà `RawPageCount` invece della proprietà [`PageCount`](../pagecount) per l'estrazione del testo grezzo. Alcuni documenti hanno numeri di pagina diversi nelle modalità di estrazione del testo accurata e grezza. La proprietà [`PageCount`](../pagecount) può eseguire calcoli aggiuntivi che influiscono sulla velocità di estrazione del testo in modalità grezza.
