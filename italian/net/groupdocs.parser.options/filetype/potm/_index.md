## FileType.POTM field

I file con estensione POTM sono modelli di Microsoft PowerPoint con supporto per macro. I file POTM sono creati con PowerPoint 2007 o versioni successive e contengono impostazioni predefinite che possono essere usate per creare ulteriori file di presentazione.
