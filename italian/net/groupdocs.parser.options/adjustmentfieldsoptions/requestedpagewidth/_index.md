## AdjustmentFieldsOptions.RequestedPageWidth property

Ottiene o imposta il valore della larghezza della pagina richiesta. Questo valore è usato per scalare i campi del modello alla dimensione della pagina desiderata. Il valore predefinito è `null`, il che significa che non viene effettuata alcuna scalatura.

```csharp
public double? RequestedPageWidth { get; set; }
```

### Property Value
