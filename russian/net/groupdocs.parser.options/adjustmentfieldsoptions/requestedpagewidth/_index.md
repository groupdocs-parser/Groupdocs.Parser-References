## AdjustmentFieldsOptions.RequestedPageWidth property

Получает или задает запрашиваемое значение ширины страницы. Это значение используется для масштабирования полей шаблона до требуемого размера страницы. Значение по умолчанию — `null`, что означает отсутствие масштабирования.

```csharp
public double? RequestedPageWidth { get; set; }
```

### Property Value

Запрашиваемое значение ширины страницы.
