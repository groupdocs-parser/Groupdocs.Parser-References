## FileTypeDetectionMode enumeration

Определяет режим обнаружения типа файла.

```csharp
public enum FileTypeDetectionMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Default | `0` | Тип файла определяется по расширению файла; если расширение не распознано, тип файла определяется по содержимому файла. |
| Extension | `1` | Тип файла определяется только по расширению файла. |
| Content | `2` | Тип файла определяется только по содержимому файла. |
