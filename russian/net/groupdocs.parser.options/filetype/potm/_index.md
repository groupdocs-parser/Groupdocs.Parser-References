## FileType.POTM field

Файлы с расширением POTM — это шаблоны Microsoft PowerPoint с поддержкой макросов. Файлы POTM создаются в PowerPoint 2007 и более новых версиях и содержат настройки по умолчанию, которые можно использовать для создания последующих презентаций. Узнайте больше о этом формате файла [здесь](https://wiki.fileformat.com/presentation/potm/).
