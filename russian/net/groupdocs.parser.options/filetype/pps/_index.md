## FileType.PPS field

PPS, PowerPoint Slide Show, файлы создаются с помощью Microsoft PowerPoint для показа слайдов. Чтение и создание файлов PPS поддерживается Microsoft PowerPoint 97‑2003. Узнайте больше о этом формате файла [здесь](https://wiki.fileformat.com/presentation/pps/).
