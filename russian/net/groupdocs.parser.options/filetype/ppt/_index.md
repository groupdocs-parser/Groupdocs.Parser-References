## FileType.PPT field

Файл с расширением PPT представляет файл PowerPoint, который состоит из набора слайдов для отображения в виде слайд-шоу. Он определяет двоичный формат файла, используемый Microsoft PowerPoint 97-2003. Узнайте больше об этом формате файла [здесь](https://wiki.fileformat.com/presentation/ppt/).
