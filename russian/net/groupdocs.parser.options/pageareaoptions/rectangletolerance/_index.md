## PageAreaOptions.RectangleTolerance property

Получает размер границы, игнорируемой при захвате прямоугольной областью. Он измеряется как доля высоты текстового элемента.

```csharp
public double RectangleTolerance { get; set; }
```

### Возвращаемое значение

Дробное значение от 0 (без границы) до 1 (игнорировать весь элемент).
