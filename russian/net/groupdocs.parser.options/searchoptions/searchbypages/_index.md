## SearchOptions.SearchByPages property

Получает значение, указывающее, выполняется ли поиск по страницам.

```csharp
public bool SearchByPages { get; set; }
```

### Property Value

`true`, если поиск выполняется по страницам; иначе `false`, и поиск выполняется по всему документу без включения значения свойства [`PageIndex`](../../../groupdocs.parser.data/searchresult/pageindex) в класс [`SearchResult`](../../../groupdocs.parser.data/searchresult).
