## HighlightOptions.IsLineLimited property

Получает значение, указывающее, ограничено ли извлечение выделения началом (или концом) строки текста.

```csharp
public bool IsLineLimited { get; set; }
```

### Возвращаемое значение

`true`, если выделение ограничено началом (или концом) строки текста; иначе `false`.
