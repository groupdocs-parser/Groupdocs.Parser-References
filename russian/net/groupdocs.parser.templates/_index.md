Пространство имён предоставляет классы для создания шаблонов разбора данных документов.

## Классы

| Класс | Описание |
| --- | --- |
| [Template](./template) | Предоставляет шаблон страницы документа. Он состоит из объектов [`TemplateItem`](../groupdocs.parser.templates/templateitem), которые представляют элементы шаблона, такие как текстовое поле и определения таблиц. |
| [TemplateBarcode](./templatebarcode) | Предоставляет поле штрих‑кода шаблона. |
| [TemplateCollection](./templatecollection) | Представляет коллекцию шаблонов парсинга документов. |
| [TemplateField](./templatefield) | Предоставляет текстовое поле шаблона. |
| [TemplateFixedPosition](./templatefixedposition) | Предоставляет позицию поля шаблона, определяемую прямоугольной областью. |
| [TemplateItem](./templateitem) | Предоставляет базовый абстрактный класс для элементов шаблона. |
| [TemplateLinkedPosition](./templatelinkedposition) | Предоставляет позицию поля шаблона, использующую связанное поле. |
| [TemplateLinkedPositionEdges](./templatelinkedpositionedges) | Предоставляет границы связанного поля, где ищется текстовое поле. [`TemplateLinkedPositionEdges`](../groupdocs.parser.templates/templatelinkedpositionedges) используется в классе [`TemplateLinkedPosition`](../groupdocs.parser.templates/templatelinkedposition). |
| [TemplateOptions](./templateoptions) | Предоставляет параметры, используемые для парсинга с помощью шаблонов. |
| [TemplatePosition](./templateposition) | Предоставляет базовый абстрактный класс для позиций шаблона. |
| [TemplateRegexPosition](./templateregexposition) | Предоставляет позицию поля шаблона, использующую регулярное выражение. |
| [TemplateTable](./templatetable) | Предоставляет таблицу шаблона. |
| [TemplateTableLayout](./templatetablelayout) | Предоставляет макет таблицы шаблона, который используется классом [`TemplateTable`](../groupdocs.parser.templates/templatetable) для определения позиции таблицы. |
| [TemplateTableParameters](./templatetableparameters) | Предоставляет параметры для алгоритмов обнаружения таблиц. |
