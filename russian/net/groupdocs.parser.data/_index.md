Пространство имён предоставляет классы, представляющие результаты разбора.

## Классы

| Класс | Описание |
| --- | --- |
| [AnnotationItem](./annotationitem) | Представляет элемент аннотации, используемый в функции извлечения аннотаций. |
| [ContainerItem](./containeritem) | Представляет элемент контейнера, такой как объект Zip‑архива, вложение электронной почты, элемент PDF‑портфолио и т.д. |
| [DocumentData](./documentdata) | Представляет данные документа. Состоит из объектов [`FieldData`](../groupdocs.parser.data/fielddata), содержащих данные полей из документа. |
| [DocumentPageData](./documentpagedata) | Представляет данные страницы документа. Состоит из объектов [`FieldData`](../groupdocs.parser.data/fielddata), содержащих данные полей из страницы документа. |
| [FieldData](./fielddata) | Представляет данные поля, такие как имя, индекс страницы, значение поля и т.д. В зависимости от поля значение может быть текстом, изображением, таблицей и т.п. |
| [HighlightItem](./highlightitem) | Представляет выделение, часть текста, обычно используемую для пояснения контекста найденного текста в функции поиска. |
| [MetadataItem](./metadataitem) | Представляет элемент метаданных, используемый в контейнерных элементах и функции извлечения метаданных. |
| [Page](./page) | Представляет информацию о странице документа, такую как индекс страницы и размер страницы. Используется для представления страницы, содержащей наследников класса [`PageArea`](../groupdocs.parser.data/pagearea) в функции парсинга по шаблону. |
| [PageArea](./pagearea) | Представляет абстрактный базовый класс для областей страницы, которые используются для представления блоков на странице документа в функции парсинга по шаблону. |
| [PageBarcodeArea](./pagebarcodearea) | Представляет область штрихкода на странице, используемую для представления значения штрихкода в функции парсинга по шаблону. |
| [PageGroupArea](./pagegrouparea) | Представляет группу областей страницы, используемую для группировки различных типов блоков страницы документа в функции парсинга по шаблону. |
| [PageHyperlinkArea](./pagehyperlinkarea) | Представляет область страницы, используемую для представления гиперссылки на странице. |
| [PageImageArea](./pageimagearea) | Представляет область изображения на странице, используемую для представления изображения на странице в функции парсинга по шаблону или вложения изображения, если изображения извлекаются из электронных писем или ZIP‑архивов. |
| [PageTableArea](./pagetablearea) | Представляет область таблицы на странице, используемую для представления таблицы в функции парсинга по шаблону. |
| [PageTableAreaCell](./pagetableareacell) | Представляет ячейку таблицы, используемую в классе [`PageTableArea`](../groupdocs.parser.data/pagetablearea). |
| [PageTextArea](./pagetextarea) | Представляет текстовую область страницы, используемую для представления текстового значения в функции парсинга по шаблону или парсинга форм. |
| [Point](./point) | Представляет точку. |
| [Rectangle](./rectangle) | Представляет прямоугольную область. |
| [SearchResult](./searchresult) | Представляет результат поиска в функции поиска. |
| [Size](./size) | Представляет размер. |
| [TextStyle](./textstyle) | Представляет стиль текста, такой как название шрифта, размер шрифта и т.д. |
| [TocItem](./tocitem) | Представляет элемент, используемый в функции извлечения оглавления. |
| [WorksheetCell](./worksheetcell) | Представляет ячейку листа. |
| [WorksheetInfo](./worksheetinfo) | Представляет информацию о листе. |
| [WorksheetRange](./worksheetrange) | Предоставляет диапазон, используемый для извлечения листа. |
