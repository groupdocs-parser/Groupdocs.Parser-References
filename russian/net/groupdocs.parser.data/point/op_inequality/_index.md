## Point Inequality operator

Определяет, не являются ли два объекта [`Point`](../../point) одинаковыми.

```csharp
public static bool operator !=(Point left, Point right)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| left | Point | Левый объект [`Point`](../../point). |
| right | Point | Правый объект [`Point`](../../point). |

### Возвращаемое значение

```csharp
true
```

если оба объекта [`Point`](../../point) не одинаковы; иначе,

```csharp
false
```
