Пакет предоставляет различные классы исключений.



## Классы

| Класс | Описание |
| --- | --- |
| [CorruptedDocumentException](../com.groupdocs.parser.exceptions/corrupteddocumentexception) | Выбрасывается при загрузке документа, когда документ повреждён. |
| [GroupDocsParserException](../com.groupdocs.parser.exceptions/groupdocsparserexception) | Представляет ошибки, которые возникают во время выполнения приложения. |
| [InvalidPasswordException](../com.groupdocs.parser.exceptions/invalidpasswordexception) | Выбрасывается, если документ зашифрован паролем, и указанный при открытии документа пароль неверен или отсутствует. |
| [UnsupportedDocumentFormatException](../com.groupdocs.parser.exceptions/unsupporteddocumentformatexception) | Выбрасывается при загрузке документа, когда формат документа не распознан или не поддерживается. |
