Пакет предоставляет классы, представляющие результаты разбора.



## Классы

| Класс | Описание |
| --- | --- |
| [ContainerItem](../com.groupdocs.parser.data/containeritem) | Представляет элемент контейнера, такой как объект Zip-архива, вложение электронной почты, элемент PDF‑портфеля и т.д. |
| [DocumentData](../com.groupdocs.parser.data/documentdata) | Представляет данные документа. |
| [DocumentPageData](../com.groupdocs.parser.data/documentpagedata) | Представляет данные страницы документа. |
| [FieldData](../com.groupdocs.parser.data/fielddata) | Представляет данные поля, такие как имя, индекс страницы, значение поля и т.д. |
| [HighlightItem](../com.groupdocs.parser.data/highlightitem) | Представляет выделение, часть текста, обычно используемую для объяснения контекста найденного текста в функции поиска. |
| [MetadataItem](../com.groupdocs.parser.data/metadataitem) | Представляет элемент метаданных, который используется в элементах контейнера и функции извлечения метаданных. |
| [Page](../com.groupdocs.parser.data/page) | Представляет информацию о странице документа, такую как индекс страницы и размер страницы. |
| [PageArea](../com.groupdocs.parser.data/pagearea) | Представляет абстрактный базовый класс для областей страницы, которые используются для представления блоков на странице документа в функции разбора по шаблону. |
| [PageBarcodeArea](../com.groupdocs.parser.data/pagebarcodearea) | Представляет область штрих‑кода на странице, которая используется для представления значения штрих‑кода в функции разбора по шаблону. |
| [PageGroupArea](../com.groupdocs.parser.data/pagegrouparea) | Представляет группу областей страницы, которая используется для группировки разных типов блоков страницы документа в функции разбора по шаблону. |
| [PageHyperlinkArea](../com.groupdocs.parser.data/pagehyperlinkarea) | Представляет область страницы, которая используется для представления гиперссылки на странице. |
| [PageImageArea](../com.groupdocs.parser.data/pageimagearea) | Представляет область изображения на странице, которая используется для представления изображения на странице в функции разбора по шаблону или вложения изображения, если изображения извлекаются из электронных писем или Zip‑архивов. |
| [PageTableArea](../com.groupdocs.parser.data/pagetablearea) | Представляет область таблицы на странице, которая используется для представления таблицы в функции разбора по шаблону. |
| [PageTableAreaCell](../com.groupdocs.parser.data/pagetableareacell) | Представляет ячейку таблицы, которая используется в классе [PageTableArea](../com.groupdocs.parser.data/pagetablearea). |
| [PageTextArea](../com.groupdocs.parser.data/pagetextarea) | Представляет текстовую область страницы, которая используется для представления текстового значения в функции разбора по шаблону или разбора форм. |
| [Point](../com.groupdocs.parser.data/point) | Представляет точку. |
| [Rectangle](../com.groupdocs.parser.data/rectangle) | Представляет прямоугольную область. |
| [SearchResult](../com.groupdocs.parser.data/searchresult) | Представляет результат поиска в функции поиска. |
| [Size](../com.groupdocs.parser.data/size) | Представляет размер. |
| [TextReader](../com.groupdocs.parser.data/textreader) | Представляет читатель, который может последовательно считывать символы. |
| [TextStyle](../com.groupdocs.parser.data/textstyle) | Представляет стиль текста, такой как название шрифта, размер шрифта и т.д. |
| [TocItem](../com.groupdocs.parser.data/tocitem) | Представляет элемент, который используется в функции извлечения оглавления. |
