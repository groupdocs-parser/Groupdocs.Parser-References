Пакет предоставляет классы для создания шаблонов разбора данных документов.



## Классы

| Класс | Описание |
| --- | --- |
| [Template](../com.groupdocs.parser.templates/template) | Предоставляет шаблон страницы документа. |
| [TemplateBarcode](../com.groupdocs.parser.templates/templatebarcode) | Предоставляет поле штрихкода шаблона. |
| [TemplateField](../com.groupdocs.parser.templates/templatefield) | Предоставляет текстовое поле шаблона. |
| [TemplateFixedPosition](../com.groupdocs.parser.templates/templatefixedposition) | Предоставляет позицию поля шаблона, определяемую прямоугольной областью. |
| [TemplateItem](../com.groupdocs.parser.templates/templateitem) | Предоставляет базовый абстрактный класс для элементов шаблона. |
| [TemplateLinkedPosition](../com.groupdocs.parser.templates/templatelinkedposition) | Предоставляет позицию поля шаблона, использующую связанное поле. |
| [TemplateLinkedPositionEdges](../com.groupdocs.parser.templates/templatelinkedpositionedges) | Предоставляет границы связанного поля, где ищется текстовое поле. |
| [TemplateOptions](../com.groupdocs.parser.templates/templateoptions) | Предоставляет параметры, используемые для парсинга с помощью функциональности шаблонов. |
| [TemplatePosition](../com.groupdocs.parser.templates/templateposition) | Предоставляет базовый абстрактный класс для позиций шаблона. |
| [TemplateRegexPosition](../com.groupdocs.parser.templates/templateregexposition) | Предоставляет позицию поля шаблона, использующую регулярное выражение. |
| [TemplateTable](../com.groupdocs.parser.templates/templatetable) | Предоставляет таблицу шаблона. |
| [TemplateTableLayout](../com.groupdocs.parser.templates/templatetablelayout) | Предоставляет макет таблицы шаблона, который используется классом [TemplateTable](../com.groupdocs.parser.templates/templatetable) для определения положения таблицы. |
| [TemplateTableParameters](../com.groupdocs.parser.templates/templatetableparameters) | Предоставляет параметры для алгоритмов обнаружения таблиц. |
