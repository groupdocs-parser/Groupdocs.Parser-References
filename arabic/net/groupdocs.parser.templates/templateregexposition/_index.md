### أمثلة

المثال التالي يوضح الحالة إذا كان المستند يحتوي على "Invoice Number INV-12345" ثم يمكن تعريف حقل القالب بالطريقة التالية:

```csharp
// إنشاء حقل قالب regex بالاسم "InvoiceNumber"
TemplateField templateField = new TemplateField(
    new TemplateRegexPosition("Invoice Number\\s+[A-Z0-9\\-]+"),
    "InvoiceNumber");
```

في هذه الحالة يتم استخراج السلسلة بالكامل كقيمة. لاستخراج جزء فقط من السلسلة يتم استخدام مجموعة التعبير النمطي "value":

```csharp
// إنشاء حقل قالب regex بالاسم "InvoiceNumber" مع مجموعة "value"
TemplateField templateField = new TemplateField(
    new TemplateRegexPosition("Invoice Number\\s+(?<value>[A-Z0-9\\-]+)"),
    "InvoiceNumber");
```

في هذه الحالة يتم استخراج السلسلة "INV-3337" كقيمة.
