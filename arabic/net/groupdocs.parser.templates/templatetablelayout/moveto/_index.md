## TemplateTableLayout.MoveTo method

ينشئ تخطيطًا جديدًا بنفس الحجم والفواصل والموضع في *النقطة*.

```csharp
public TemplateTableLayout MoveTo(Point point)
```

| Parameter | Type | الوصف |
| --- | --- | --- |
| نقطة | Point | موضع التخطيط الجديد. |

### قيمة الإرجاع

تخطيط جديد بنفس الحجم، والفواصل، والموضع في *point*.

### أمثلة

تتيح هذه الوظيفة نقل تخطيط الجدول.

على سبيل المثال، يحتوي المستند على جداول في كل صفحة (أو مجموعة من المستندات تحتوي على جدول في الصفحة). تختلف هذه الجداول في الموقع والمحتوى، لكنها تحتوي على نفس الأعمدة والصفوف. في هذه الحالة يمكن للمستخدم تعريف كائن [`TemplateTableLayout`](../../templatetablelayout) عند `(0, 0)` مرة واحدة ثم نقله إلى موقع الجدول المحدد.

إذا كان موقع الجدول يعتمد على كائن آخر في الصفحة، يمكن للمستخدم تعريف كائن [`TemplateTableLayout`](../../templatetablelayout) بناءً على مستند القالب ثم نقله وفقًا لكائن مرساة. على سبيل المثال، إذا كان هذا جدول ملخص ويتبعه جدول تفاصيل (يمكن أن يحتوي على عدد مختلف من الصفوف). في هذه الحالة يمكن للمستخدم تعريف كائن [`TemplateTableLayout`](../../templatetablelayout) في مستند القالب (مع مستطيل جدول التفاصيل المعروف) ثم نقل كائن [`TemplateTableLayout`](../../templatetablelayout) وفقًا لاختلاف مستطيل جدول التفاصيل بين القالب والمستند الحقيقي.

طريقة `MoveTo` تُعيد نسخة من الكائن الحالي. يمكن للمستخدم تمرير أي إحداثيات (حتى السالبة - حينها سيتم نقل التخطيط إلى اليسار/الأعلى).

```csharp
// إنشاء تخطيط جدول
TemplateTableLayout layout = new TemplateTableLayout(
    new double[] { 0, 25, 150, 180, 230 },
    new double[] { 0, 15, 30, 45, 60, 75 });

// طباعة مستطيل
Rectangle rect = layout.Rectangle;

// يطبع: الموضع: (0, 0) الحجم: (230, 75)
Console.WriteLine(string.Format("pos: ({0}, {1}) size: ({2}, {3})", rect.Left, rect.Top, rect.Size.Width, rect.Size.Height));

// نقل التخطيط إلى موقع الجدول المحدد
TemplateTableLayout movedLayout = layout.MoveTo(new Point(315, 250));

// تأكد من أن الفواصل الأولى قد تم نقلها:
Console.WriteLine(movedLayout.VerticalSeparators[0]); // prints: 315
Console.WriteLine(movedLayout.HorizontalSeparators[0]); // prints: 250

Rectangle movedRect = movedLayout.Rectangle;

// يطبع: الموضع: (315, 250) الحجم: (230, 75)
Console.WriteLine(string.Format("pos: ({0}, {1}) size: ({2}, {3})", movedRect.Left, movedRect.Top, movedRect.Size.Width, movedRect.Size.Height));

// كائن movedLayout هو نسخة من كائن layout، وبالتالي يمكننا تعديل الفواصل دون التأثير على التخطيط الأصلي:
movedLayout.HorizontalSeparators.Add(90);

Console.WriteLine(movedLayout.HorizontalSeparators.Count); // prints: 7
Console.WriteLine(layout.HorizontalSeparators.Count); // prints: 6
```
