## TocItem.ExtractText method

يستخرج نصًا من المستند الذي يشير إليه كائن [`TocItem`](../../tocitem).

```csharp
public virtual TextReader ExtractText()
```

### قيمة الإرجاع

مثال من فئة TextReader يحتوي على النص المستخرج.

### أمثلة

المثال التالي يوضح كيفية استخراج نص بواسطة عنصر من جدول المحتويات:

```csharp
// إنشاء مثال من فئة Parser
using (Parser parser = new Parser(Constants.SampleDocxWithToc))
{
    // احصل على جدول المحتويات
    IEnumerable<TocItem> tocItems = parser.GetToc();
    // تحقق مما إذا كان استخراج toc مدعومًا
    if (tocItems == null)
    {
        Console.WriteLine("Table of contents extraction isn't supported");
    }
    // التكرار عبر العناصر
    foreach (TocItem tocItem in tocItems)
    {
        // اطبع نص الفصل
        using (TextReader reader = tocItem.ExtractText())
        {
            Console.WriteLine("----");
            Console.WriteLine(reader.ReadToEnd());
        }
    }
}
```
