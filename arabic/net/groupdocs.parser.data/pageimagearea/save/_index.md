### أمثلة

المثال التالي يوضح كيفية حفظ الصور إلى ملفات بصيغة مختلفة:

```csharp
// إنشاء مثال من فئة Parser
using (Parser parser = new Parser(filePath))
{
    // استخراج الصور من المستند
    IEnumerable<PageImageArea> images = parser.GetImages();
    
    // التحقق مما إذا كان استخراج الصور مدعومًا
    if (images == null)
    {
        Console.WriteLine("Page images extraction isn't supported");
        return;
    }

    // أنشئ الخيارات لحفظ الصور بصيغة PNG
    ImageOptions options = new ImageOptions(ImageFormat.Png);
    
    // التكرار عبر الصور
    foreach (PageImageArea image in images)
    {
        // احفظ الصورة إلى ملف PNG
        image.Save(Guid.NewGuid().ToString() + ".png", options);
    }
}
```
