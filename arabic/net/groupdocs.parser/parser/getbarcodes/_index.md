## GetBarcodes() {#getbarcodes}

يستخرج الرموز الشريطية من المستند.

```csharp
public IEnumerable<PageBarcodeArea> GetBarcodes()
```

### قيمة الإرجاع

مجموعة من كائنات [`PageBarcodeArea`](../../../groupdocs.parser.data/pagebarcodearea)؛ `null` إذا لم يكن استخراج الباركود مدعومًا.

### أمثلة

المثال التالي يوضح كيفية استخراج الباركودات من مستند:

```csharp
// إنشاء مثال من فئة Parser
using (Parser parser = new Parser(filePath))
{
    // استخراج الباركودات من المستند.
    IEnumerable<PageBarcodeArea> barcodes = parser.GetBarcodes();

    // التكرار عبر الباركودات
    foreach(PageBarcodeArea barcode in barcodes)
    {
        // طباعة فهرس الصفحة
        Console.WriteLine("Page: " + barcode.Page.Index.ToString());
        // طباعة قيمة الباركود
        Console.WriteLine("Value: " + barcode.Value);
    }
}
```

```csharp

{
    // إنشاء الخيارات المستخدمة لاستخراج الباركودات

    // استخراج الباركودات من الزاوية العليا اليمنى.

    // التكرار عبر الباركودات
    foreach (PageBarcodeArea barcode in barcodes)
    {
        // طباعة فهرس الصفحة
        Console.WriteLine("Page: " + barcode.Page.Index.ToString());
        // طباعة قيمة الباركود
        Console.WriteLine("Value: " + barcode.Value);
    }
}
```
