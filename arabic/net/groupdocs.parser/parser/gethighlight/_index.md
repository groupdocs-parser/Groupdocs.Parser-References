## Parser.GetHighlight method

```csharp
public HighlightItem GetHighlight(int position, bool isDirect, HighlightOptions options)
```

| Parameter | Type | الوصف |

| الموضع | Int32 | موضع البداية للتمييز. |
| isDirect | Boolean | القيمة التي تشير إلى ما إذا كان استخراج التمييز مباشرًا. `true` إذا تم استخراج التمييز من يمين *position*؛ وإلا `false`. |
| options | HighlightOptions | خيارات استخراج التمييز. |

### قيمة الإرجاع

مثال من فئة [`HighlightItem`](../../../groupdocs.parser.data/highlightitem) التي تمثل التمييز المستخرج؛ `null` إذا لم يكن استخراج التمييز مدعومًا.

### أمثلة

المثال التالي يوضح كيفية استخراج تمييز يحتوي على 3 كلمات:

```csharp
// إنشاء مثال من فئة Parser
using (Parser parser = new Parser(filePath))
{
    // استخراج تمييز:
    HighlightItem hl = parser.GetHighlight(2, true, new HighlightOptions(3));
    
    // تحقق مما إذا كان استخراج التمييز مدعومًا
    if (hl == null)
    {
        Console.WriteLine("Highlight extraction isn't supported");
        return;
    }
    
    // طباعة تمييز مستخرج
    Console.WriteLine(string.Format("At {0}: {1}", hl.Position, hl.Text));
}
```
