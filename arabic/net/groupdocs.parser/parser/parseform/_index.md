## Parser.ParseForm method

### قيمة الإرجاع

مثيل من فئة [`DocumentData`](../../../groupdocs.parser.data/documentdata) التي تحتوي على البيانات المستخرجة؛ `null` إذا لم يكن التحليل باستخدام القالب مدعومًا.

### أمثلة

المثال التالي يوضح كيفية تحليل نموذج من المستند:

```csharp
// إنشاء مثال من فئة Parser
using (Parser parser = new Parser(filePath))
{
    // استخراج البيانات من مستند PDF
    DocumentData data = parser.ParseForm();
    // التكرار عبر البيانات المستخرجة
    for (int i = 0; i<data.Count; i++)
    {
        Console.Write(data[i].Name + ": ");
        PageTextArea area = data[i].PageArea as PageTextArea;
        Console.WriteLine(area == null ? "Not a template field" : area.Text);
    }
}
```
