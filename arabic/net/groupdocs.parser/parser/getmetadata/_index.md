## Parser.GetMetadata method

يستخرج البيانات الوصفية من المستند.

```csharp
public IEnumerable<MetadataItem> GetMetadata()
```

### قيمة الإرجاع

مجموعة من عناصر البيانات الوصفية؛ `null` إذا لم يكن استخراج البيانات الوصفية مدعومًا.

### أمثلة

المثال التالي يوضح كيفية استخراج البيانات الوصفية من مستند:

```csharp
// إنشاء مثال من فئة Parser
using(Parser parser = new Parser(filePath))
{
    // استخراج البيانات الوصفية من المستند
    IEnumerable<MetadataItem> metadata = parser.GetMetadata();
    // تحقق مما إذا كان استخراج البيانات الوصفية مدعومًا
    if(metadata == null)
    {
        Console.WriteLine("Metatada extraction isn't supported");
    }
 
    // تكرار عبر عناصر البيانات الوصفية
    foreach(MetadataItem item in metadata)
    {
        // اطبع اسم العنصر وقيمته
        Console.WriteLine(string.Format("{0}: {1}", item.Name, item.Value));
    }
}
```
