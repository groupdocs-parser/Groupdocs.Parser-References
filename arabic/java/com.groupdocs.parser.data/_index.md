توفر الحزمة فئات تمثل نتائج التحليل.



## الفئات

| الفئة | الوصف |
| --- | --- |
| [ContainerItem](../com.groupdocs.parser.data/containeritem) | يمثل عنصر حاوية مثل كيان أرشيف Zip، مرفق بريد إلكتروني، عنصر PDF Portfolio وما إلى ذلك. |
| [DocumentData](../com.groupdocs.parser.data/documentdata) | يمثل بيانات المستند. |
| [DocumentPageData](../com.groupdocs.parser.data/documentpagedata) | يمثل بيانات صفحة المستند. |
| [FieldData](../com.groupdocs.parser.data/fielddata) | يمثل بيانات الحقل مثل الاسم، فهرس الصفحة، قيمة الحقل وما إلى ذلك. |
| [HighlightItem](../com.groupdocs.parser.data/highlightitem) | يمثل تمييزًا، وهو جزء من النص يُستخدم عادةً لشرح سياق النص الموجود في وظيفة البحث. |
| [MetadataItem](../com.groupdocs.parser.data/metadataitem) | يمثل عنصر بيانات تعريف يُستخدم في عناصر الحاوية ووظيفة استخراج البيانات التعريفية. |
| [Page](../com.groupdocs.parser.data/page) | يمثل معلومات صفحة المستند مثل فهرس الصفحة وحجم الصفحة. |
| [PageArea](../com.groupdocs.parser.data/pagearea) | يمثل فئة أساسية مجردة لمناطق الصفحة التي تُستخدم لتمثيل الكتل على صفحة المستند في وظيفة التحليل باستخدام القالب. |
| [PageBarcodeArea](../com.groupdocs.parser.data/pagebarcodearea) | يمثل منطقة باركود الصفحة التي تُستخدم لتمثيل قيمة الباركود في وظيفة التحليل باستخدام القالب. |
| [PageGroupArea](../com.groupdocs.parser.data/pagegrouparea) | يمثل مجموعة من مناطق الصفحة التي تُستخدم لتجميع أنواع مختلفة من كتل صفحة المستند في وظيفة التحليل باستخدام القالب. |
| [PageHyperlinkArea](../com.groupdocs.parser.data/pagehyperlinkarea) | يمثل منطقة صفحة تُستخدم لتمثيل ارتباط تشعبي على الصفحة. |
| [PageImageArea](../com.groupdocs.parser.data/pageimagearea) | يمثل منطقة صورة الصفحة التي تُستخدم لتمثيل صورة على الصفحة في وظيفة التحليل باستخدام القالب أو مرفق صورة إذا تم استخراج الصور من رسائل البريد الإلكتروني أو أرشيفات Zip. |
| [PageTableArea](../com.groupdocs.parser.data/pagetablearea) | يمثل منطقة جدول الصفحة التي تُستخدم لتمثيل جدول في وظيفة التحليل باستخدام القالب. |
| [PageTableAreaCell](../com.groupdocs.parser.data/pagetableareacell) | يمثل خلية جدول تُستخدم في الصف [PageTableArea](../com.groupdocs.parser.data/pagetablearea). |
| [PageTextArea](../com.groupdocs.parser.data/pagetextarea) | يمثل منطقة نص الصفحة التي تُستخدم لتمثيل قيمة نصية في وظيفة التحليل باستخدام القالب أو وظيفة تحليل النماذج. |
| [Point](../com.groupdocs.parser.data/point) | يمثل نقطة. |
| [Rectangle](../com.groupdocs.parser.data/rectangle) | يمثل مساحة مستطيلة. |
| [SearchResult](../com.groupdocs.parser.data/searchresult) | يمثل نتيجة البحث في وظيفة البحث. |
| [Size](../com.groupdocs.parser.data/size) | يمثل حجمًا. |
| [TextReader](../com.groupdocs.parser.data/textreader) | يمثل قارئًا يمكنه قراءة سلسلة متسلسلة من الأحرف. |
| [TextStyle](../com.groupdocs.parser.data/textstyle) | يمثل نمط النص مثل اسم الخط، حجم الخط وما إلى ذلك. |
| [TocItem](../com.groupdocs.parser.data/tocitem) | يمثل العنصر الذي يُستخدم في وظيفة استخراج جدول المحتويات. |
