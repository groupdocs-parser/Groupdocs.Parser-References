Het pakket biedt klassen voor het maken van sjablonen voor het parseren van documentgegevens.



## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [Template](../com.groupdocs.parser.templates/template) | Biedt de sjabloon voor de documentpagina. |
| [TemplateBarcode](../com.groupdocs.parser.templates/templatebarcode) | Biedt het sjabloon barcode-veld. |
| [TemplateField](../com.groupdocs.parser.templates/templatefield) | Biedt het sjabloon tekstveld. |
| [TemplateFixedPosition](../com.groupdocs.parser.templates/templatefixedposition) | Biedt een sjabloon-veldpositie die wordt gedefinieerd door het rechthoekige gebied. |
| [TemplateItem](../com.groupdocs.parser.templates/templateitem) | Biedt een abstracte basisklasse voor sjabloonitems. |
| [TemplateLinkedPosition](../com.groupdocs.parser.templates/templatelinkedposition) | Biedt een sjabloon-veldpositie die het gekoppelde veld gebruikt. |
| [TemplateLinkedPositionEdges](../com.groupdocs.parser.templates/templatelinkedpositionedges) | Biedt de randen van het gekoppelde veld waar het tekstveld wordt gezocht. |
| [TemplateOptions](../com.groupdocs.parser.templates/templateoptions) | Biedt de opties die worden gebruikt voor het parseren via sjabloonfunctionaliteit. |
| [TemplatePosition](../com.groupdocs.parser.templates/templateposition) | Biedt een abstracte basisklasse voor sjabloonposities. |
| [TemplateRegexPosition](../com.groupdocs.parser.templates/templateregexposition) | Biedt een sjabloon-veldpositie die de reguliere expressie gebruikt. |
| [TemplateTable](../com.groupdocs.parser.templates/templatetable) | Biedt de sjabloontabel. |
| [TemplateTableLayout](../com.groupdocs.parser.templates/templatetablelayout) | Biedt de lay-out van de sjabloontabel die wordt gebruikt door de klasse [TemplateTable](../com.groupdocs.parser.templates/templatetable) om de tabelpositie te definiëren. |
| [TemplateTableParameters](../com.groupdocs.parser.templates/templatetableparameters) | Biedt parameters voor de tabeldetectie-algoritmen. |
