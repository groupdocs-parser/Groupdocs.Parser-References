Het pakket biedt klassen die parsingresultaten vertegenwoordigen.



## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [ContainerItem](../com.groupdocs.parser.data/containeritem) | Stelt een containeritem voor, zoals een Zip-archief‑entiteit, e‑mailbijlage, PDF‑portfoliopost en dergelijke. |
| [DocumentData](../com.groupdocs.parser.data/documentdata) | Stelt de gegevens van het document voor. |
| [DocumentPageData](../com.groupdocs.parser.data/documentpagedata) | Stelt de gegevens van de documentpagina voor. |
| [FieldData](../com.groupdocs.parser.data/fielddata) | Stelt veldgegevens voor, zoals een naam, een paginanummer, een veldwaarde en dergelijke. |
| [HighlightItem](../com.groupdocs.parser.data/highlightitem) | Stelt een markering voor, een deel van de tekst dat meestal wordt gebruikt om de context van de gevonden tekst in de zoekfunctionaliteit uit te leggen. |
| [MetadataItem](../com.groupdocs.parser.data/metadataitem) | Stelt een metadata‑item voor dat wordt gebruikt in containeritems en de functionaliteit voor metadata‑extractie. |
| [Page](../com.groupdocs.parser.data/page) | Stelt de paginainformatie van het document voor, zoals paginanummer en paginagrootte. |
| [PageArea](../com.groupdocs.parser.data/pagearea) | Stelt een abstracte basisklasse voor paginagebieden voor die worden gebruikt om blokken op de documentpagina te representeren in de functionaliteit voor parsing op basis van sjablonen. |
| [PageBarcodeArea](../com.groupdocs.parser.data/pagebarcodearea) | Stelt een paginabarcoderegio voor die wordt gebruikt om een barcodelabel te representeren in de functionaliteit voor parsing op basis van sjablonen. |
| [PageGroupArea](../com.groupdocs.parser.data/pagegrouparea) | Stelt een groep paginagebieden voor die wordt gebruikt om verschillende soorten blokken van de documentpagina te groeperen in de functionaliteit voor parsing op basis van sjablonen. |
| [PageHyperlinkArea](../com.groupdocs.parser.data/pagehyperlinkarea) | Stelt een paginagebied voor dat wordt gebruikt om een hyperlink op de pagina te representeren. |
| [PageImageArea](../com.groupdocs.parser.data/pageimagearea) | Stelt een paginabeeldgebied voor dat wordt gebruikt om een afbeelding op de pagina te representeren in de functionaliteit voor parsing op basis van sjablonen of een afbeeldingbijlage als afbeeldingen worden geëxtraheerd uit e‑mails of Zip‑archieven. |
| [PageTableArea](../com.groupdocs.parser.data/pagetablearea) | Stelt een tabelpaginagebied voor dat wordt gebruikt om een tabel te representeren in de functionaliteit voor parsing op basis van sjablonen. |
| [PageTableAreaCell](../com.groupdocs.parser.data/pagetableareacell) | Stelt een tabelcel voor die wordt gebruikt in de klasse [PageTableArea](../com.groupdocs.parser.data/pagetablearea). |
| [PageTextArea](../com.groupdocs.parser.data/pagetextarea) | Stelt een paginatekstgebied voor dat wordt gebruikt om een tekstwaarde te representeren in de functionaliteit voor parsing op basis van sjablonen of formulierparsing. |
| [Point](../com.groupdocs.parser.data/point) | Stelt een punt voor. |
| [Rectangle](../com.groupdocs.parser.data/rectangle) | Stelt een rechthoekig gebied voor. |
| [SearchResult](../com.groupdocs.parser.data/searchresult) | Stelt het zoekresultaat voor in de zoekfunctionaliteit. |
| [Size](../com.groupdocs.parser.data/size) | Stelt een grootte voor. |
| [TextReader](../com.groupdocs.parser.data/textreader) | Stelt een lezer voor die een opeenvolgende reeks tekens kan lezen. |
| [TextStyle](../com.groupdocs.parser.data/textstyle) | Stelt de stijl van de tekst voor, zoals een lettertype‑naam, een lettergrootte en dergelijke. |
| [TocItem](../com.groupdocs.parser.data/tocitem) | Stelt het item voor dat wordt gebruikt in de functionaliteit voor het extraheren van de inhoudsopgave. |
