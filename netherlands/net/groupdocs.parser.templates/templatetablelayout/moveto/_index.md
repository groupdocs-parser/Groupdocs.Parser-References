## TemplateTableLayout.MoveTo method

Maakt een nieuwe lay-out met dezelfde grootte, scheidingstekens en positie in het *punt*.

```csharp
public TemplateTableLayout MoveTo(Point point)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| punt | Point | De positie van de nieuwe lay-out. |

### Retourwaarde

Een nieuwe lay-out met dezelfde grootte, scheidingstekens en positie in het *punt*.

### Voorbeelden

Deze functionaliteit maakt het mogelijk om Table Layout te verplaatsen.

Bijvoorbeeld, een document heeft tabellen op elke pagina (of een reeks documenten met een tabel op de pagina). Deze tabellen verschillen in positie en inhoud, maar hebben dezelfde kolommen en rijen. In dit geval kan een gebruiker een [`TemplateTableLayout`](../../templatetablelayout) object op `(0, 0)` definiëren en vervolgens verplaatsen naar de locatie van de definitieve tabel.

Als de tabelpositie afhankelijk is van een ander object op de pagina, kan een gebruiker een [`TemplateTableLayout`](../../templatetablelayout) object definiëren op basis van een sjabloondocument en het vervolgens verplaatsen volgens een ankerobject. Bijvoorbeeld, als dit een samenvattabel is en deze wordt gevolgd door een detailtabel (die een verschillend aantal rijen kan bevatten). In dit geval kan een gebruiker een [`TemplateTableLayout`](../../templatetablelayout) object definiëren in het sjabloondocument (met de bekende rechthoek van de detailtabel) en vervolgens het [`TemplateTableLayout`](../../templatetablelayout) object verplaatsen volgens het verschil tussen de rechthoek van de detailtabel in het sjabloon en het echte document.

`MoveTo`-methode retourneert een kopie van het huidige object. Een gebruiker kan elke coördinaat doorgeven (ook negatieve - dan wordt de lay-out naar links/boven verplaatst).

```csharp
// Maak een tabelindeling
TemplateTableLayout layout = new TemplateTableLayout(
    new double[] { 0, 25, 150, 180, 230 },
    new double[] { 0, 15, 30, 45, 60, 75 });

// Print een rechthoek
Rectangle rect = layout.Rectangle;

// Print: pos: (0, 0) size: (230, 75)
Console.WriteLine(string.Format("pos: ({0}, {1}) size: ({2}, {3})", rect.Left, rect.Top, rect.Size.Width, rect.Size.Height));

// Verplaats lay-out naar de definitieve tabellocatie
TemplateTableLayout movedLayout = layout.MoveTo(new Point(315, 250));

// Zorg ervoor dat de eerste scheidingslijnen worden verplaatst:
Console.WriteLine(movedLayout.VerticalSeparators[0]); // prints: 315
Console.WriteLine(movedLayout.HorizontalSeparators[0]); // prints: 250

Rectangle movedRect = movedLayout.Rectangle;

// Print: pos: (315, 250) size: (230, 75)
Console.WriteLine(string.Format("pos: ({0}, {1}) size: ({2}, {3})", movedRect.Left, movedRect.Top, movedRect.Size.Width, movedRect.Size.Height));

// Het movedLayout-object is een kopie van het layout-object, zodat we scheidingslijnen kunnen afstemmen zonder invloed op de originele lay-out:
movedLayout.HorizontalSeparators.Add(90);

Console.WriteLine(movedLayout.HorizontalSeparators.Count); // prints: 7
Console.WriteLine(layout.HorizontalSeparators.Count); // prints: 6
```
