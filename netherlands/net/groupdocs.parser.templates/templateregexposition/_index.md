### Voorbeelden

Het volgende voorbeeld toont de situatie wanneer het document \"Invoice Number INV-12345\" bevat, dan kan het sjabloonveld als volgt worden gedefinieerd:

```csharp
// Maak een regex-sjabloonveld met de naam \"InvoiceNumber\"
TemplateField templateField = new TemplateField(
    new TemplateRegexPosition("Invoice Number\\s+[A-Z0-9\\-]+"),
    "InvoiceNumber");
```

In dit geval wordt de volledige tekenreeks als waarde geëxtraheerd. Om alleen een deel van de tekenreeks te extraheren, wordt de reguliere expressiegroep \"value\" gebruikt:

```csharp
// Maak een regex-sjabloonveld met de naam \"InvoiceNumber\" met de groep \"value\"
TemplateField templateField = new TemplateField(
    new TemplateRegexPosition("Invoice Number\\s+(?<value>[A-Z0-9\\-]+)"),
    "InvoiceNumber");
```

In dit geval wordt de tekenreeks \"INV-3337\" als waarde geëxtraheerd.
