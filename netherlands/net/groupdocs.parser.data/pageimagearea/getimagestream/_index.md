## GetImageStream() {#getimagestream}

Retourneert de afbeeldingstroom.

```csharp
public Stream GetImageStream()
```

### Retourwaarde

Een stream met de afbeelding.

### Voorbeelden

Het volgende voorbeeld toont hoe afbeeldingen naar bestanden op te slaan:

```csharp
// Maak een instantie van de Parser‑klasse
using (Parser parser = new Parser(filePath))
{
    // Afbeeldingen uit document extraheren
    IEnumerable<PageImageArea> images = parser.GetImages();
    
    // Controleren of het extraheren van afbeeldingen wordt ondersteund
    if (images == null)
    {
        Console.WriteLine("Page images extraction isn't supported");
        return;
    }

    // Itereren over afbeeldingen
    foreach (PageImageArea image in images)
    {
        // Open de afbeeldingstroom
        using (Stream imageStream = image.GetImageStream())
        {
            // Maak het bestand aan om de afbeelding op te slaan
            using (Stream destStream = File.Create(Guid.NewGuid().ToString() + image.FileType.Extension))
            {
                byte[] buffer = new byte[4096];
                int readed = 0;

                do
                {
                    // Lees gegevens van de afbeeldingstroom
                    readed = imageStream.Read(buffer, 0, buffer.Length);

                    if (readed > 0)
                    {
                        // Schrijf gegevens naar de bestandsstroom
                        destStream.Write(buffer, 0, readed);
                    }
                }
                while (readed > 0);
            }
        }
    }
}
```

### Retourwaarde

Een stream met de afbeelding.

### Voorbeelden

Het volgende voorbeeld toont hoe afbeeldingen in een ander formaat naar bestanden kunnen worden opgeslagen:

```csharp
// Maak een instantie van de Parser‑klasse
using (Parser parser = new Parser(filePath))
{
    // Afbeeldingen uit document extraheren
    IEnumerable<PageImageArea> images = parser.GetImages();
    
    // Controleren of het extraheren van afbeeldingen wordt ondersteund
    if (images == null)
    {
        Console.WriteLine("Page images extraction isn't supported");
        return;
    }

    // Maak de opties aan om afbeeldingen op te slaan in PNG-formaat
    ImageOptions options = new ImageOptions(ImageFormat.Png);
    
    // Itereren over afbeeldingen
    foreach (PageImageArea image in images)
    {
        // Open de afbeeldingstroom
        using (Stream imageStream = image.GetImageStream(options))
        {
            // Maak het bestand aan om de afbeelding op te slaan
            using (Stream destStream = File.Create(Guid.NewGuid().ToString() + ".png"))
            {
                byte[] buffer = new byte[4096];
                int readed = 0;

                do
                {
                    // Lees gegevens van de afbeeldingstroom
                    readed = imageStream.Read(buffer, 0, buffer.Length);

                    if (readed > 0)
                    {
                        // Schrijf gegevens naar de bestandsstroom
                        destStream.Write(buffer, 0, readed);
                    }
                }
                while (readed > 0);
            }
        }
    }
}
```
