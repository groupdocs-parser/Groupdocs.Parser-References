## TocItem.ExtractText method

Extraheert een tekst uit het document waarnaar het [`TocItem`](../../tocitem)‑object verwijst.

```csharp
public virtual TextReader ExtractText()
```

### Retourwaarde

Een instantie van de TextReader‑klasse met de geëxtraheerde tekst.

### Voorbeelden

Het volgende voorbeeld hoe een tekst te extraheren met een item uit de inhoudsopgave:

```csharp
// Maak een instantie van de Parser‑klasse
using (Parser parser = new Parser(Constants.SampleDocxWithToc))
{
    // Haal inhoudsopgave op
    IEnumerable<TocItem> tocItems = parser.GetToc();
    // Controleren of toc-extractie wordt ondersteund
    if (tocItems == null)
    {
        Console.WriteLine("Table of contents extraction isn't supported");
    }
    // Itereer over items
    foreach (TocItem tocItem in tocItems)
    {
        // Print de tekst van het hoofdstuk
        using (TextReader reader = tocItem.ExtractText())
        {
            Console.WriteLine("----");
            Console.WriteLine(reader.ReadToEnd());
        }
    }
}
```
