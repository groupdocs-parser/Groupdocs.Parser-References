## FieldData.PageArea property

Haalt de waarde van het veld op.

public PageArea PageArea { get; }

### Property Value

Een instantie van de [`PageArea`](../../pagearea) klasse die de waarde van het veld vertegenwoordigt.

### Voorbeelden

Afhankelijk van het veld kan de eigenschap `PageArea` elk van de overervingen van de [`PageArea`](../../pagearea) klasse bevatten. Bijvoorbeeld, de methode [`ParseForm`](../../../groupdocs.parser/parser/parseform) haalt alleen tekstvelden op.

```csharp
// Haal de veldgegevens op
FieldData field = data[i];
// Controleer of de veldgegevens een tekst bevatten
if(field.PageArea is PageTextArea)
{
    // Print de tekstwaarde van het veld
    Console.WriteLine(field.Text);
}
```
