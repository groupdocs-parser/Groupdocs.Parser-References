## Parser.GetHighlight method

Extraheert een markering uit het document.

```csharp
public HighlightItem GetHighlight(int position, bool isDirect, HighlightOptions options)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| positie | Int32 | De startpositie van de markering. |
| isDirect | Boolean | De waarde die aangeeft of highlight-extractie direct is. `true` als de highlight wordt geëxtraheerd rechts van *position*; anders `false`. |
| options | HighlightOptions | De opties voor highlight-extractie. |

### Retourwaarde

Een instantie van de [`HighlightItem`](../../../groupdocs.parser.data/highlightitem) klasse die de geëxtraheerde highlight vertegenwoordigt; `null` als highlight-extractie niet wordt ondersteund.

### Opmerkingen

**Learn more:**

* [Extract highlights](https://docs.groupdocs.com/display/parsernet/Extract+highlights)

### Voorbeelden

Het volgende voorbeeld laat zien hoe een highlight met 3 woorden geëxtraheerd kan worden:

```csharp
// Maak een instantie van de Parser‑klasse
using (Parser parser = new Parser(filePath))
{
    // Highlight extraheren:
    HighlightItem hl = parser.GetHighlight(2, true, new HighlightOptions(3));
    
    // Controleren of highlight-extractie wordt ondersteund
    if (hl == null)
    {
        Console.WriteLine("Highlight extraction isn't supported");
        return;
    }
    
    // Een geëxtraheerde highlight afdrukken
    Console.WriteLine(string.Format("At {0}: {1}", hl.Position, hl.Text));
}
```
