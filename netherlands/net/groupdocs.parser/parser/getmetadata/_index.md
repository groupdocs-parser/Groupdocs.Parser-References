### Voorbeelden

Het volgende voorbeeld toont hoe metagegevens uit een document te extraheren:

```csharp
// Maak een instantie van de Parser‑klasse
using(Parser parser = new Parser(filePath))
{
    // Metagegevens uit het document extraheren
    IEnumerable<MetadataItem> metadata = parser.GetMetadata();
    // Controleren of metadata-extractie wordt ondersteund
    if(metadata == null)
    {
        Console.WriteLine("Metatada extraction isn't supported");
    }
 
    // Itereren over metadata-items
    foreach(MetadataItem item in metadata)
    {
        // Print een itemnaam en waarde
        Console.WriteLine(string.Format("{0}: {1}", item.Name, item.Value));
    }
}
```
