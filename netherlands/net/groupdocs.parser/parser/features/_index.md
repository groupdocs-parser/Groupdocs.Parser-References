### Voorbeelden

Als de functie niet wordt ondersteund, retourneert de methode `null` in plaats van de waarde. Sommige bewerkingen kunnen aanzienlijke tijd kosten. Het is dus niet optimaal om de methode aan te roepen alleen om de ondersteuning van de functie te controleren. Voor dit doel wordt de Features‑eigenschap gebruikt:

```csharp
using(Parser parser = new Parser("doc.zip"))
{
    if(!parser.Features.Text)
    {
        Console.WriteLine("Text extraction isn't supported");
        return;
    }
 
    using(TextReader reader = parser.GetText())
    {
        Console.WriteLine(reader.ReadToEnd());
    }
}
```
