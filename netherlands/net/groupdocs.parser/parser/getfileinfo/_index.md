```csharp
public static FileInfo GetFileInfo(string filePath)
```

| Parameter | Type | Beschrijving |

| filePath | String | Het pad naar het bestand. |

### Retourwaarde

### Voorbeelden

De volgende code toont hoe het bestandstype van het met wachtwoord beveiligde document te controleren:

```csharp
// Haal bestandsinfo op

// Print het bestandstype
Console.WriteLine(info.FileType.ToString());
```
