该包提供用于创建解析文档数据模板的类。



## 类

| 类 | 描述 |
| --- | --- |
| [Template](../com.groupdocs.parser.templates/template) | 提供文档页面模板。 |
| [TemplateBarcode](../com.groupdocs.parser.templates/templatebarcode) | 提供模板条形码字段。 |
| [TemplateField](../com.groupdocs.parser.templates/templatefield) | 提供模板文本字段。 |
| [TemplateFixedPosition](../com.groupdocs.parser.templates/templatefixedposition) | 提供由矩形区域定义的模板字段位置。 |
| [TemplateItem](../com.groupdocs.parser.templates/templateitem) | 提供模板项的基抽象类。 |
| [TemplateLinkedPosition](../com.groupdocs.parser.templates/templatelinkedposition) | 提供使用链接字段的模板字段位置。 |
| [TemplateLinkedPositionEdges](../com.groupdocs.parser.templates/templatelinkedpositionedges) | 提供链接字段的边缘，以搜索文本字段。 |
| [TemplateOptions](../com.groupdocs.parser.templates/templateoptions) | 提供用于模板功能解析的选项。 |
| [TemplatePosition](../com.groupdocs.parser.templates/templateposition) | 提供模板位置的基抽象类。 |
| [TemplateRegexPosition](../com.groupdocs.parser.templates/templateregexposition) | 提供使用正则表达式的模板字段位置。 |
| [TemplateTable](../com.groupdocs.parser.templates/templatetable) | 提供模板表。 |
| [TemplateTableLayout](../com.groupdocs.parser.templates/templatetablelayout) | 提供模板表布局，该布局被 [TemplateTable](../com.groupdocs.parser.templates/templatetable) 类用于定义表位置。 |
| [TemplateTableParameters](../com.groupdocs.parser.templates/templatetableparameters) | 提供用于表检测算法的参数。 |
