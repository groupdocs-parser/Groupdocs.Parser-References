该包提供表示解析结果的类。



## 类

| 类 | 描述 |
| --- | --- |
| [ContainerItem](../com.groupdocs.parser.data/containeritem) | 表示容器项，例如 Zip 存档实体、电子邮件附件、PDF Portfolio 项等。 |
| [DocumentData](../com.groupdocs.parser.data/documentdata) | 表示文档的数据。 |
| [DocumentPageData](../com.groupdocs.parser.data/documentpagedata) | 表示文档页的数据。 |
| [FieldData](../com.groupdocs.parser.data/fielddata) | 表示字段数据，例如名称、页索引、字段值等。 |
| [HighlightItem](../com.groupdocs.parser.data/highlightitem) | 表示高亮，即通常用于在搜索功能中解释找到的文本上下文的文本片段。 |
| [MetadataItem](../com.groupdocs.parser.data/metadataitem) | 表示在容器项和元数据提取功能中使用的元数据项。 |
| [Page](../com.groupdocs.parser.data/page) | 表示文档页信息，例如页索引和页大小。 |
| [PageArea](../com.groupdocs.parser.data/pagearea) | 表示用于在基于模板的解析功能中表示文档页块的页面区域抽象基类。 |
| [PageBarcodeArea](../com.groupdocs.parser.data/pagebarcodearea) | 表示用于在基于模板的解析功能中表示条码值的页面条码区域。 |
| [PageGroupArea](../com.groupdocs.parser.data/pagegrouparea) | 表示用于在基于模板的解析功能中对文档页不同类型块进行分组的页面区域组。 |
| [PageHyperlinkArea](../com.groupdocs.parser.data/pagehyperlinkarea) | 表示用于在页面上表示超链接的页面区域。 |
| [PageImageArea](../com.groupdocs.parser.data/pageimagearea) | 表示用于在基于模板的解析功能中表示页面图像的页面图像区域，或在从电子邮件或 Zip 存档中提取图像时表示图像附件。 |
| [PageTableArea](../com.groupdocs.parser.data/pagetablearea) | 表示用于在基于模板的解析功能中表示表格的页面表格区域。 |
| [PageTableAreaCell](../com.groupdocs.parser.data/pagetableareacell) | 表示在 [PageTableArea](../com.groupdocs.parser.data/pagetablearea) 类中使用的表格单元格。 |
| [PageTextArea](../com.groupdocs.parser.data/pagetextarea) | 表示用于在基于模板或表单解析功能中表示文本值的页面文本区域。 |
| [Point](../com.groupdocs.parser.data/point) | 表示一个点。 |
| [Rectangle](../com.groupdocs.parser.data/rectangle) | 表示一个矩形区域。 |
| [SearchResult](../com.groupdocs.parser.data/searchresult) | 表示搜索功能中的搜索结果。 |
| [Size](../com.groupdocs.parser.data/size) | 表示一个尺寸。 |
| [TextReader](../com.groupdocs.parser.data/textreader) | 表示能够读取字符序列的读取器。 |
| [TextStyle](../com.groupdocs.parser.data/textstyle) | 表示文本的样式，例如字体名称、字体大小等。 |
| [TocItem](../com.groupdocs.parser.data/tocitem) | 表示在目录提取功能中使用的项。 |
