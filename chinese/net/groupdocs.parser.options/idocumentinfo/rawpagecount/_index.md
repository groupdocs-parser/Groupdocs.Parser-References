## IDocumentInfo.RawPageCount property

获取文档原始页的总数。

```csharp
public int RawPageCount { get; }
```

### Property Value

表示原始页总数的整数值。

### 备注

在原始文本提取时，请使用 `RawPageCount` 属性而不是 [`PageCount`](../pagecount) 属性。某些文档在精确和原始文本提取模式下的页码不同。[`PageCount`](../pagecount) 属性可能执行额外的计算，从而影响原始模式下的文本提取速度。
