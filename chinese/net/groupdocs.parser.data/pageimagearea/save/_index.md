## Save(string) {#save}

将图像保存到文件。

```csharp
public void Save(string filePath)
```

| Parameter | Type | 描述 |
| --- | --- | --- |
| filePath | 字符串 | 文件的路径。 |

### 示例

以下示例展示了如何将图像保存到文件：

```csharp
// 创建 Parser 类的实例
using (Parser parser = new Parser(filePath))
{
    // 从文档中提取图像
    IEnumerable<PageImageArea> images = parser.GetImages();
    
    // 检查是否支持图像提取
    if (images == null)
    {
        Console.WriteLine("Page images extraction isn't supported");
        return;
    }

    // 遍历图像
    foreach (PageImageArea image in images)
    {
        // 将图像保存到文件
        image.Save(Guid.NewGuid().ToString() + image.FileType.Extension);
    }
}
```

## Save(string, ImageOptions) {#save_1}

以不同的格式将图像保存到文件。

```csharp
public void Save(string filePath, ImageOptions options)
```

| Parameter | Type | 描述 |
| --- | --- | --- |
| filePath | 字符串 | 文件的路径。 |
| options | ImageOptions | 用于保存图像的选项。 |

### 示例

以下示例展示了如何将图像保存为不同格式的文件：

```csharp
// 创建 Parser 类的实例
using (Parser parser = new Parser(filePath))
{
    // 从文档中提取图像
    IEnumerable<PageImageArea> images = parser.GetImages();
    
    // 检查是否支持图像提取
    if (images == null)
    {
        Console.WriteLine("Page images extraction isn't supported");
        return;
    }

    // 创建用于以 PNG 格式保存图像的选项
    ImageOptions options = new ImageOptions(ImageFormat.Png);
    
    // 遍历图像
    foreach (PageImageArea image in images)
    {
        // 将图像保存到 png 文件
        image.Save(Guid.NewGuid().ToString() + ".png", options);
    }
}
```
