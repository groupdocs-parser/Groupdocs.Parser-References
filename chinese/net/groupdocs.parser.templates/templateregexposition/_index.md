### 示例

以下示例展示了当文档包含 "Invoice Number INV-12345" 时，模板字段可以这样定义：

```csharp
// 创建一个名称为 "InvoiceNumber" 的正则模板字段
TemplateField templateField = new TemplateField(
    new TemplateRegexPosition("Invoice Number\\s+[A-Z0-9\\-]+"),
    "InvoiceNumber");
```

在这种情况下，提取的值为整个字符串。要仅提取字符串的一部分，使用正则表达式组 "value"：

```csharp
// 创建一个名称为 "InvoiceNumber"、使用 "value" 组的正则模板字段
TemplateField templateField = new TemplateField(
    new TemplateRegexPosition("Invoice Number\\s+(?<value>[A-Z0-9\\-]+)"),
    "InvoiceNumber");
```

在这种情况下，提取的值为字符串 "INV-3337"。
