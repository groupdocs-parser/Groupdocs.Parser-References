## Parser.GetHighlight method

从文档中提取高亮。

```csharp
public HighlightItem GetHighlight(int position, bool isDirect, HighlightOptions options)
```

| Parameter | Type | 描述 |
| --- | --- | --- |
| 位置 | Int32 | 高亮的起始位置。 |
| isDirect | Boolean | 指示高亮提取是否直接的值。`true` 表示高亮是从 *position* 的右侧提取的；否则为 `false`。 |
| options | HighlightOptions | 高亮提取选项。 |

### 返回值

表示提取的高亮的 [`HighlightItem`](../../../groupdocs.parser.data/highlightitem) 类的实例；如果不支持高亮提取，则为 `null`。

### 备注

**Learn more:**

* [Extract highlights](https://docs.groupdocs.com/display/parsernet/Extract+highlights)

### 示例

以下示例展示如何提取包含 3 个词的高亮：

```csharp
// 创建 Parser 类的实例
using (Parser parser = new Parser(filePath))
{
    // 提取高亮：
    HighlightItem hl = parser.GetHighlight(2, true, new HighlightOptions(3));
    
    // 检查是否支持高亮提取
    if (hl == null)
    {
        Console.WriteLine("Highlight extraction isn't supported");
        return;
    }
    
    // 打印提取的高亮
    Console.WriteLine(string.Format("At {0}: {1}", hl.Position, hl.Text));
}
```
