### 예제

다음 예제는 문서에 "Invoice Number INV-12345"가 포함된 경우 템플릿 필드를 다음과 같이 정의할 수 있음을 보여줍니다:

```csharp
// "InvoiceNumber" 이름으로 정규식 템플릿 필드를 생성합니다.
TemplateField templateField = new TemplateField(
    new TemplateRegexPosition("Invoice Number\\s+[A-Z0-9\\-]+"),
    "InvoiceNumber");
```

이 경우 값으로 전체 문자열이 추출됩니다. 문자열의 일부만 추출하려면 정규식 그룹 "value"를 사용합니다:

```csharp
// "InvoiceNumber" 이름과 "value" 그룹을 사용하여 정규식 템플릿 필드를 생성합니다.
TemplateField templateField = new TemplateField(
    new TemplateRegexPosition("Invoice Number\\s+(?<value>[A-Z0-9\\-]+)"),
    "InvoiceNumber");
```

이 경우 값으로 "INV-3337" 문자열이 추출됩니다.
