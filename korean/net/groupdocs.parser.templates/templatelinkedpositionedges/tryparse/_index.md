## TemplateLinkedPositionEdges.TryParse method

가장자리의 문자열 표현을 해당 클래스 형태로 변환합니다. 반환 값은 변환이 성공했는지 실패했는지를 나타냅니다.

```csharp
public static bool TryParse(string s, out TemplateLinkedPositionEdges edges)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| s | 문자열 | 변환할 에지를 포함하는 문자열입니다. |
| edges | TemplateLinkedPositionEdges& | 메서드가 반환될 때, 변환이 성공한 경우 *s* 매개변수에 지정된 값과 동일한 [`TemplateLinkedPositionEdges`](../../templatelinkedpositionedges) 클래스의 인스턴스를 포함하고; 그렇지 않으면 `null`을 반환합니다. |

### 반환 값
