## TemplateTableLayout.MoveTo method

같은 크기, 구분자 및 위치를 가진 새 레이아웃을 *point*에 생성합니다.

```csharp
public TemplateTableLayout MoveTo(Point point)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| 점 | Point | 새 레이아웃의 위치. |

### 반환 값

*point*에 동일한 크기, 구분선 및 위치를 가진 새 레이아웃.

### 예제

이 기능을 사용하면 Table Layout을 이동할 수 있습니다.

예를 들어, 문서의 각 페이지에 테이블이 있거나(또는 페이지에 테이블이 있는 문서 집합) 각 페이지에 테이블이 있습니다. 이러한 테이블은 위치와 내용이 다르지만 동일한 열과 행을 가집니다. 이 경우 사용자는 [`TemplateTableLayout`](../../templatetablelayout) 객체를 `(0, 0)`에 한 번 정의한 다음, 해당 테이블의 위치로 이동시킬 수 있습니다.

테이블 위치가 페이지의 다른 객체에 따라 달라지는 경우, 사용자는 템플릿 문서를 기반으로 [`TemplateTableLayout`](../../templatetablelayout) 객체를 정의한 다음 앵커 객체에 따라 이동시킬 수 있습니다. 예를 들어, 이것이 요약 테이블이고 그 뒤에 상세 테이블이 따라오는 경우(행 수가 다를 수 있음). 이 경우 사용자는 템플릿 문서에 (알려진 상세 테이블 사각형을 포함하여) [`TemplateTableLayout`](../../templatetablelayout) 객체를 정의하고, 템플릿과 실제 문서의 상세 테이블 사각형 차이에 따라 [`TemplateTableLayout`](../../templatetablelayout) 객체를 이동시킬 수 있습니다.

`MoveTo` 메서드는 현재 객체의 복사본을 반환합니다. 사용자는 어떤 좌표든 전달할 수 있으며(음수도 가능 - 이 경우 레이아웃이 왼쪽/위쪽으로 이동합니다).

```csharp
// 테이블 레이아웃 만들기
TemplateTableLayout layout = new TemplateTableLayout(
    new double[] { 0, 25, 150, 180, 230 },
    new double[] { 0, 15, 30, 45, 60, 75 });

// 사각형 출력
Rectangle rect = layout.Rectangle;

// 출력: 위치: (0, 0) 크기: (230, 75)
Console.WriteLine(string.Format("pos: ({0}, {1}) size: ({2}, {3})", rect.Left, rect.Top, rect.Size.Width, rect.Size.Height));

// 레이아웃을 지정된 테이블 위치로 이동
TemplateTableLayout movedLayout = layout.MoveTo(new Point(315, 250));

// 첫 번째 구분자가 이동되었는지 확인:
Console.WriteLine(movedLayout.VerticalSeparators[0]); // prints: 315
Console.WriteLine(movedLayout.HorizontalSeparators[0]); // prints: 250

Rectangle movedRect = movedLayout.Rectangle;

// 출력: 위치: (315, 250) 크기: (230, 75)
Console.WriteLine(string.Format("pos: ({0}, {1}) size: ({2}, {3})", movedRect.Left, movedRect.Top, movedRect.Size.Width, movedRect.Size.Height));

// movedLayout 객체는 layout 객체의 복사본이므로 원본 레이아웃에 영향을 주지 않고 구분자를 조정할 수 있습니다:
movedLayout.HorizontalSeparators.Add(90);

Console.WriteLine(movedLayout.HorizontalSeparators.Count); // prints: 7
Console.WriteLine(layout.HorizontalSeparators.Count); // prints: 6
```
