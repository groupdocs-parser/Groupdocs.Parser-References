## GetFormattedText(FormattedTextOptions) {#getformattedtext}

문서에서 서식이 지정된 텍스트를 추출합니다.

```csharp
public TextReader GetFormattedText(FormattedTextOptions options)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| options | FormattedTextOptions | 서식 있는 텍스트 추출 옵션입니다. |

### 반환 값

추출된 텍스트를 포함하는 TextReader 클래스 인스턴스; 서식 있는 텍스트 추출을 지원하지 않으면 `null`.

### 예제

다음 예제는 문서 텍스트를 HTML 텍스트로 추출하는 방법을 보여줍니다:

```csharp
// Parser 클래스의 인스턴스를 생성합니다
using (Parser parser = new Parser(filePath))
{
    // 서식 있는 텍스트를 리더에 추출합니다
    using (TextReader reader = parser.GetFormattedText(new FormattedTextOptions(FormattedTextMode.Html)))
    {
        // 문서에서 서식 있는 텍스트를 출력합니다
        // 서식 있는 텍스트 추출을 지원하지 않으면, 리더는 null입니다
        Console.WriteLine(reader == null ? "Formatted text extraction isn't suppported" : reader.ReadToEnd());
    }
}
```

### 예제

다음 예제는 문서 페이지 텍스트를 Markdown 텍스트로 추출하는 방법을 보여줍니다:

```csharp
// Parser 클래스의 인스턴스를 생성합니다
using (Parser parser = new Parser(filePath))
{
    // 문서가 서식 있는 텍스트 추출을 지원하는지 확인합니다
    if (!parser.Features.FormattedText)
    {
        Console.WriteLine("Document isn't supports formatted text extraction.");
        return;
    }
    
    // 문서 정보를 가져옵니다
    IDocumentInfo documentInfo = parser.GetDocumentInfo();
    // 문서에 페이지가 있는지 확인합니다
    if (documentInfo.PageCount == 0)
    {
        Console.WriteLine("Document hasn't pages.");
        return;
    }
    
    // 페이지를 순회합니다
    for (int p = 0; p<documentInfo.PageCount; p++)
    {
        // 페이지 번호를 출력합니다 
        Console.WriteLine(string.Format("Page {0}/{1}", p + 1, documentInfo.PageCount));
        // 서식 있는 텍스트를 리더에 추출합니다
        using (TextReader reader = parser.GetFormattedText(p, new FormattedTextOptions(FormattedTextMode.Markdown)))
        {
            // 문서에서 서식 있는 텍스트를 출력합니다
            // 이미 서식 있는 텍스트 추출 기능 지원을 확인했으므로 null 검사을 무시합니다
            Console.WriteLine(reader.ReadToEnd());
        }
    }
}
```
