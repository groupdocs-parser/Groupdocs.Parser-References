## Parser.GetHighlight method

문서에서 하이라이트를 추출합니다.

```csharp
public HighlightItem GetHighlight(int position, bool isDirect, HighlightOptions options)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| 위치 | Int32 | 하이라이트의 시작 위치입니다. |
| isDirect | Boolean | 하이라이트 추출이 직접적인지 여부를 나타내는 값입니다. `true`는 하이라이트가 *position* 오른쪽에서 추출된 경우이며, 그 외에는 `false`입니다. |
| options | HighlightOptions | 하이라이트 추출 옵션입니다. |

### 반환 값

[`HighlightItem`](../../../groupdocs.parser.data/highlightitem) 클래스의 인스턴스로, 추출된 하이라이트를 나타냅니다; 하이라이트 추출이 지원되지 않으면 `null`입니다.

### 예제

다음 예제는 3개의 단어를 포함하는 하이라이트를 추출하는 방법을 보여줍니다:

```csharp
// Parser 클래스의 인스턴스를 생성합니다
using (Parser parser = new Parser(filePath))
{
    // 하이라이트 추출:
    HighlightItem hl = parser.GetHighlight(2, true, new HighlightOptions(3));
    
    // 하이라이트 추출이 지원되는지 확인
    if (hl == null)
    {
        Console.WriteLine("Highlight extraction isn't supported");
        return;
    }
    
    // 추출된 하이라이트 출력
    Console.WriteLine(string.Format("At {0}: {1}", hl.Position, hl.Text));
}
```
