이 패키지는 구문 분석 결과를 나타내는 클래스를 제공합니다.



## 클래스

| 클래스 | 설명 |
| --- | --- |
| [ContainerItem](../com.groupdocs.parser.data/containeritem) | Zip 아카이브 엔터티, 이메일 첨부 파일, PDF 포트폴리오 항목 등과 같은 컨테이너 항목을 나타냅니다. |
| [DocumentData](../com.groupdocs.parser.data/documentdata) | 문서 데이터를 나타냅니다. |
| [DocumentPageData](../com.groupdocs.parser.data/documentpagedata) | 문서 페이지 데이터를 나타냅니다. |
| [FieldData](../com.groupdocs.parser.data/fielddata) | 이름, 페이지 인덱스, 필드 값 등과 같은 필드 데이터를 나타냅니다. |
| [HighlightItem](../com.groupdocs.parser.data/highlightitem) | 검색 기능에서 찾은 텍스트의 컨텍스트를 설명하는 데 일반적으로 사용되는 텍스트의 일부인 하이라이트를 나타냅니다. |
| [MetadataItem](../com.groupdocs.parser.data/metadataitem) | 컨테이너 항목 및 메타데이터 추출 기능에서 사용되는 메타데이터 항목을 나타냅니다. |
| [Page](../com.groupdocs.parser.data/page) | 페이지 인덱스 및 페이지 크기와 같은 문서 페이지 정보를 나타냅니다. |
| [PageArea](../com.groupdocs.parser.data/pagearea) | 템플릿 기반 파싱 기능에서 문서 페이지의 블록을 나타내는 데 사용되는 페이지 영역에 대한 추상 기본 클래스를 나타냅니다. |
| [PageBarcodeArea](../com.groupdocs.parser.data/pagebarcodearea) | 템플릿 기반 파싱 기능에서 바코드 값을 나타내는 페이지 바코드 영역을 나타냅니다. |
| [PageGroupArea](../com.groupdocs.parser.data/pagegrouparea) | 템플릿 기반 파싱 기능에서 문서 페이지의 다양한 유형 블록을 그룹화하는 데 사용되는 페이지 영역 그룹을 나타냅니다. |
| [PageHyperlinkArea](../com.groupdocs.parser.data/pagehyperlinkarea) | 페이지의 하이퍼링크를 나타내는 페이지 영역을 나타냅니다. |
| [PageImageArea](../com.groupdocs.parser.data/pageimagearea) | 템플릿 기반 파싱 기능에서 페이지의 이미지를 나타내는 페이지 이미지 영역 또는 이메일이나 Zip 아카이브에서 추출된 이미지인 경우 이미지 첨부 파일을 나타냅니다. |
| [PageTableArea](../com.groupdocs.parser.data/pagetablearea) | 템플릿 기반 파싱 기능에서 테이블을 나타내는 테이블 페이지 영역을 나타냅니다. |
| [PageTableAreaCell](../com.groupdocs.parser.data/pagetableareacell) | [PageTableArea](../com.groupdocs.parser.data/pagetablearea) 클래스에서 사용되는 테이블 셀을 나타냅니다. |
| [PageTextArea](../com.groupdocs.parser.data/pagetextarea) | 템플릿 파싱 또는 양식 파싱 기능에서 텍스트 값을 나타내는 페이지 텍스트 영역을 나타냅니다. |
| [Point](../com.groupdocs.parser.data/point) | 점을 나타냅니다. |
| [Rectangle](../com.groupdocs.parser.data/rectangle) | 직사각형 영역을 나타냅니다. |
| [SearchResult](../com.groupdocs.parser.data/searchresult) | 검색 기능에서 검색 결과를 나타냅니다. |
| [Size](../com.groupdocs.parser.data/size) | 크기를 나타냅니다. |
| [TextReader](../com.groupdocs.parser.data/textreader) | 연속적인 문자 시퀀스를 읽을 수 있는 리더를 나타냅니다. |
| [TextStyle](../com.groupdocs.parser.data/textstyle) | 글꼴 이름, 글꼴 크기 등과 같은 텍스트 스타일을 나타냅니다. |
| [TocItem](../com.groupdocs.parser.data/tocitem) | 목차 추출 기능에 사용되는 항목을 나타냅니다. |
