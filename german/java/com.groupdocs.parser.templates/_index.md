Das Paket stellt Klassen zum Erstellen von Vorlagen für das Parsen von Dokumentdaten bereit.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [Template](../com.groupdocs.parser.templates/template) | Stellt die Dokumentenseitenvorlage bereit. |
| [TemplateBarcode](../com.groupdocs.parser.templates/templatebarcode) | Stellt das Vorlagen-Barcode-Feld bereit. |
| [TemplateField](../com.groupdocs.parser.templates/templatefield) | Stellt das Vorlagen-Textfeld bereit. |
| [TemplateFixedPosition](../com.groupdocs.parser.templates/templatefixedposition) | Stellt eine Vorlagenfeldposition bereit, die durch den rechteckigen Bereich definiert ist. |
| [TemplateItem](../com.groupdocs.parser.templates/templateitem) | Stellt eine abstrakte Basisklasse für Vorlagenobjekte bereit. |
| [TemplateLinkedPosition](../com.groupdocs.parser.templates/templatelinkedposition) | Stellt eine Vorlagenfeldposition bereit, die das verknüpfte Feld verwendet. |
| [TemplateLinkedPositionEdges](../com.groupdocs.parser.templates/templatelinkedpositionedges) | Stellt die Kanten des verknüpften Feldes bereit, in denen das Textfeld gesucht wird. |
| [TemplateOptions](../com.groupdocs.parser.templates/templateoptions) | Stellt die Optionen bereit, die für das Parsen mittels Vorlagenfunktionalität verwendet werden. |
| [TemplatePosition](../com.groupdocs.parser.templates/templateposition) | Stellt eine abstrakte Basisklasse für Vorlagenpositionen bereit. |
| [TemplateRegexPosition](../com.groupdocs.parser.templates/templateregexposition) | Stellt eine Vorlagenfeldposition bereit, die den regulären Ausdruck verwendet. |
| [TemplateTable](../com.groupdocs.parser.templates/templatetable) | Stellt die Vorlagentabelle bereit. |
| [TemplateTableLayout](../com.groupdocs.parser.templates/templatetablelayout) | Stellt das Layout der Vorlagentabelle bereit, das von der Klasse [TemplateTable](../com.groupdocs.parser.templates/templatetable) verwendet wird, um die Tabellenposition zu definieren. |
| [TemplateTableParameters](../com.groupdocs.parser.templates/templatetableparameters) | Stellt Parameter für die Tabellenerkennungs‑Algorithmen bereit. |
