Das Paket stellt Klassen bereit, die Parsergebnisse repräsentieren.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ContainerItem](../com.groupdocs.parser.data/containeritem) | Stellt ein Containerelement dar, wie z. B. ein Zip‑Archiv‑Objekt, einen E‑Mail‑Anhang, ein PDF‑Portfolio‑Element und so weiter. |
| [DocumentData](../com.groupdocs.parser.data/documentdata) | Stellt Daten des Dokuments dar. |
| [DocumentPageData](../com.groupdocs.parser.data/documentpagedata) | Stellt Daten der Dokumentseite dar. |
| [FieldData](../com.groupdocs.parser.data/fielddata) | Stellt Felddaten dar, wie z. B. einen Namen, einen Seitenindex, einen Feldwert und so weiter. |
| [HighlightItem](../com.groupdocs.parser.data/highlightitem) | Stellt eine Hervorhebung dar, einen Teil des Textes, der normalerweise verwendet wird, um den Kontext des gefundenen Textes in der Suchfunktion zu erklären. |
| [MetadataItem](../com.groupdocs.parser.data/metadataitem) | Stellt ein Metadaten‑Element dar, das in Containerelementen und der Metadaten‑Extraktionsfunktion verwendet wird. |
| [Page](../com.groupdocs.parser.data/page) | Stellt die Informationen der Dokumentseite dar, wie Seitenindex und Seitengröße. |
| [PageArea](../com.groupdocs.parser.data/pagearea) | Stellt eine abstrakte Basisklasse für Seitenbereiche dar, die verwendet wird, um Blöcke auf der Dokumentseite in der Vorlagen‑Parsing‑Funktionalität zu repräsentieren. |
| [PageBarcodeArea](../com.groupdocs.parser.data/pagebarcodearea) | Stellt einen Seiten‑Barcode‑Bereich dar, der verwendet wird, um einen Barcode‑Wert in der Vorlagen‑Parsing‑Funktionalität zu repräsentieren. |
| [PageGroupArea](../com.groupdocs.parser.data/pagegrouparea) | Stellt eine Gruppe von Seitenbereichen dar, die verwendet wird, um verschiedene Arten von Blöcken der Dokumentseite in der Vorlagen‑Parsing‑Funktionalität zu gruppieren. |
| [PageHyperlinkArea](../com.groupdocs.parser.data/pagehyperlinkarea) | Stellt einen Seitenbereich dar, der verwendet wird, um einen Hyperlink auf der Seite zu repräsentieren. |
| [PageImageArea](../com.groupdocs.parser.data/pageimagearea) | Stellt einen Seiten‑Bild‑Bereich dar, der verwendet wird, um ein Bild auf der Seite in der Vorlagen‑Parsing‑Funktionalität zu repräsentieren oder einen Bildanhang, wenn Bilder aus E‑Mails oder Zip‑Archiven extrahiert werden. |
| [PageTableArea](../com.groupdocs.parser.data/pagetablearea) | Stellt einen Tabellen‑Seitenbereich dar, der verwendet wird, um eine Tabelle in der Vorlagen‑Parsing‑Funktionalität zu repräsentieren. |
| [PageTableAreaCell](../com.groupdocs.parser.data/pagetableareacell) | Stellt eine Tabellenzelle dar, die in der Klasse [PageTableArea](../com.groupdocs.parser.data/pagetablearea) verwendet wird. |
| [PageTextArea](../com.groupdocs.parser.data/pagetextarea) | Stellt einen Seiten‑Text‑Bereich dar, der verwendet wird, um einen Textwert im Vorlagen‑Parsing oder Formular‑Parsing zu repräsentieren. |
| [Point](../com.groupdocs.parser.data/point) | Stellt einen Punkt dar. |
| [Rectangle](../com.groupdocs.parser.data/rectangle) | Stellt einen rechteckigen Bereich dar. |
| [SearchResult](../com.groupdocs.parser.data/searchresult) | Stellt das Suchergebnis in der Suchfunktion dar. |
| [Size](../com.groupdocs.parser.data/size) | Stellt eine Größe dar. |
| [TextReader](../com.groupdocs.parser.data/textreader) | Stellt einen Reader dar, der eine sequenzielle Reihe von Zeichen lesen kann. |
| [TextStyle](../com.groupdocs.parser.data/textstyle) | Stellt den Stil des Textes dar, wie einen Schriftartnamen, eine Schriftgröße und so weiter. |
| [TocItem](../com.groupdocs.parser.data/tocitem) | Stellt das Element dar, das in der Funktionalität zur Extraktion des Inhaltsverzeichnisses verwendet wird. |
