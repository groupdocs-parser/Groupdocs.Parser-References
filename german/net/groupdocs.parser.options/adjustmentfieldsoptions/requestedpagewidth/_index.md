## AdjustmentFieldsOptions.RequestedPageWidth property

Liest oder setzt den gewünschten Seitenbreitenwert. Dieser Wert wird verwendet, um die Vorlagenfelder auf die gewünschte Seitengröße zu skalieren. Der Standardwert ist `null`, was bedeutet, dass keine Skalierung vorgenommen wird.

```csharp
public double? RequestedPageWidth { get; set; }
```

### Property Value

Der gewünschte Seitenbreitenwert.
