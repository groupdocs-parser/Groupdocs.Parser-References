## SearchOptions.SearchByPages property

Ruft den Wert ab, der angibt, ob die Suche seitenweise durchgeführt wird.

```csharp
public bool SearchByPages { get; set; }
```

### Property Value

`true` wenn die Suche seitenweise durchgeführt wird; andernfalls `false` und die Suche wird im gesamten Dokument durchgeführt, ohne den Eigenschaftswert [`PageIndex`](../../../groupdocs.parser.data/searchresult/pageindex) in der Klasse [`SearchResult`](../../../groupdocs.parser.data/searchresult) einzuschließen.
