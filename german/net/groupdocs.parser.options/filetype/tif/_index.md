## FileType.TIF field

TIF, Tagged Image File Format, steht für Rasterbilder, die für die Verwendung auf einer Vielzahl von Geräten gedacht sind, die diesem Dateiformatstandard entsprechen. Weitere Informationen zu diesem Dateiformat finden Sie [hier](https://wiki.fileformat.com/image/tiff/).
