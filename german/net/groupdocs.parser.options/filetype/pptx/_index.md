## FileType.PPTX field

Dateien mit der PPTX-Erweiterung sind Präsentationsdateien, die mit der beliebten Microsoft PowerPoint-Anwendung erstellt werden. Im Gegensatz zur vorherigen Version des Präsentationsdateiformats PPT, das binär war, basiert das PPTX-Format auf dem Microsoft PowerPoint Open XML Präsentationsdateiformat. Weitere Informationen zu diesem Dateiformat finden Sie [hier](https://wiki.fileformat.com/presentation/pptx/).
