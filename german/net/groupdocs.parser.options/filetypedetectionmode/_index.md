## FileTypeDetectionMode enumeration

Definiert einen Modus der Dateityp-Erkennung.

```csharp
public enum FileTypeDetectionMode
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Default | `0` | Der Dateityp wird anhand der Dateierweiterung erkannt; wenn die Dateierweiterung nicht erkannt wird, wird der Dateityp anhand des Dateiinhalts ermittelt. |
| Extension | `1` | Der Dateityp wird ausschließlich anhand der Dateierweiterung erkannt. |
| Content | `2` | Der Dateityp wird ausschließlich anhand des Dateiinhalts erkannt. |
