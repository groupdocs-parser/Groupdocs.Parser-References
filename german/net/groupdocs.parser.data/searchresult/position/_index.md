## SearchResult.Position property

Liefert die Position im Dokumenttext.

```csharp
public int Position { get; }
```

### Property Value

Ein nullbasierter Index der Startposition des Suchergebnisses. Abhängig vom Wert der [`SearchByPages`](../../../groupdocs.parser.options/searchoptions/searchbypages)-Eigenschaft beginnt dieser Index entweder am Dokumentanfang oder am Seitenanfang des Dokuments.
