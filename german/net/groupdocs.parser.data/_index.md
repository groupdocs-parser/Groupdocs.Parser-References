Der Namespace stellt Klassen bereit, die Parsergebnisse repräsentieren.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [AnnotationItem](./annotationitem) | Stellt ein Annotationsobjekt dar, das in der Annotations-Extraktionsfunktionalität verwendet wird. |
| [ContainerItem](./containeritem) | Stellt ein Containerelement dar, wie z. B. ein Zip‑Archiv‑Entität, E‑Mail‑Anhang, PDF‑Portfolio‑Element und so weiter. |
| [DocumentData](./documentdata) | Stellt Daten des Dokuments dar. Es besteht aus [`FieldData`](../groupdocs.parser.data/fielddata)-Objekten, die Felddaten aus dem Dokument enthalten. |
| [DocumentPageData](./documentpagedata) | Stellt Daten der Dokumentenseite dar. Es besteht aus [`FieldData`](../groupdocs.parser.data/fielddata)-Objekten, die Felddaten aus der Dokumentenseite enthalten. |
| [FieldData](./fielddata) | Stellt Felddaten wie einen Namen, einen Seitenindex, einen Feldwert usw. dar. Je nach Feld kann der Wert ein Text, ein Bild, eine Tabelle usw. sein. |
| [HighlightItem](./highlightitem) | Stellt eine Hervorhebung dar, einen Teil des Textes, der üblicherweise verwendet wird, um den Kontext des gefundenen Textes in der Suchfunktion zu erklären. |
| [MetadataItem](./metadataitem) | Stellt ein Metadaten-Element dar, das in Container-Elementen und der Metadaten-Extraktionsfunktion verwendet wird. |
| [Page](./page) | Stellt die Dokumentenseiten-Informationen wie Seitenindex und Seitengröße dar. Sie wird verwendet, um die Seite zu repräsentieren, die Erben der Klasse [`PageArea`](../groupdocs.parser.data/pagearea) in der Vorlagen-Parsing-Funktionalität enthält. |
| [PageArea](./pagearea) | Stellt eine abstrakte Basisklasse für Seitenbereiche dar, die verwendet wird, um Blöcke auf der Dokumentenseite in der Vorlagen-Parsing-Funktionalität zu repräsentieren. |
| [PageBarcodeArea](./pagebarcodearea) | Stellt einen Seiten-Barcode-Bereich dar, der verwendet wird, um einen Barcode-Wert in der Vorlagen-Parsing-Funktionalität zu repräsentieren. |
| [PageGroupArea](./pagegrouparea) | Stellt eine Gruppe von Seitenbereichen dar, die verwendet wird, um verschiedene Arten von Blöcken der Dokumentenseite in der Vorlagen-Parsing-Funktionalität zu gruppieren. |
| [PageHyperlinkArea](./pagehyperlinkarea) | Stellt einen Seitenbereich dar, der verwendet wird, um einen Hyperlink auf der Seite zu repräsentieren. |
| [PageImageArea](./pageimagearea) | Stellt einen Seiten-Bild-Bereich dar, der verwendet wird, um ein Bild auf der Seite in der Vorlagen-Parsing-Funktionalität oder einen Bildanhang zu repräsentieren, wenn Bilder aus E-Mails oder Zip-Archiven extrahiert werden. |
| [PageTableArea](./pagetablearea) | Stellt einen Tabellen-Seiten-Bereich dar, der verwendet wird, um eine Tabelle in der Vorlagen-Parsing-Funktionalität zu repräsentieren. |
| [PageTableAreaCell](./pagetableareacell) | Stellt eine Tabellenzelle dar, die in der Klasse [`PageTableArea`](../groupdocs.parser.data/pagetablearea) verwendet wird. |
| [PageTextArea](./pagetextarea) | Stellt einen Seiten-Text-Bereich dar, der verwendet wird, um einen Textwert in der Vorlagen-Parsing- oder Formular-Parsing-Funktionalität zu repräsentieren. |
| [Point](./point) | Stellt einen Punkt dar. |
| [Rectangle](./rectangle) | Stellt einen rechteckigen Bereich dar. |
| [SearchResult](./searchresult) | Stellt das Suchergebnis in der Suchfunktion dar. |
| [Size](./size) | Stellt eine Größe dar. |
| [TextStyle](./textstyle) | Stellt den Stil des Textes dar, wie einen Schriftartnamen, eine Schriftgröße usw. |
| [TocItem](./tocitem) | Stellt das Element dar, das in der Inhaltsverzeichnis-Extraktionsfunktion verwendet wird. |
| [WorksheetCell](./worksheetcell) | Stellt eine Arbeitsblattzelle dar. |
| [WorksheetInfo](./worksheetinfo) | Stellt ein Blatt-Info dar. |
| [WorksheetRange](./worksheetrange) | Stellt den Bereich bereit, der für die Arbeitsblatt-Extraktion verwendet wird. |
