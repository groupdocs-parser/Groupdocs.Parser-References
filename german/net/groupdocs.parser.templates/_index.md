Der Namespace stellt Klassen zum Erstellen von Vorlagen für das Parsen von Dokumentdaten bereit.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [Template](./template) | Stellt die Dokumentseitenvorlage bereit. Sie besteht aus [`TemplateItem`](../groupdocs.parser.templates/templateitem)-Objekten, die die Elemente der Vorlage wie Textfelder und Tabellendefinitionen darstellen. |
| [TemplateBarcode](./templatebarcode) | Stellt das Barcode‑Feld der Vorlage bereit. |
| [TemplateCollection](./templatecollection) | Stellt eine Sammlung von Dokument‑Parsing‑Vorlagen dar. |
| [TemplateField](./templatefield) | Stellt das Textfeld der Vorlage bereit. |
| [TemplateFixedPosition](./templatefixedposition) | Stellt eine Position des Vorlagenfeldes bereit, die durch den rechteckigen Bereich definiert ist. |
| [TemplateItem](./templateitem) | Stellt eine abstrakte Basisklasse für Vorlagen‑Elemente bereit. |
| [TemplateLinkedPosition](./templatelinkedposition) | Stellt eine Vorlagenfeld‑Position bereit, die das verknüpfte Feld verwendet. |
| [TemplateLinkedPositionEdges](./templatelinkedpositionedges) | Stellt die Kanten des verknüpften Feldes bereit, in dem das Textfeld gesucht wird. [`TemplateLinkedPositionEdges`](../groupdocs.parser.templates/templatelinkedpositionedges) wird in der Klasse [`TemplateLinkedPosition`](../groupdocs.parser.templates/templatelinkedposition) verwendet. |
| [TemplateOptions](./templateoptions) | Stellt die Optionen bereit, die für das Parsen mittels Vorlagen‑Funktionalität verwendet werden. |
| [TemplatePosition](./templateposition) | Stellt eine abstrakte Basisklasse für Vorlagen‑Positionen bereit. |
| [TemplateRegexPosition](./templateregexposition) | Stellt eine Vorlagenfeld‑Position bereit, die den regulären Ausdruck verwendet. |
| [TemplateTable](./templatetable) | Stellt die Tabellenvorlage bereit. |
| [TemplateTableLayout](./templatetablelayout) | Stellt das Layout der Tabellenvorlage bereit, das von der Klasse [`TemplateTable`](../groupdocs.parser.templates/templatetable) verwendet wird, um die Tabellenposition zu definieren. |
| [TemplateTableParameters](./templatetableparameters) | Stellt Parameter für die Tabellenerkennungs‑Algorithmen bereit. |
