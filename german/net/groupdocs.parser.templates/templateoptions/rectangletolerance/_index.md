## TemplateOptions.RectangleTolerance property

Liest die Größe des Randes, der beim Erfassen durch den rechteckigen Bereich ignoriert wird. Er wird als Bruchteil der Höhe eines Textelements gemessen.

```csharp
public double RectangleTolerance { get; }
```

### Rückgabewert

Der double‑Wert von 0 (kein Rand) bis 1 (das gesamte Element ignorieren).
