## MetadataItem class

Represents a metadata item used in container items and metadata extraction functionality.

An instance of [`MetadataItem`](/parser/python-net/groupdocs.parser.data/metadataitem/) is used as the return value of [`Parser.get_metadata`](/parser/python-net/groupdocs.parser/parser/get_metadata/) and as an item in the [`ContainerItem.metadata`](/parser/python-net/groupdocs.parser.data/containeritem/metadata/) collection.
