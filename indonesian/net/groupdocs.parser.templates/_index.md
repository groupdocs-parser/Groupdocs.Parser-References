Namespace menyediakan kelas untuk membuat templat dalam mengurai data dokumen.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [Template](./template) | Menyediakan templat halaman dokumen. Templat ini terdiri dari objek [`TemplateItem`](../groupdocs.parser.templates/templateitem) yang mewakili item templat seperti bidang teks dan definisi tabel. |
| [TemplateBarcode](./templatebarcode) | Menyediakan bidang barcode templat. |
| [TemplateCollection](./templatecollection) | Mewakili koleksi templat parsing dokumen. |
| [TemplateField](./templatefield) | Menyediakan bidang teks templat. |
| [TemplateFixedPosition](./templatefixedposition) | Menyediakan posisi bidang templat yang didefinisikan oleh area persegi panjang. |
| [TemplateItem](./templateitem) | Menyediakan kelas abstrak dasar untuk item templat. |
| [TemplateLinkedPosition](./templatelinkedposition) | Menyediakan posisi bidang templat yang menggunakan bidang yang ditautkan. |
| [TemplateLinkedPositionEdges](./templatelinkedpositionedges) | Menyediakan tepi bidang yang ditautkan tempat bidang teks dicari. [`TemplateLinkedPositionEdges`](../groupdocs.parser.templates/templatelinkedpositionedges) digunakan dalam kelas [`TemplateLinkedPosition`](../groupdocs.parser.templates/templatelinkedposition). |
| [TemplateOptions](./templateoptions) | Menyediakan opsi yang digunakan untuk parsing dengan fungsionalitas templat. |
| [TemplatePosition](./templateposition) | Menyediakan kelas abstrak dasar untuk posisi templat. |
| [TemplateRegexPosition](./templateregexposition) | Menyediakan posisi bidang templat yang menggunakan ekspresi reguler. |
| [TemplateTable](./templatetable) | Menyediakan tabel templat. |
| [TemplateTableLayout](./templatetablelayout) | Menyediakan tata letak tabel templat yang digunakan oleh kelas [`TemplateTable`](../groupdocs.parser.templates/templatetable) untuk menentukan posisi tabel. |
| [TemplateTableParameters](./templatetableparameters) | Menyediakan parameter untuk algoritma deteksi tabel. |
