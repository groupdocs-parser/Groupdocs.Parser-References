## FileType.ODT field

File ODT adalah jenis dokumen yang dibuat dengan aplikasi pengolah kata yang berbasis pada format OpenDocument Text File. Dokumen ini dibuat dengan aplikasi pengolah kata seperti OpenOffice Writer gratis dan dapat berisi konten seperti teks, gambar, objek, dan gaya. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/word-processing/odt/).
