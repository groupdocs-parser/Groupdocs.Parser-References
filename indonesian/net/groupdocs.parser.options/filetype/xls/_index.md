## FileType.XLS field

File dengan ekstensi XLS mewakili Excel Binary File Format. File semacam itu dapat dibuat oleh Microsoft Excel maupun program spreadsheet serupa seperti OpenOffice Calc atau Apple Numbers. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/specification/spreadsheet/xls/).
