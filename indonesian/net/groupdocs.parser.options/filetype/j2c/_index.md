## FileType.J2C field

JPEG 2000 (J2C) adalah sistem pengkodean gambar dan standar kompresi gambar mutakhir. Dirancang, menggunakan teknologi wavelet JPEG 2000 dapat mengkode konten lossless dalam kualitas apa pun sekaligus. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/image/jp2/).
