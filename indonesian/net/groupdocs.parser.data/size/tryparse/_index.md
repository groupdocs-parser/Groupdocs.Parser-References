## Size.TryParse method

Mengonversi representasi string dari ukuran menjadi setara kelasnya. Nilai kembali menunjukkan apakah konversi berhasil atau gagal.

```csharp
public static bool TryParse(string s, out Size size)
```

| Parameter | Type | Deskripsi |
| --- | --- | --- |
| s | String | String yang berisi ukuran untuk dikonversi. |
| size | Size& | Saat metode mengembalikan, ia berisi instance dari kelas [`Size`](../../size) yang setara dengan nilai yang ditentukan dalam parameter *s*, jika konversi berhasil; jika tidak, `null`. |

### Nilai Kembali

`true` jika *s* berhasil dikonversi; jika tidak, `false`.
