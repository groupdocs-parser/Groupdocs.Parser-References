Namespace menyediakan kelas yang mewakili hasil penguraian.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [AnnotationItem](./annotationitem) | Mewakili item anotasi yang digunakan dalam fungsi ekstraksi anotasi. |
| [ContainerItem](./containeritem) | Mewakili item kontainer seperti entitas arsip Zip, lampiran email, item PDF Portfolio, dan sebagainya. |
| [DocumentData](./documentdata) | Mewakili data dokumen. Terdiri dari objek [`FieldData`](../groupdocs.parser.data/fielddata) yang berisi data bidang dari dokumen. |
| [DocumentPageData](./documentpagedata) | Mewakili data halaman dokumen. Terdiri dari objek [`FieldData`](../groupdocs.parser.data/fielddata) yang berisi data bidang dari halaman dokumen. |
| [FieldData](./fielddata) | Mewakili data bidang seperti nama, indeks halaman, nilai bidang, dan sebagainya. Tergantung pada bidang, nilai dapat berupa teks, gambar, tabel, dan sebagainya. |
| [HighlightItem](./highlightitem) | Mewakili sorotan, bagian teks yang biasanya digunakan untuk menjelaskan konteks teks yang ditemukan dalam fungsi pencarian. |
| [MetadataItem](./metadataitem) | Mewakili item metadata yang digunakan dalam item kontainer dan fungsi ekstraksi metadata. |
| [Page](./page) | Mewakili informasi halaman dokumen seperti indeks halaman dan ukuran halaman. Digunakan untuk mewakili halaman yang berisi turunan kelas [`PageArea`](../groupdocs.parser.data/pagearea) dalam fungsi parsing dengan templat. |
| [PageArea](./pagearea) | Mewakili kelas dasar abstrak untuk area halaman yang digunakan untuk mewakili blok pada halaman dokumen dalam fungsi parsing dengan templat. |
| [PageBarcodeArea](./pagebarcodearea) | Mewakili area barcode halaman yang digunakan untuk mewakili nilai barcode dalam fungsi parsing dengan templat. |
| [PageGroupArea](./pagegrouparea) | Mewakili sekelompok area halaman yang digunakan untuk mengelompokkan berbagai jenis blok pada halaman dokumen dalam fungsi parsing dengan templat. |
| [PageHyperlinkArea](./pagehyperlinkarea) | Mewakili area halaman yang digunakan untuk mewakili hyperlink pada halaman. |
| [PageImageArea](./pageimagearea) | Mewakili area gambar halaman yang digunakan untuk mewakili gambar pada halaman dalam fungsi parsing dengan templat atau lampiran gambar jika gambar diekstrak dari email atau arsip Zip. |
| [PageTableArea](./pagetablearea) | Mewakili area tabel halaman yang digunakan untuk mewakili tabel dalam fungsi parsing dengan templat. |
| [PageTableAreaCell](./pagetableareacell) | Mewakili sel tabel yang digunakan dalam kelas [`PageTableArea`](../groupdocs.parser.data/pagetablearea). |
| [PageTextArea](./pagetextarea) | Mewakili area teks halaman yang digunakan untuk mewakili nilai teks dalam fungsi parsing dengan templat atau parsing formulir. |
| [Point](./point) | Mewakili sebuah titik. |
| [Rectangle](./rectangle) | Mewakili area persegi panjang. |
| [SearchResult](./searchresult) | Mewakili hasil pencarian dalam fungsi pencarian. |
| [Size](./size) | Mewakili ukuran. |
| [TextStyle](./textstyle) | Mewakili gaya teks seperti nama font, ukuran font, dan sebagainya. |
| [TocItem](./tocitem) | Mewakili item yang digunakan dalam fungsi ekstraksi daftar isi. |
| [WorksheetCell](./worksheetcell) | Mewakili sel lembar kerja. |
| [WorksheetInfo](./worksheetinfo) | Mewakili informasi lembar. |
| [WorksheetRange](./worksheetrange) | Menyediakan rentang yang digunakan untuk ekstraksi lembar kerja. |
