Paket ini menyediakan kelas yang mewakili hasil parsing.



## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [ContainerItem](../com.groupdocs.parser.data/containeritem) | Mewakili item kontainer seperti entitas arsip Zip, lampiran email, item PDF Portfolio, dan sebagainya. |
| [DocumentData](../com.groupdocs.parser.data/documentdata) | Mewakili data dokumen. |
| [DocumentPageData](../com.groupdocs.parser.data/documentpagedata) | Mewakili data halaman dokumen. |
| [FieldData](../com.groupdocs.parser.data/fielddata) | Mewakili data bidang seperti nama, indeks halaman, nilai bidang, dan sebagainya. |
| [HighlightItem](../com.groupdocs.parser.data/highlightitem) | Mewakili penyorotan, bagian teks yang biasanya digunakan untuk menjelaskan konteks teks yang ditemukan dalam fungsi pencarian. |
| [MetadataItem](../com.groupdocs.parser.data/metadataitem) | Mewakili item metadata yang digunakan dalam item kontainer dan fungsi ekstraksi metadata. |
| [Page](../com.groupdocs.parser.data/page) | Mewakili informasi halaman dokumen seperti indeks halaman dan ukuran halaman. |
| [PageArea](../com.groupdocs.parser.data/pagearea) | Mewakili kelas dasar abstrak untuk area halaman yang digunakan untuk mewakili blok pada halaman dokumen dalam fungsi parsing dengan templat. |
| [PageBarcodeArea](../com.groupdocs.parser.data/pagebarcodearea) | Mewakili area barcode halaman yang digunakan untuk mewakili nilai barcode dalam fungsi parsing dengan templat. |
| [PageGroupArea](../com.groupdocs.parser.data/pagegrouparea) | Mewakili grup area halaman yang digunakan untuk mengelompokkan berbagai jenis blok pada halaman dokumen dalam fungsi parsing dengan templat. |
| [PageHyperlinkArea](../com.groupdocs.parser.data/pagehyperlinkarea) | Mewakili area halaman yang digunakan untuk mewakili hyperlink pada halaman. |
| [PageImageArea](../com.groupdocs.parser.data/pageimagearea) | Mewakili area gambar halaman yang digunakan untuk mewakili gambar pada halaman dalam fungsi parsing dengan templat atau lampiran gambar jika gambar diekstrak dari email atau arsip Zip. |
| [PageTableArea](../com.groupdocs.parser.data/pagetablearea) | Mewakili area tabel halaman yang digunakan untuk mewakili tabel dalam fungsi parsing dengan templat. |
| [PageTableAreaCell](../com.groupdocs.parser.data/pagetableareacell) | Mewakili sel tabel yang digunakan dalam kelas [PageTableArea](../com.groupdocs.parser.data/pagetablearea). |
| [PageTextArea](../com.groupdocs.parser.data/pagetextarea) | Mewakili area teks halaman yang digunakan untuk mewakili nilai teks dalam fungsi parsing dengan templat atau parsing formulir. |
| [Point](../com.groupdocs.parser.data/point) | Mewakili titik. |
| [Rectangle](../com.groupdocs.parser.data/rectangle) | Mewakili area persegi panjang. |
| [SearchResult](../com.groupdocs.parser.data/searchresult) | Mewakili hasil pencarian dalam fungsi pencarian. |
| [Size](../com.groupdocs.parser.data/size) | Mewakili ukuran. |
| [TextReader](../com.groupdocs.parser.data/textreader) | Mewakili pembaca yang dapat membaca rangkaian karakter secara berurutan. |
| [TextStyle](../com.groupdocs.parser.data/textstyle) | Mewakili gaya teks seperti nama font, ukuran font, dan sebagainya. |
| [TocItem](../com.groupdocs.parser.data/tocitem) | Mewakili item yang digunakan dalam fungsionalitas ekstraksi daftar isi. |
