Paketet tillhandahåller klasser som representerar parsresultat.



## Klasser

| Klass | Beskrivning |
| --- | --- |
| [ContainerItem](../com.groupdocs.parser.data/containeritem) | Representerar ett containerobjekt som Zip-arkivpost, e-postbilaga, PDF‑portföljobjekt och så vidare. |
| [DocumentData](../com.groupdocs.parser.data/documentdata) | Representerar dokumentets data. |
| [DocumentPageData](../com.groupdocs.parser.data/documentpagedata) | Representerar data för dokumentsidan. |
| [FieldData](../com.groupdocs.parser.data/fielddata) | Representerar fältdata såsom ett namn, ett sidindex, ett fältvärde och så vidare. |
| [HighlightItem](../com.groupdocs.parser.data/highlightitem) | Representerar en markering, en del av texten som vanligtvis används för att förklara sammanhanget för den hittade texten i sökfunktionen. |
| [MetadataItem](../com.groupdocs.parser.data/metadataitem) | Representerar ett metadataobjekt som används i containerobjekt och metadataextraktionsfunktionalitet. |
| [Page](../com.groupdocs.parser.data/page) | Representerar information om dokumentsidan såsom sidindex och sidstorlek. |
| [PageArea](../com.groupdocs.parser.data/pagearea) | Representerar en abstrakt basklass för sidområden som används för att representera block på dokumentsidan i funktionaliteten för parsning med mall. |
| [PageBarcodeArea](../com.groupdocs.parser.data/pagebarcodearea) | Representerar ett sidområde för streckkod som används för att representera ett streckkodsvärde i funktionaliteten för parsning med mall. |
| [PageGroupArea](../com.groupdocs.parser.data/pagegrouparea) | Representerar en grupp av sidområden som används för att gruppera olika typer av block på dokumentsidan i funktionaliteten för parsning med mall. |
| [PageHyperlinkArea](../com.groupdocs.parser.data/pagehyperlinkarea) | Representerar ett sidområde som används för att representera en hyperlänk på sidan. |
| [PageImageArea](../com.groupdocs.parser.data/pageimagearea) | Representerar ett sidområde för bild som används för att representera en bild på sidan i funktionaliteten för parsning med mall eller en bildbilaga om bilder extraheras från e‑post eller Zip‑arkiv. |
| [PageTableArea](../com.groupdocs.parser.data/pagetablearea) | Representerar ett sidområde för tabell som används för att representera en tabell i funktionaliteten för parsning med mall. |
| [PageTableAreaCell](../com.groupdocs.parser.data/pagetableareacell) | Representerar en tabellcell som används i klassen [PageTableArea](../com.groupdocs.parser.data/pagetablearea). |
| [PageTextArea](../com.groupdocs.parser.data/pagetextarea) | Representerar ett sidområde för text som används för att representera ett textvärde i funktionaliteten för parsning med mall eller formulärparsning. |
| [Point](../com.groupdocs.parser.data/point) | Representerar en punkt. |
| [Rectangle](../com.groupdocs.parser.data/rectangle) | Representerar ett rektangulärt område. |
| [SearchResult](../com.groupdocs.parser.data/searchresult) | Representerar sökresultatet i sökfunktionen. |
| [Size](../com.groupdocs.parser.data/size) | Representerar en storlek. |
| [TextReader](../com.groupdocs.parser.data/textreader) | Representerar en läsare som kan läsa en sekventiell serie av tecken. |
| [TextStyle](../com.groupdocs.parser.data/textstyle) | Representerar textens stil såsom ett typsnittsnamn, en typsnittsstorlek och så vidare. |
| [TocItem](../com.groupdocs.parser.data/tocitem) | Representerar objektet som används i funktionaliteten för extrahering av innehållsförteckning. |
