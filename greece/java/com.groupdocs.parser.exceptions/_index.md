Το πακέτο παρέχει διαφορετικές κλάσεις εξαιρέσεων.



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [CorruptedDocumentException](../com.groupdocs.parser.exceptions/corrupteddocumentexception) | Εκτοπίζεται κατά τη φόρτωση του εγγράφου, όταν το έγγραφο είναι κατεστραμμένο. |
| [GroupDocsParserException](../com.groupdocs.parser.exceptions/groupdocsparserexception) | Αντιπροσωπεύει τα σφάλματα που εμφανίζονται κατά την εκτέλεση της εφαρμογής. |
| [InvalidPasswordException](../com.groupdocs.parser.exceptions/invalidpasswordexception) | Εκτοπίζεται εάν ένα έγγραφο είναι κρυπτογραφημένο με κωδικό πρόσβασης και ο κωδικός που καθορίζεται κατά το άνοιγμα του εγγράφου είναι λανθασμένος ή λείπει. |
| [UnsupportedDocumentFormatException](../com.groupdocs.parser.exceptions/unsupporteddocumentformatexception) | Εκτοπίζεται κατά τη φόρτωση του εγγράφου, όταν η μορφή του εγγράφου δεν αναγνωρίζεται ή δεν υποστηρίζεται. |
