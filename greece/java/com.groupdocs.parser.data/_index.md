Το πακέτο παρέχει κλάσεις που αντιπροσωπεύουν τα αποτελέσματα ανάλυσης.



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ContainerItem](../com.groupdocs.parser.data/containeritem) | Αντιπροσωπεύει ένα στοιχείο κοντέινερ όπως οντότητα αρχείου Zip, συνημμένο email, στοιχείο PDF Portfolio κ.λπ. |
| [DocumentData](../com.groupdocs.parser.data/documentdata) | Αντιπροσωπεύει τα δεδομένα του εγγράφου. |
| [DocumentPageData](../com.groupdocs.parser.data/documentpagedata) | Αντιπροσωπεύει τα δεδομένα της σελίδας του εγγράφου. |
| [FieldData](../com.groupdocs.parser.data/fielddata) | Αντιπροσωπεύει δεδομένα πεδίου όπως όνομα, δείκτη σελίδας, τιμή πεδίου κ.λπ. |
| [HighlightItem](../com.groupdocs.parser.data/highlightitem) | Αντιπροσωπεύει μια επισήμανση, ένα τμήμα του κειμένου που συνήθως χρησιμοποιείται για την εξήγηση του πλαισίου του ευρεθέντος κειμένου στη λειτουργία αναζήτησης. |
| [MetadataItem](../com.groupdocs.parser.data/metadataitem) | Αντιπροσωπεύει ένα στοιχείο μεταδεδομένων που χρησιμοποιείται σε στοιχεία κοντέινερ και στη λειτουργία εξαγωγής μεταδεδομένων. |
| [Page](../com.groupdocs.parser.data/page) | Αντιπροσωπεύει τις πληροφορίες της σελίδας του εγγράφου όπως δείκτης σελίδας και μέγεθος σελίδας. |
| [PageArea](../com.groupdocs.parser.data/pagearea) | Αντιπροσωπεύει μια αφηρημένη βασική κλάση για περιοχές σελίδας που χρησιμοποιούνται για την αναπαράσταση μπλοκ στη σελίδα του εγγράφου στη λειτουργία ανάλυσης με πρότυπο. |
| [PageBarcodeArea](../com.groupdocs.parser.data/pagebarcodearea) | Αντιπροσωπεύει μια περιοχή barcode στη σελίδα που χρησιμοποιείται για την αναπαράσταση της τιμής barcode στη λειτουργία ανάλυσης με πρότυπο. |
| [PageGroupArea](../com.groupdocs.parser.data/pagegrouparea) | Αντιπροσωπεύει μια ομάδα περιοχών σελίδας που χρησιμοποιείται για την ομαδοποίηση διαφορετικών τύπων μπλοκ της σελίδας του εγγράφου στη λειτουργία ανάλυσης με πρότυπο. |
| [PageHyperlinkArea](../com.groupdocs.parser.data/pagehyperlinkarea) | Αντιπροσωπεύει μια περιοχή σελίδας που χρησιμοποιείται για την αναπαράσταση ενός υπερσυνδέσμου στη σελίδα. |
| [PageImageArea](../com.groupdocs.parser.data/pageimagearea) | Αντιπροσωπεύει μια περιοχή εικόνας σελίδας που χρησιμοποιείται για την αναπαράσταση μιας εικόνας στη σελίδα στη λειτουργία ανάλυσης με πρότυπο ή ένα συνημμένο εικόνας εάν οι εικόνες εξάγονται από email ή αρχεία Zip. |
| [PageTableArea](../com.groupdocs.parser.data/pagetablearea) | Αντιπροσωπεύει μια περιοχή πίνακα σελίδας που χρησιμοποιείται για την αναπαράσταση πίνακα στη λειτουργία ανάλυσης με πρότυπο. |
| [PageTableAreaCell](../com.groupdocs.parser.data/pagetableareacell) | Αντιπροσωπεύει ένα κελί πίνακα που χρησιμοποιείται στην κλάση [PageTableArea](../com.groupdocs.parser.data/pagetablearea). |
| [PageTextArea](../com.groupdocs.parser.data/pagetextarea) | Αντιπροσωπεύει μια περιοχή κειμένου σελίδας που χρησιμοποιείται για την αναπαράσταση μιας τιμής κειμένου στη λειτουργία ανάλυσης με πρότυπο ή ανάλυσης φορμών. |
| [Point](../com.groupdocs.parser.data/point) | Αντιπροσωπεύει ένα σημείο. |
| [Rectangle](../com.groupdocs.parser.data/rectangle) | Αντιπροσωπεύει μια ορθογώνια περιοχή. |
| [SearchResult](../com.groupdocs.parser.data/searchresult) | Αντιπροσωπεύει το αποτέλεσμα αναζήτησης στη λειτουργία αναζήτησης. |
| [Size](../com.groupdocs.parser.data/size) | Αντιπροσωπεύει ένα μέγεθος. |
| [TextReader](../com.groupdocs.parser.data/textreader) | Αντιπροσωπεύει έναν αναγνώστη που μπορεί να διαβάσει μια διαδοχική σειρά χαρακτήρων. |
| [TextStyle](../com.groupdocs.parser.data/textstyle) | Αντιπροσωπεύει το στυλ του κειμένου όπως όνομα γραμματοσειράς, μέγεθος γραμματοσειράς κ.λπ. |
| [TocItem](../com.groupdocs.parser.data/tocitem) | Αντιπροσωπεύει το στοιχείο που χρησιμοποιείται στη λειτουργία εξαγωγής πίνακα περιεχομένων. |
