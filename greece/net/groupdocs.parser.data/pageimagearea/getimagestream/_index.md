## GetImageStream() {#getimagestream}

Επιστρέφει τη ροή της εικόνας.

```csharp
public Stream GetImageStream()
```

### Τιμή επιστροφής

Ένα ρεύμα με την εικόνα.

### Παραδείγματα

Το παρακάτω παράδειγμα δείχνει πώς να αποθηκεύσετε εικόνες σε αρχεία:

```csharp
// Δημιουργήστε μια παρουσία της κλάσης Parser
using (Parser parser = new Parser(filePath))
{
    // Εξαγωγή εικόνων από το έγγραφο
    IEnumerable<PageImageArea> images = parser.GetImages();
    
    // Έλεγχος εάν η εξαγωγή εικόνων υποστηρίζεται
    if (images == null)
    {
        Console.WriteLine("Page images extraction isn't supported");
        return;
    }

    // Επανάληψη πάνω από τις εικόνες
    foreach (PageImageArea image in images)
    {
        // Ανοίξτε τη ροή της εικόνας
        using (Stream imageStream = image.GetImageStream())
        {
            // Δημιουργήστε το αρχείο για αποθήκευση της εικόνας
            using (Stream destStream = File.Create(Guid.NewGuid().ToString() + image.FileType.Extension))
            {
                byte[] buffer = new byte[4096];
                int readed = 0;

                do
                {
                    // Διαβάστε δεδομένα από τη ροή της εικόνας
                    readed = imageStream.Read(buffer, 0, buffer.Length);

                    if (readed > 0)
                    {
                        // Γράψτε δεδομένα στη ροή του αρχείου
                        destStream.Write(buffer, 0, readed);
                    }
                }
                while (readed > 0);
            }
        }
    }
}
```

using (Parser parser = new Parser(filePath))

    // Εξαγωγή εικόνων από το έγγραφο
    IEnumerable<PageImageArea> images = parser.GetImages();
    
    // Έλεγχος εάν η εξαγωγή εικόνων υποστηρίζεται

                    // Διαβάστε δεδομένα από τη ροή της εικόνας
                    readed = imageStream.Read(buffer, 0, buffer.Length);

                    if (readed > 0)
                    {
                        // Γράψτε δεδομένα στη ροή του αρχείου
                        destStream.Write(buffer, 0, readed);
                    }
                }
                while (readed > 0);
            }
        }
    }
}
