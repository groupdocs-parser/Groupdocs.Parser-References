### Παραδείγματα

Το παρακάτω παράδειγμα δείχνει πώς να αποθηκεύσετε εικόνες σε αρχεία:

```csharp
// Δημιουργήστε μια παρουσία της κλάσης Parser
using (Parser parser = new Parser(filePath))
{
    // Εξαγωγή εικόνων από το έγγραφο
    IEnumerable<PageImageArea> images = parser.GetImages();
    
    // Έλεγχος εάν η εξαγωγή εικόνων υποστηρίζεται
    if (images == null)
    {
        Console.WriteLine("Page images extraction isn't supported");
        return;
    }

    // Επανάληψη πάνω από τις εικόνες
    foreach (PageImageArea image in images)
    {
        // Αποθηκεύστε την εικόνα στο αρχείο
        image.Save(Guid.NewGuid().ToString() + image.FileType.Extension);
    }
}
```

### Παραδείγματα

Το παρακάτω παράδειγμα δείχνει πώς να αποθηκεύσετε εικόνες σε αρχεία σε διαφορετική μορφή:

```csharp
// Δημιουργήστε μια παρουσία της κλάσης Parser
using (Parser parser = new Parser(filePath))
{
    // Εξαγωγή εικόνων από το έγγραφο
    IEnumerable<PageImageArea> images = parser.GetImages();
    
    // Έλεγχος εάν η εξαγωγή εικόνων υποστηρίζεται
    if (images == null)
    {
        Console.WriteLine("Page images extraction isn't supported");
        return;
    }

    // Δημιουργήστε τις επιλογές για αποθήκευση εικόνων σε μορφή PNG
    ImageOptions options = new ImageOptions(ImageFormat.Png);
    
    // Επανάληψη πάνω από τις εικόνες
    foreach (PageImageArea image in images)
    {
        // Αποθηκεύστε την εικόνα στο αρχείο png
        image.Save(Guid.NewGuid().ToString() + ".png", options);
    }
}
```
