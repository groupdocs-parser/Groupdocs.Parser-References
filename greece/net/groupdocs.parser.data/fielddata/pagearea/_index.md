## FieldData.PageArea property

Λαμβάνει την τιμή του πεδίου.

```csharp
public PageArea PageArea { get; }
```

### Property Value

Μία παρουσία της κλάσης [`PageArea`](../../pagearea) που αντιπροσωπεύει την τιμή του πεδίου.

### Παραδείγματα

Ανάλογα με το πεδίο, η ιδιότητα `PageArea` μπορεί να περιέχει οποιονδήποτε από τους κληρονόμους της κλάσης [`PageArea`](../../pagearea). Για παράδειγμα, η μέθοδος [`ParseForm`](../../../groupdocs.parser/parser/parseform) εξάγει μόνο πεδία κειμένου.

```csharp
// Απόκτηση των δεδομένων του πεδίου
FieldData field = data[i];
// Ελέγξτε αν τα δεδομένων του πεδίου περιέχουν κείμενο
if(field.PageArea is PageTextArea)
{
    // Εκτυπώστε την τιμή κειμένου του πεδίου
    Console.WriteLine(field.Text);
}
```
