## ContainerItem.DetectFileType method

Ανιχνεύει τον τύπο αρχείου του στοιχείου container.

```csharp
public FileType DetectFileType(FileTypeDetectionMode detectionMode)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| detectionMode | FileTypeDetectionMode | Ορίζει μια λειτουργία ανίχνευσης τύπου αρχείου. |

### Τιμή επιστροφής

Μία παρουσία της κλάσης [`FileType`](../../../groupdocs.parser.options/filetype); [`Unknown`](../../../groupdocs.parser.options/filetype/unknown) εάν δεν εντοπιστεί τύπος αρχείου.

### Σχόλια

*detectionMode* parameter provides the ability to control file type detection:

* **Default**. The file type is detected by the file extension; if the file extension isn't recognized, the file type is detected by the file content.
* **Extension**.The file type is detected only by the file extension.
* **Content**. The file type is detected only by the file content.

### Παραδείγματα

Το παρακάτω παράδειγμα δείχνει πώς να εντοπιστεί ο τύπος αρχείου του στοιχείου του δοχείου:

```csharp
// Δημιουργήστε μια παρουσία της κλάσης Parser
using (Parser parser = new Parser(filePath))
{
    // Εξαγωγή συνημμένων από το δοχείο
    IEnumerable<ContainerItem> attachments = parser.GetContainer();
    // Ελέγξτε αν η εξαγωγή του container υποστηρίζεται
    if (attachments == null)
    {
        Console.WriteLine("Container extraction isn't supported");
    }
    // Επανάληψη στα συνημμένα
    foreach (ContainerItem item in attachments)
    {
        // Ανίχνευση του τύπου αρχείου
        Options.FileType fileType = item.DetectFileType(Options.FileTypeDetectionMode.Default);

        // Εκτύπωση του ονόματος και του τύπου αρχείου
        Console.WriteLine(string.Format("{0}: {1}", item.Name, fileType));
    }
}
```
