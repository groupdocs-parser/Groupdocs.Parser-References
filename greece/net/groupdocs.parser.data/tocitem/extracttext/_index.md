## TocItem.ExtractText method

Εξάγει κείμενο από το έγγραφο στο οποίο αναφέρεται το αντικείμενο [`TocItem`](../../tocitem).

```csharp
public virtual TextReader ExtractText()
```

### Τιμή επιστροφής

Μία παρουσία της κλάσης TextReader με το εξαγόμενο κείμενο.

### Παραδείγματα

Το παρακάτω παράδειγμα δείχνει πώς να εξάγετε κείμενο από ένα στοιχείο του πίνακα περιεχομένων:

```csharp
// Δημιουργήστε μια παρουσία της κλάσης Parser
using (Parser parser = new Parser(Constants.SampleDocxWithToc))
{
    // Αποκτήστε τον πίνακα περιεχομένων
    IEnumerable<TocItem> tocItems = parser.GetToc();
    // Ελέγξτε αν η εξαγωγή toc υποστηρίζεται
    if (tocItems == null)
    {
        Console.WriteLine("Table of contents extraction isn't supported");
    }
    // Επανάληψη στα στοιχεία
    foreach (TocItem tocItem in tocItems)
    {
        // Εκτυπώστε το κείμενο του κεφαλαίου
        using (TextReader reader = tocItem.ExtractText())
        {
            Console.WriteLine("----");
            Console.WriteLine(reader.ReadToEnd());
        }
    }
}
```
