Ονοματοχώρος παρέχει κλάσεις που αντιπροσωπεύουν τα αποτελέσματα ανάλυσης.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [AnnotationItem](./annotationitem) | Αντιπροσωπεύει ένα στοιχείο σημείωσης που χρησιμοποιείται στη λειτουργία εξαγωγής σημειώσεων. |
| [ContainerItem](./containeritem) | Αντιπροσωπεύει ένα στοιχείο κοντέινερ όπως οντότητα αρχείου Zip, συνημμένο email, στοιχείο PDF Portfolio κ.λπ. |
| [DocumentData](./documentdata) | Αναπαριστά τα δεδομένα του εγγράφου. Αποτελείται από αντικείμενα [`FieldData`](../groupdocs.parser.data/fielddata) που περιέχουν δεδομένα πεδίου από το έγγραφο. |
| [DocumentPageData](./documentpagedata) | Αναπαριστά τα δεδομένα της σελίδας του εγγράφου. Αποτελείται από αντικείμενα [`FieldData`](../groupdocs.parser.data/fielddata) που περιέχουν δεδομένα πεδίου από τη σελίδα του εγγράφου. |
| [FieldData](./fielddata) | Αναπαριστά δεδομένα πεδίου όπως όνομα, δείκτη σελίδας, τιμή πεδίου κ.λπ. Ανάλογα με το πεδίο, η τιμή μπορεί να είναι κείμενο, εικόνα, πίνακας κ.λπ. |
| [HighlightItem](./highlightitem) | Αναπαριστά μια επισήμανση, ένα τμήμα του κειμένου που συνήθως χρησιμοποιείται για να εξηγήσει το πλαίσιο του ευρεθέντος κειμένου στη λειτουργία αναζήτησης. |
| [MetadataItem](./metadataitem) | Αναπαριστά ένα στοιχείο μεταδεδομένων που χρησιμοποιείται σε στοιχεία κοντέινερ και στη λειτουργία εξαγωγής μεταδεδομένων. |
| [Page](./page) | Αναπαριστά τις πληροφορίες της σελίδας του εγγράφου όπως δείκτης σελίδας και μέγεθος σελίδας. Χρησιμοποιείται για να αναπαραστήσει τη σελίδα που περιέχει κληρονόμους της κλάσης [`PageArea`](../groupdocs.parser.data/pagearea) στη λειτουργία ανάλυσης με πρότυπο. |
| [PageArea](./pagearea) | Αναπαριστά μια αφηρημένη βασική κλάση για περιοχές σελίδας που χρησιμοποιούνται για την αναπαράσταση μπλοκ στη σελίδα του εγγράφου στη λειτουργία ανάλυσης με πρότυπο. |
| [PageBarcodeArea](./pagebarcodearea) | Αναπαριστά μια περιοχή barcode σελίδας που χρησιμοποιείται για την αναπαράσταση τιμής barcode στη λειτουργία ανάλυσης με πρότυπο. |
| [PageGroupArea](./pagegrouparea) | Αναπαριστά μια ομάδα περιοχών σελίδας που χρησιμοποιείται για ομαδοποίηση διαφορετικών τύπων μπλοκ της σελίδας του εγγράφου στη λειτουργία ανάλυσης με πρότυπο. |
| [PageHyperlinkArea](./pagehyperlinkarea) | Αναπαριστά μια περιοχή σελίδας που χρησιμοποιείται για την αναπαράσταση υπερσυνδέσμου στη σελίδα. |
| [PageImageArea](./pageimagearea) | Αναπαριστά μια περιοχή εικόνας σελίδας που χρησιμοποιείται για την αναπαράσταση εικόνας στη σελίδα στη λειτουργία ανάλυσης με πρότυπο ή ως συνημμένο εικόνας εάν οι εικόνες εξάγονται από email ή αρχεία Zip. |
| [PageTableArea](./pagetablearea) | Αναπαριστά μια περιοχή πίνακα σελίδας που χρησιμοποιείται για την αναπαράσταση πίνακα στη λειτουργία ανάλυσης με πρότυπο. |
| [PageTableAreaCell](./pagetableareacell) | Αναπαριστά ένα κελί πίνακα που χρησιμοποιείται στην κλάση [`PageTableArea`](../groupdocs.parser.data/pagetablearea). |
| [PageTextArea](./pagetextarea) | Αναπαριστά μια περιοχή κειμένου σελίδας που χρησιμοποιείται για την αναπαράσταση τιμής κειμένου στη λειτουργία ανάλυσης με πρότυπο ή ανάλυσης φορμών. |
| [Point](./point) | Αναπαριστά ένα σημείο. |
| [Rectangle](./rectangle) | Αναπαριστά μια ορθογώνια περιοχή. |
| [SearchResult](./searchresult) | Αναπαριστά το αποτέλεσμα αναζήτησης στη λειτουργία αναζήτησης. |
| [Size](./size) | Αναπαριστά ένα μέγεθος. |
