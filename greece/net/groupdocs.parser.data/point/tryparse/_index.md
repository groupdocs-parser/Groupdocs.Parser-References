| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| s | String | Μια συμβολοσειρά που περιέχει ένα σημείο για μετατροπή. |
| point | Point& | Όταν η μέθοδος επιστρέφει, περιέχει την παρουσία της κλάσης [`Point`](../../point) που είναι ισοδύναμη με την τιμή που καθορίζεται στην παράμετρο *s*, εάν η μετατροπή ολοκληρωθεί επιτυχώς· διαφορετικά, `null`. |
