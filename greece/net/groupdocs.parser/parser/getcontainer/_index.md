## Parser.GetContainer method

Εξάγει ένα αντικείμενο container από το έγγραφο για εργασία με μορφές που περιέχουν συνημμένα, αρχεία ZIP κ.λπ.

```csharp
public IEnumerable<ContainerItem> GetContainer()
```

### Τιμή επιστροφής

Μια συλλογή αντικειμένων container· `null` εάν η εξαγωγή container δεν υποστηρίζεται.

### Παραδείγματα

Το παρακάτω παράδειγμα δείχνει πώς να εξάγετε συνημμένα από ένα container:

```csharp
// Δημιουργήστε μια παρουσία της κλάσης Parser
using(Parser parser = new Parser(filePath))
{
    // Εξαγωγή συνημμένων από το δοχείο
    IEnumerable<ContainerItem> attachments = parser.GetContainer();
    // Ελέγξτε αν η εξαγωγή του container υποστηρίζεται
    if(attachments == null)
    {
        Console.WriteLine("Container extraction isn't supported");
    }
 
    // Επανάληψη στα συνημμένα
    foreach(ContainerItem item in attachments)
    {
        // Εκτυπώστε το όνομα και το μέγεθος ενός αντικειμένου
        Console.WriteLine(string.Format("{0}: {1}", item.Name, item.Size));
    }
}
```
