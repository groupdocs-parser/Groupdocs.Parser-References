## Parser.GetToc method

### Τιμή επιστροφής

Μια συλλογή στοιχείων πίνακα περιεχομένων· `null` εάν η εξαγωγή πίνακα περιεχομένων δεν υποστηρίζεται.

### Παραδείγματα

Το παρακάτω παράδειγμα δείχνει πώς να εξάγετε τον πίνακα περιεχομένων από αρχείο CHM:

```csharp
// Δημιουργήστε μια παρουσία της κλάσης Parser
using (Parser parser = new Parser(filePath))
{
    // Ελέγξτε εάν η εξαγωγή κειμένου υποστηρίζεται
    if (!parser.Features.Text)
    {
        Console.WriteLine("Text extraction isn't supported.");
        return;
    }

    // Ελέγξτε αν η εξαγωγή toc υποστηρίζεται
    if (!parser.Features.Toc)
    {
        Console.WriteLine("Toc extraction isn't supported.");
        return;
    }
 
    // Αποκτήστε τον πίνακα περιεχομένων
    IEnumerable<TocItem> toc = parser.GetToc();
    
    // Επανάληψη στα στοιχεία
    foreach (TocItem i in toc)
    {
        // Εκτυπώστε το κείμενο του Πίνακα Περιεχομένων
        Console.WriteLine(i.Text);
        // Ελέγξτε εάν ο δείκτης σελίδας έχει τιμή
        if (i.PageIndex == null)
        {
            continue;
        }
        // Εξάγετε το κείμενο μιας σελίδας
        using (TextReader reader = parser.GetText(i.PageIndex.Value))
        {
            Console.WriteLine(reader.ReadToEnd());
        }
    }
}
```
