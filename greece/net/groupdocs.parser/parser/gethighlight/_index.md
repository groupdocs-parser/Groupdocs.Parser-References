## Parser.GetHighlight method

Εξάγει επισήμανση από το έγγραφο.

```csharp
public HighlightItem GetHighlight(int position, bool isDirect, HighlightOptions options)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| θέση | Int32 | Η αρχική θέση της επισήμανσης. |
| isDirect | Boolean | Η τιμή που υποδεικνύει εάν η εξαγωγή της επισήμανσης είναι άμεση. `true` εάν η επισήμανση εξάγεται δεξιά της *position*; διαφορετικά, `false`. |
| options | HighlightOptions | Οι επιλογές εξαγωγής της επισήμανσης. |

### Τιμή επιστροφής

Μια παρουσία της κλάσης [`HighlightItem`](../../../groupdocs.parser.data/highlightitem) που αντιπροσωπεύει την εξαγόμενη επισήμανση· `null` εάν η εξαγωγή της επισήμανσης δεν υποστηρίζεται.

### Παραδείγματα

Το παρακάτω παράδειγμα δείχνει πώς να εξάγετε μια επισήμανση που περιέχει 3 λέξεις:

```csharp
// Δημιουργήστε μια παρουσία της κλάσης Parser
using (Parser parser = new Parser(filePath))
{
    // Εξάγετε μια επισήμανση:
    HighlightItem hl = parser.GetHighlight(2, true, new HighlightOptions(3));
    
    // Ελέγξτε αν η εξαγωγή της επισήμανσης υποστηρίζεται
    if (hl == null)
    {
        Console.WriteLine("Highlight extraction isn't supported");
        return;
    }
    
    // Εκτυπώστε μια εξαγόμενη επισήμανση
    Console.WriteLine(string.Format("At {0}: {1}", hl.Position, hl.Text));
}
```
