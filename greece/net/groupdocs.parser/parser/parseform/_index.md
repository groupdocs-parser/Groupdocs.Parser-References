## Parser.ParseForm method

Αναλύει τη φόρμα του εγγράφου.

public DocumentData ParseForm()

### Τιμή επιστροφής

Ένα στιγμιότυπο της κλάσης [`DocumentData`](../../../groupdocs.parser.data/documentdata) που περιέχει τα εξαγόμενα δεδομένα· `null` εάν η ανάλυση με πρότυπο δεν υποστηρίζεται.

### Παραδείγματα

Το παρακάτω παράδειγμα δείχνει πώς να αναλύσετε μια φόρμα του εγγράφου:

```csharp
// Δημιουργήστε μια παρουσία της κλάσης Parser
using (Parser parser = new Parser(filePath))
{
    // Εξαγωγή δεδομένων από έγγραφο PDF
    DocumentData data = parser.ParseForm();
    // Επανάληψη πάνω στα εξαγόμενα δεδομένα
    for (int i = 0; i<data.Count; i++)
    {
        Console.Write(data[i].Name + ": ");
        PageTextArea area = data[i].PageArea as PageTextArea;
        Console.WriteLine(area == null ? "Not a template field" : area.Text);
    }
}
```
