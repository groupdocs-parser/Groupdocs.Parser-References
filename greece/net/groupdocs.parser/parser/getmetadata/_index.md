### Παραδείγματα

Το παρακάτω παράδειγμα δείχνει πώς να εξάγετε μεταδεδομένα από ένα έγγραφο:

```csharp
// Δημιουργήστε μια παρουσία της κλάσης Parser
using(Parser parser = new Parser(filePath))
{
    // Εξαγωγή μεταδεδομένων από το έγγραφο
    IEnumerable<MetadataItem> metadata = parser.GetMetadata();
    // Ελέγξτε αν η εξαγωγή μεταδεδομένων υποστηρίζεται
    if(metadata == null)
    {
        Console.WriteLine("Metatada extraction isn't supported");
    }
 
    // Επανάληψη πάνω στα στοιχεία μεταδεδομένων
    foreach(MetadataItem item in metadata)
    {
        // Εκτυπώστε το όνομα και την τιμή ενός στοιχείου
        Console.WriteLine(string.Format("{0}: {1}", item.Name, item.Value));
    }
}
```
