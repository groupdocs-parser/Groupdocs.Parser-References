### Παραδείγματα

Το παρακάτω παράδειγμα δείχνει την κατάσταση εάν το έγγραφο περιέχει "Invoice Number INV-12345" τότε το πεδίο προτύπου μπορεί να οριστεί με τον ακόλουθο τρόπο:

```csharp
// Δημιουργήστε ένα πεδίο προτύπου regex με όνομα "InvoiceNumber"
TemplateField templateField = new TemplateField(
    new TemplateRegexPosition("Invoice Number\\s+[A-Z0-9\\-]+"),
    "InvoiceNumber");
```

Σε αυτή την περίπτωση, ως τιμή εξάγεται ολόκληρη η συμβολοσειρά. Για να εξαχθεί μόνο ένα μέρος της συμβολοσειράς, χρησιμοποιείται η ομάδα κανονικής έκφρασης "value".

```csharp
// Δημιουργήστε ένα πεδίο προτύπου regex με όνομα "InvoiceNumber" με την ομάδα "value"
TemplateField templateField = new TemplateField(
    new TemplateRegexPosition("Invoice Number\\s+(?<value>[A-Z0-9\\-]+)"),
    "InvoiceNumber");
```

Σε αυτή την περίπτωση, ως τιμή εξάγεται η συμβολοσειρά "INV-3337".
