Ονοματοχώρος παρέχει κλάσεις για τη δημιουργία προτύπων για την ανάλυση δεδομένων εγγράφων.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [Template](./template) | Παρέχει το πρότυπο σελίδας εγγράφου. Αποτελείται από αντικείμενα [`TemplateItem`](../groupdocs.parser.templates/templateitem) που αντιπροσωπεύουν τα στοιχεία του προτύπου, όπως το πεδίο κειμένου και τους ορισμούς πινάκων. |
| [TemplateBarcode](./templatebarcode) | Παρέχει το πεδίο barcode του προτύπου. |
| [TemplateCollection](./templatecollection) | Αντιπροσωπεύει μια συλλογή προτύπων ανάλυσης εγγράφων. |
| [TemplateField](./templatefield) | Παρέχει το πεδίο κειμένου του προτύπου. |
| [TemplateFixedPosition](./templatefixedposition) | Παρέχει τη θέση του πεδίου προτύπου που ορίζεται από την ορθογώνια περιοχή. |
| [TemplateItem](./templateitem) | Παρέχει μια βασική αφηρημένη κλάση για τα στοιχεία του προτύπου. |
| [TemplateLinkedPosition](./templatelinkedposition) | Παρέχει τη θέση του πεδίου προτύπου που χρησιμοποιεί το συνδεδεμένο πεδίο. |
| [TemplateLinkedPositionEdges](./templatelinkedpositionedges) | Παρέχει τις άκρες του συνδεδεμένου πεδίου όπου αναζητείται το πεδίο κειμένου. [`TemplateLinkedPositionEdges`](../groupdocs.parser.templates/templatelinkedpositionedges) χρησιμοποιείται στην κλάση [`TemplateLinkedPosition`](../groupdocs.parser.templates/templatelinkedposition). |
| [TemplateOptions](./templateoptions) | Παρέχει τις επιλογές που χρησιμοποιούνται για την ανάλυση μέσω της λειτουργικότητας προτύπου. |
| [TemplatePosition](./templateposition) | Παρέχει μια βασική αφηρημένη κλάση για τις θέσεις του προτύπου. |
| [TemplateRegexPosition](./templateregexposition) | Παρέχει τη θέση του πεδίου προτύπου που χρησιμοποιεί την κανονική έκφραση. |
| [TemplateTable](./templatetable) | Παρέχει τον πίνακα προτύπου. |
| [TemplateTableLayout](./templatetablelayout) | Παρέχει τη διάταξη του πίνακα προτύπου που χρησιμοποιείται από την κλάση [`TemplateTable`](../groupdocs.parser.templates/templatetable) για τον ορισμό της θέσης του πίνακα. |
| [TemplateTableParameters](./templatetableparameters) | Παρέχει παραμέτρους για τους αλγόριθμους ανίχνευσης πινάκων. |
