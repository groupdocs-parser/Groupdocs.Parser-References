### Τιμή επιστροφής

Μια νέα διάταξη με το ίδιο μέγεθος, διαχωριστές και θέση στο *point*.

### Παραδείγματα

Αυτή η λειτουργία επιτρέπει τη μετακίνηση της διάταξης πίνακα.

Για παράδειγμα, ένα έγγραφο έχει πίνακες σε κάθε σελίδα (ή ένα σύνολο εγγράφων με πίνακα στη σελίδα). Αυτοί οι πίνακες διαφέρουν ως προς τη θέση και το περιεχόμενο, αλλά έχουν τις ίδιες στήλες και γραμμές. Σε αυτήν την περίπτωση, ο χρήστης μπορεί να ορίσει το αντικείμενο [`TemplateTableLayout`](../../templatetablelayout) στο `(0, 0)` μία φορά και στη συνέχεια να το μετακινήσει στη θέση του συγκεκριμένου πίνακα.

Εάν η θέση του πίνακα εξαρτάται από το άλλο αντικείμενο της σελίδας, ο χρήστης μπορεί να ορίσει το αντικείμενο [`TemplateTableLayout`](../../templatetablelayout) με βάση το έγγραφο προτύπου και στη συνέχεια να το μετακινήσει σύμφωνα με ένα αντικείμενο άγκυρας. Για παράδειγμα, εάν αυτός είναι ένας πίνακας σύνοψης και ακολουθείται από πίνακα λεπτομερειών (ο οποίος μπορεί να περιέχει διαφορετικό αριθμό γραμμών). Σε αυτήν την περίπτωση, ο χρήστης μπορεί να ορίσει το αντικείμενο [`TemplateTableLayout`](../../templatetablelayout) στο έγγραφο προτύπου (με το γνωστό ορθογώνιο του πίνακα λεπτομερειών) και στη συνέχεια να μετακινήσει το αντικείμενο [`TemplateTableLayout`](../../templatetablelayout) σύμφωνα με τη διαφορά του ορθογωνίου του πίνακα λεπτομερειών του προτύπου και του πραγματικού εγγράφου.

Η μέθοδος `MoveTo` επιστρέφει ένα αντίγραφο του τρέχοντος αντικειμένου. Ένας χρήστης μπορεί να περάσει οποιεσδήποτε συντεταγμένες (ακόμη και αρνητικές - τότε η διάταξη θα μετακινηθεί προς τα αριστερά/πάνω).

```csharp
// Δημιουργήστε διάταξη πίνακα
TemplateTableLayout layout = new TemplateTableLayout(
    new double[] { 0, 25, 150, 180, 230 },
    new double[] { 0, 15, 30, 45, 60, 75 });

// Εκτυπώστε ένα ορθογώνιο
Rectangle rect = layout.Rectangle;

// Εκτυπώνει: θέση: (0, 0) μέγεθος: (230, 75)
Console.WriteLine(string.Format("pos: ({0}, {1}) size: ({2}, {3})", rect.Left, rect.Top, rect.Size.Width, rect.Size.Height));

// Μετακινήστε τη διάταξη στη συγκεκριμένη θέση του πίνακα
TemplateTableLayout movedLayout = layout.MoveTo(new Point(315, 250));

// Βεβαιωθείτε ότι οι πρώτοι διαχωριστές έχουν μετακινηθεί:
Console.WriteLine(movedLayout.VerticalSeparators[0]); // prints: 315
Console.WriteLine(movedLayout.HorizontalSeparators[0]); // prints: 250

Rectangle movedRect = movedLayout.Rectangle;

// Εκτυπώνει: θέση: (315, 250) μέγεθος: (230, 75)
Console.WriteLine(string.Format("pos: ({0}, {1}) size: ({2}, {3})", movedRect.Left, movedRect.Top, movedRect.Size.Width, movedRect.Size.Height));

// Το αντικείμενο movedLayout είναι αντίγραφο του αντικειμένου layout, έτσι μπορούμε να ρυθμίσουμε τους διαχωριστές χωρίς να επηρεάσουμε την αρχική διάταξη:
movedLayout.HorizontalSeparators.Add(90);

Console.WriteLine(movedLayout.HorizontalSeparators.Count); // prints: 7
Console.WriteLine(layout.HorizontalSeparators.Count); // prints: 6
```
