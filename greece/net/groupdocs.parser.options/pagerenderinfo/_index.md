### Σχόλια

Ορισμένα έγγραφα (υπολογιστικά φύλλα, για παράδειγμα) δεν είναι δυνατόν να αποδοθούν σε μια σελίδα ως μία ενιαία εικόνα. Για αυτά τα έγγραφα μια σελίδα αποδίδεται ως σύνολο πλακιδίων. Αυτά τα πλακίδια τοποθετούνται σε έναν ορθογώνιο πίνακα.

[`RowCount`](./rowcount) and [`ColumnCount`](./columncount) represent the total number of rows and columns of this table. If document page is rendered to the single image these properties are equal to 1.
