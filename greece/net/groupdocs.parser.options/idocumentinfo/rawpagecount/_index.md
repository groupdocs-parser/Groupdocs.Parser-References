## IDocumentInfo.RawPageCount property

Λαμβάνει τον συνολικό αριθμό ακατέργαστων σελίδων του εγγράφου.

```csharp
public int RawPageCount { get; }
```

### Property Value

Μια ακέραια τιμή που αντιπροσωπεύει το συνολικό αριθμό των ακατέργαστων σελίδων.

### Σχόλια

Χρησιμοποιήστε την ιδιότητα `RawPageCount` αντί της ιδιότητας [`PageCount`](../pagecount) για εξαγωγή ακατέργαστου κειμένου. Ορισμένα έγγραφα έχουν διαφορετικούς αριθμούς σελίδων σε ακριβείς και ακατέργαστες λειτουργίες εξαγωγής κειμένου. Η ιδιότητα [`PageCount`](../pagecount) μπορεί να εκτελεί επιπλέον υπολογισμούς που επηρεάζουν την ταχύτητα εξαγωγής κειμένου σε ακατέργαστη λειτουργία.
