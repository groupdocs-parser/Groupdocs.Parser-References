L'espace de noms fournit des classes pour créer des modèles d'analyse des données de documents.

## Classes

| Classe | Description |
| --- | --- |
| [Template](./template) | Fournit le modèle de page de document. Il se compose d'objets [`TemplateItem`](../groupdocs.parser.templates/templateitem) qui représentent les éléments du modèle tels que les champs de texte et les définitions de tableau. |
| [TemplateBarcode](./templatebarcode) | Fournit le champ de code-barres du modèle. |
| [TemplateCollection](./templatecollection) | Représente une collection de modèles d'analyse de documents. |
| [TemplateField](./templatefield) | Fournit le champ de texte du modèle. |
| [TemplateFixedPosition](./templatefixedposition) | Fournit une position de champ de modèle définie par la zone rectangulaire. |
| [TemplateItem](./templateitem) | Fournit une classe abstraite de base pour les éléments de modèle. |
| [TemplateLinkedPosition](./templatelinkedposition) | Fournit une position de champ de modèle qui utilise le champ lié. |
| [TemplateLinkedPositionEdges](./templatelinkedpositionedges) | Fournit les bords du champ lié où le champ de texte est recherché. [`TemplateLinkedPositionEdges`](../groupdocs.parser.templates/templatelinkedpositionedges) est utilisé dans la classe [`TemplateLinkedPosition`](../groupdocs.parser.templates/templatelinkedposition). |
| [TemplateOptions](./templateoptions) | Fournit les options utilisées pour l'analyse via la fonctionnalité de modèle. |
| [TemplatePosition](./templateposition) | Fournit une classe abstraite de base pour les positions de modèle. |
| [TemplateRegexPosition](./templateregexposition) | Fournit une position de champ de modèle qui utilise l'expression régulière. |
| [TemplateTable](./templatetable) | Fournit le tableau du modèle. |
| [TemplateTableLayout](./templatetablelayout) | Fournit la disposition du tableau du modèle qui est utilisée par la classe [`TemplateTable`](../groupdocs.parser.templates/templatetable) pour définir la position du tableau. |
| [TemplateTableParameters](./templatetableparameters) | Fournit des paramètres pour les algorithmes de détection de tableau. |
