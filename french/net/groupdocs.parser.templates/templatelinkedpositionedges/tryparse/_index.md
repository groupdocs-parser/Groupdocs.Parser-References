## TemplateLinkedPositionEdges.TryParse method

Convertit la représentation sous forme de chaîne des bords en son équivalent de classe. Une valeur de retour indique si la conversion a réussi ou échoué.

```csharp
public static bool TryParse(string s, out TemplateLinkedPositionEdges edges)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| s | Chaîne | Une chaîne contenant des bords à convertir. |
| edges | TemplateLinkedPositionEdges& | Lorsque la méthode retourne, elle contient l'instance de la classe [`TemplateLinkedPositionEdges`](../../templatelinkedpositionedges) qui est équivalente à la valeur spécifiée dans le paramètre *s*, si la conversion a réussi ; sinon, `null`. |

### Valeur de retour

`true` si *s* est converti avec succès ; sinon, `false`.
