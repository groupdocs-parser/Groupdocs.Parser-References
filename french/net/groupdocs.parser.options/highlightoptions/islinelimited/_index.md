## HighlightOptions.IsLineLimited property

Obtient la valeur qui indique si l'extraction du surlignage est limitée par le début (ou la fin) d'une ligne de texte.

```csharp
public bool IsLineLimited { get; set; }
```

### Valeur de retour

`true` si l'extraction de surlignage est limitée par le début (ou la fin) d'une ligne de texte ; sinon, `false`.
