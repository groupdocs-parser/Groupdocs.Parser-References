## SearchOptions.SearchByPages property

Obtient la valeur indiquant si la recherche est effectuée par pages.

```csharp
public bool SearchByPages { get; set; }
```

### Property Value

`true` si la recherche est effectuée par pages ; sinon, `false` et la recherche est effectuée sur l'ensemble du document sans inclure la valeur de la propriété [`PageIndex`](../../../groupdocs.parser.data/searchresult/pageindex) dans la classe [`SearchResult`](../../../groupdocs.parser.data/searchresult).
