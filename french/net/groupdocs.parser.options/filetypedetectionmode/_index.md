## FileTypeDetectionMode enumeration

Définit un mode de détection du type de fichier.

```csharp
public enum FileTypeDetectionMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Default | `0` | Le type de fichier est détecté par l'extension du fichier ; si l'extension du fichier n'est pas reconnue, le type de fichier est détecté par le contenu du fichier. |
| Extension | `1` | Le type de fichier est détecté uniquement par l'extension du fichier. |
| Content | `2` | Le type de fichier est détecté uniquement par le contenu du fichier. |
