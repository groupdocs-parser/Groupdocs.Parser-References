## FileType.XLAM field

Le format de module complémentaire basé sur XML et activé par macro pour Excel 2010 et Excel 2007. Un module complémentaire est un programme supplémentaire conçu pour exécuter du code additionnel. Prend en charge l'utilisation de projets VBA et les feuilles de macro Excel 4.0 (.xlm).
