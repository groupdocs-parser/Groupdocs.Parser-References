## AdjustmentFieldsOptions.RequestedPageWidth property

Obtient ou définit la valeur de largeur de page demandée. Cette valeur est utilisée pour mettre à l'échelle les champs du modèle à la taille de page souhaitée. La valeur par défaut est `null`, ce qui signifie qu'aucune mise à l'échelle n'est effectuée.

```csharp
public double? RequestedPageWidth { get; set; }
```

### Property Value

La valeur de largeur de page demandée.
