## SearchResult.Position property

Obtient la position dans le texte du document.

```csharp
public int Position { get; }
```

### Property Value

Un indice basé sur zéro de la position de départ du résultat de recherche. Selon la valeur de la propriété [`SearchByPages`](../../../groupdocs.parser.options/searchoptions/searchbypages), cet indice commence depuis le début du document ou depuis le début de la page du document.
