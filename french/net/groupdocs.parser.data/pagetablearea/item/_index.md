## PageTableArea indexer

Obtient la cellule du tableau par les index de ligne et de colonne.

```csharp
public PageTableAreaCell this[int rowIndex, int columnIndex] { get; }
```

| Paramètre | Description |
| --- | --- |
| rowIndex | L'index basé sur zéro de la ligne de cellule. |
| columnIndex | L'indice basé sur zéro de la colonne de la cellule. |

### Valeur de retour

Une instance de la classe [`PageTableAreaCell`](../../pagetableareacell) ; `null` si aucune cellule n'est trouvée.
