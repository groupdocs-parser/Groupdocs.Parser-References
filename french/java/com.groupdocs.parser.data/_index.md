Le package fournit des classes qui représentent les résultats d'analyse.



## Classes

| Classe | Description |
| --- | --- |
| [ContainerItem](../com.groupdocs.parser.data/containeritem) | Représente un élément de conteneur tel qu'une entité d'archive Zip, une pièce jointe d'e-mail, un élément de portefeuille PDF, etc. |
| [DocumentData](../com.groupdocs.parser.data/documentdata) | Représente les données du document. |
| [DocumentPageData](../com.groupdocs.parser.data/documentpagedata) | Représente les données de la page du document. |
| [FieldData](../com.groupdocs.parser.data/fielddata) | Représente les données de champ telles qu'un nom, un indice de page, une valeur de champ, etc. |
| [HighlightItem](../com.groupdocs.parser.data/highlightitem) | Représente une mise en évidence, une partie du texte généralement utilisée pour expliquer le contexte du texte trouvé dans la fonctionnalité de recherche. |
| [MetadataItem](../com.groupdocs.parser.data/metadataitem) | Représente un élément de métadonnées utilisé dans les éléments de conteneur et la fonctionnalité d'extraction de métadonnées. |
| [Page](../com.groupdocs.parser.data/page) | Représente les informations de la page du document telles que l'indice de page et la taille de la page. |
| [PageArea](../com.groupdocs.parser.data/pagearea) | Représente une classe de base abstraite pour les zones de page utilisées pour représenter des blocs sur la page du document dans la fonctionnalité d'analyse par modèle. |
| [PageBarcodeArea](../com.groupdocs.parser.data/pagebarcodearea) | Représente une zone de code-barres de page utilisée pour représenter une valeur de code-barres dans la fonctionnalité d'analyse par modèle. |
| [PageGroupArea](../com.groupdocs.parser.data/pagegrouparea) | Représente un groupe de zones de page utilisé pour regrouper différents types de blocs de la page du document dans la fonctionnalité d'analyse par modèle. |
| [PageHyperlinkArea](../com.groupdocs.parser.data/pagehyperlinkarea) | Représente une zone de page utilisée pour représenter un hyperlien sur la page. |
| [PageImageArea](../com.groupdocs.parser.data/pageimagearea) | Représente une zone d'image de page utilisée pour représenter une image sur la page dans la fonctionnalité d'analyse par modèle ou une pièce jointe d'image si les images sont extraites d'e-mails ou d'archives Zip. |
| [PageTableArea](../com.groupdocs.parser.data/pagetablearea) | Représente une zone de tableau de page utilisée pour représenter un tableau dans la fonctionnalité d'analyse par modèle. |
| [PageTableAreaCell](../com.groupdocs.parser.data/pagetableareacell) | Représente une cellule de tableau utilisée dans la classe [PageTableArea](../com.groupdocs.parser.data/pagetablearea). |
| [PageTextArea](../com.groupdocs.parser.data/pagetextarea) | Représente une zone de texte de page utilisée pour représenter une valeur de texte dans la fonctionnalité d'analyse par modèle ou d'analyse de formulaire. |
| [Point](../com.groupdocs.parser.data/point) | Représente un point. |
| [Rectangle](../com.groupdocs.parser.data/rectangle) | Représente une zone rectangulaire. |
| [SearchResult](../com.groupdocs.parser.data/searchresult) | Représente le résultat de la recherche dans la fonctionnalité de recherche. |
| [Size](../com.groupdocs.parser.data/size) | Représente une taille. |
| [TextReader](../com.groupdocs.parser.data/textreader) | Représente un lecteur capable de lire une série séquentielle de caractères. |
| [TextStyle](../com.groupdocs.parser.data/textstyle) | Représente le style du texte tel qu'un nom de police, une taille de police, etc. |
| [TocItem](../com.groupdocs.parser.data/tocitem) | Représente l'élément utilisé dans la fonctionnalité d'extraction de la table des matières. |
