Le package fournit des classes pour créer des modèles d'analyse des données de documents.



## Classes

| Classe | Description |
| --- | --- |
| [Template](../com.groupdocs.parser.templates/template) | Fournit le modèle de page de document. |
| [TemplateBarcode](../com.groupdocs.parser.templates/templatebarcode) | Fournit le champ de code-barres du modèle. |
| [TemplateField](../com.groupdocs.parser.templates/templatefield) | Fournit le champ de texte du modèle. |
| [TemplateFixedPosition](../com.groupdocs.parser.templates/templatefixedposition) | Fournit une position de champ de modèle définie par la zone rectangulaire. |
| [TemplateItem](../com.groupdocs.parser.templates/templateitem) | Fournit une classe abstraite de base pour les éléments du modèle. |
| [TemplateLinkedPosition](../com.groupdocs.parser.templates/templatelinkedposition) | Fournit une position de champ de modèle qui utilise le champ lié. |
| [TemplateLinkedPositionEdges](../com.groupdocs.parser.templates/templatelinkedpositionedges) | Fournit les bords du champ lié où le champ de texte est recherché. |
| [TemplateOptions](../com.groupdocs.parser.templates/templateoptions) | Fournit les options utilisées pour l'analyse par la fonctionnalité de modèle. |
| [TemplatePosition](../com.groupdocs.parser.templates/templateposition) | Fournit une classe abstraite de base pour les positions de modèle. |
| [TemplateRegexPosition](../com.groupdocs.parser.templates/templateregexposition) | Fournit une position de champ de modèle qui utilise l'expression régulière. |
| [TemplateTable](../com.groupdocs.parser.templates/templatetable) | Fournit la table de modèle. |
| [TemplateTableLayout](../com.groupdocs.parser.templates/templatetablelayout) | Fournit la disposition de la table de modèle qui est utilisée par la classe [TemplateTable](../com.groupdocs.parser.templates/templatetable) pour définir la position de la table. |
| [TemplateTableParameters](../com.groupdocs.parser.templates/templatetableparameters) | Fournit des paramètres pour les algorithmes de détection de tables. |
